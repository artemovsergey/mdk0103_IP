# Практическая работа

Как профессиональный разработчик по языку Kotlin создай практическую работу для студентов на тему: "Коллекции". Материал по этим темам находятся в закрепленных файлах. Модифицируй практическую работу так, чтобы в ней была тема, цель, ход работы, теретическая часть, практический пример, 15 вариантов простых заданий, критерии оценки от 2 до 5, контрольные вопросы. Вариант выбирается по номеру в журнале. В репозитории должны быть: проект Idea, папка images со скриншотами работы программы, файлы gitignore и readme.md. В файле readme.md: номер, название практической работы, вариант и текст задания, оформление кода, скриншоты работы программы. Готовая практическая работа должна быть выложена на локальный git сервер gogs
