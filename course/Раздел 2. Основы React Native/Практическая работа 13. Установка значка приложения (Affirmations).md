# Практическая работа 13. Установка значка приложения (Affirmations)

Значок — важная часть оформления приложения. Он отображается на главном экране телефона, в списке приложений и в настройках, и по нему пользователь узнаёт программу среди других. В этой работе вы научитесь менять значок приложения в проекте Expo и подготовите собственный значок для приложения **Affirmations**.

### Необходимые условия

- Приложение `Affirmations` из практической работы 11.
- Умение создавать и запускать проект Expo.

### Что вы узнаете

- Где хранится значок приложения в проекте Expo.
- Как заменить значок в файле конфигурации `app.json`.
- Что такое адаптивная иконка и из каких слоёв она состоит.
- Как изменить название приложения.
- Как проверить значок в веб-версии и в собранном приложении.

### Что вы создадите

Собственный значок и название для приложения **Affirmations**.

## Шаг 1. Где хранится значок

Вся конфигурация приложения Expo описана в файле **`app.json`** в корне проекта. Откройте его:

```json
{
  "expo": {
    "name": "affirmations",
    "slug": "affirmations",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/icon.png",
    "userInterfaceStyle": "light",
    "ios": {
      "supportsTablet": true
    },
    "android": {
      "adaptiveIcon": {
        "backgroundColor": "#E6F4FE",
        "foregroundImage": "./assets/android-icon-foreground.png",
        "backgroundImage": "./assets/android-icon-background.png",
        "monochromeImage": "./assets/android-icon-monochrome.png"
      }
    },
    "web": {
      "favicon": "./assets/favicon.png"
    }
  }
}
```

За значок отвечают следующие поля:

| Поле | Назначение |
|:-----|:-----------|
| `icon` | основной значок приложения (файл `assets/icon.png`) |
| `android.adaptiveIcon.foregroundImage` | передний слой адаптивной иконки |
| `android.adaptiveIcon.backgroundImage` | фоновый слой адаптивной иконки |
| `android.adaptiveIcon.backgroundColor` | цвет фона, если фоновый слой — просто цвет |
| `android.adaptiveIcon.monochromeImage` | одноцветная версия значка |
| `web.favicon` | значок для веб-версии |

Сами изображения значков лежат в папке `assets`. Именно эти файлы мы и будем заменять.

## Шаг 2. Каким должно быть изображение значка

- Формат PNG, квадратная картинка размером **1024×1024** пикселя.
- Непрозрачный фон: так значок одинаково хорошо смотрится и на светлой, и на тёмной теме устройства.
- Простой и узнаваемый рисунок: на маленьком значке видны только крупные детали, мелкие линии смазываются.
- Для слоёв адаптивной иконки из шага 4 подойдут изображения того же размера — 1024×1024 пикселя.

> Отдельные изображения под разные экраны готовить не нужно: Expo сам сгенерирует все необходимые размеры из одного исходного файла при сборке приложения.

## Шаг 3. Замена основного значка

1. Подготовьте изображение значка для приложения Affirmations — например, солнце или сердце.
2. Сохраните его как `assets/icon.png`, заменив стандартный файл. Имя менять не нужно: путь к нему уже прописан в `app.json`.
3. Убедитесь, что в `app.json` осталась строка:

```json
"icon": "./assets/icon.png"
```

> Если значок не обновился, проверьте, что файл сохранён с тем же именем и расширением `.png`, а сервер разработки перезапущен.

После этого основной значок приложения обновлён. Осталось настроить его вид на устройствах Android.

## Шаг 4. Адаптивная иконка

На устройствах Android значок может быть **адаптивным**: он состоит из двух слоёв, поверх которых система накладывает маску — круг, скруглённый квадрат или другую форму. Слои такие:

- **передний план** (`foregroundImage`) — основной рисунок;
- **фон** (`backgroundImage` или `backgroundColor`) — изображение или цвет под рисунком.

Форму маски выбирает производитель устройства, поэтому важные детали рисунка должны находиться в **безопасной зоне**. Мысленно впишите в изображение круг диаметром примерно две трети его ширины — всё самое важное должно помещаться в этот круг. Края картинки могут быть обрезаны, поэтому там не должно быть значимых деталей.

Подготовьте три изображения:

- `assets/android-icon-foreground.png` — рисунок на прозрачном фоне;
- `assets/android-icon-background.png` — фоновый слой (если фона-картинки нет, достаточно одного цвета в `backgroundColor`);
- `assets/android-icon-monochrome.png` — одноцветный силуэт для «тематических» значков.

Фрагмент `app.json` с настройками адаптивной иконки:

```json
"android": {
  "adaptiveIcon": {
    "backgroundColor": "#E6F4FE",
    "foregroundImage": "./assets/android-icon-foreground.png",
    "backgroundImage": "./assets/android-icon-background.png",
    "monochromeImage": "./assets/android-icon-monochrome.png"
  }
}
```

- Если фоновый слой — один цвет, удалите строку с `backgroundImage` и оставьте `backgroundColor`.
- Если монохромная версия не нужна, строку с `monochromeImage` можно убрать.

## Шаг 5. Название приложения

Пока вы в `app.json`, задайте понятное название приложения:

```json
"name": "Affirmations"
```

- `name` — название, которое видит пользователь, например под значком на главном экране.
- `slug` — техническое имя проекта: строчные латинские буквы, цифры и дефисы, без пробелов.

## Шаг 6. Проверка работы

1. Проверьте конфигурацию: откройте `app.json` и убедитесь, что все пути к изображениям указывают на существующие файлы в папке `assets`.
2. В веб-режиме (`npx expo start --web`) значок веб-страницы — favicon — виден во вкладке браузера. Обновите страницу с очисткой кэша (`Ctrl+F5`).
3. Запустите приложение командой `npx expo start` и убедитесь, что оно по-прежнему открывается без ошибок.

> В приложении **Expo Go** значки отдельных проектов не отображаются: на главном экране телефона всегда виден только значок самого Expo Go. Собственный значок появляется у собранного приложения — например, после сборки через сервис **EAS Build** или после установки готового файла приложения.

## Задания для самостоятельной работы

1. Придумайте и установите значок для приложения `Courses` из практической работы 12.
2. Измените `backgroundColor` адаптивной иконки на другой цвет и сравните результат.
3. Подготовьте монохромную версию значка: простой одноцветный силуэт на прозрачном фоне.
4. Придумайте короткое название для приложения Affirmations и обновите поле `name`.
5. Сделайте значок для веб-версии: замените файл `assets/favicon.png` и проверьте вкладку браузера.

## Резюме

- Значок приложения хранится в папке `assets` и настраивается в файле `app.json`.
- Expo генерирует значки всех размеров из одного исходного изображения.
- Адаптивная иконка состоит из переднего плана и фона; важные детали должны быть в безопасной зоне.
- Название приложения задаётся полем `name`.
- В Expo Go собственный значок не виден — он появляется только у собранного приложения.
