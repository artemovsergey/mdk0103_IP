# Практическая работа 7. Основы компонентов React Native

Этот урок посвящён созданию макетов с использованием изученных компонентов React Native: `View`, `Text`, `Image` и `StyleSheet`. Упражнения основаны на реальных примерах оформления экранов.

В упражнениях вам даются спецификации интерфейса: размеры шрифтов, отступы, цвета. Эти спецификации помогают создавать единообразные интерфейсы. Умение следовать спецификациям и разбираться в документации — важный навык разработчика.

### Необходимые условия

- Лекция 11 «Введение в React Native (Happy Birthday)».
- Лекция 12 «Добавление изображений (Happy Birthday)».
- Умение создавать проект Expo и запускать его на телефоне или в браузере.

### Что вы узнаете

- Как выводить текст разных размеров и выравнивания.
- Как подключать изображения из папки `assets`.
- Как располагать элементы по центру, в ряд и в колонку с помощью flexbox.
- Как оформлять интерфейс с помощью `StyleSheet`.

### Что вы создадите

Три экрана-упражнения: «Статья», «Диспетчер задач» и «Квадрант».

## Подготовка проекта

1. Создайте проект Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest components-practice --template blank-typescript
cd components-practice
```

2. В папке `resources` репозитория предмета найдите изображения `bg_article_background.png` и `ic_task_completed.png` и скопируйте их в папку `assets` проекта.

3. Запустите приложение:

```bash
npx expo start
```

Откройте приложение клавишей `w` в браузере или отсканируйте QR-код приложением Expo Go. Все упражнения выполняются в файле `App.tsx`: после каждого упражнения заменяйте его содержимое кодом из работы.

## Упражнение 1. Приложение «Статья»

Создайте экран, на котором отображается статья об учебнике по React Native.

### Спецификация интерфейса

- Изображение заполняет всю ширину экрана.
- Первый текст: размер шрифта `24`, отступы `16` со всех сторон.
- Второй текст: размер шрифта по умолчанию (`14`), отступы `16` по бокам, выравнивание по ширине.
- Третий текст: размер шрифта по умолчанию, отступы `16` со всех сторон, выравнивание по ширине.

### Текст статьи

```
Учебник по React Native
React Native — это фреймворк для создания нативных мобильных приложений с помощью TypeScript. Он позволяет писать код один раз и запускать его на Android и iOS, используя нативные компоненты.
В этом уроке вы создадите простой интерфейс с помощью декларативных компонентов. Вы описываете, какие элементы нужны, а React Native сам отрисовывает их на экране.
```

### Код экрана

```tsx
import { StatusBar } from 'expo-status-bar'
import { Image, StyleSheet, Text, View } from 'react-native'

const articleImage = require('./assets/bg_article_background.png')

export default function App() {
  return (
    <View style={styles.screen}>
      <Image source={articleImage} style={styles.image} accessibilityLabel="Учебник по React Native" />
      <Text style={styles.title}>Учебник по React Native</Text>
      <Text style={styles.paragraph}>
        React Native — это фреймворк для создания нативных мобильных приложений с помощью
        TypeScript. Он позволяет писать код один раз и запускать его на Android и iOS, используя
        нативные компоненты.
      </Text>
      <Text style={styles.lastParagraph}>
        В этом уроке вы создадите простой интерфейс с помощью декларативных компонентов. Вы
        описываете, какие элементы нужны, а React Native сам отрисовывает их на экране.
      </Text>
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#FFFFFF' },
  image: { width: '100%', height: 220 },
  title: { fontSize: 24, padding: 16 },
  paragraph: { paddingHorizontal: 16, textAlign: 'justify' },
  lastParagraph: { padding: 16, textAlign: 'justify' },
})
```

- `require('./assets/...')` подключает изображение из папки `assets`.
- `width: '100%'` растягивает изображение на всю ширину экрана, высота задана числом.
- `textAlign: 'justify'` выравнивает текст по ширине.
- Все стили собраны в одном объекте `StyleSheet.create`.

## Упражнение 2. Приложение «Диспетчер задач»

Создайте экран, который пользователь увидит, когда выполнит все задачи за день.

### Спецификация интерфейса

- Всё содержимое выровнено по центру экрана по вертикали и горизонтали.
- Первый текст: жирный шрифт (`fontWeight: 'bold'`), отступ сверху `24`, снизу `8`.
- Второй текст: размер шрифта `16`.

### Код экрана

```tsx
import { StatusBar } from 'expo-status-bar'
import { Image, StyleSheet, Text, View } from 'react-native'

const completedImage = require('./assets/ic_task_completed.png')

export default function App() {
  return (
    <View style={styles.screen}>
      <Image source={completedImage} style={styles.image} accessibilityLabel="Все задания выполнены" />
      <Text style={styles.title}>Все задания выполнены</Text>
      <Text style={styles.subtitle}>Отличная работа!</Text>
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 16 },
  image: { width: 160, height: 160 },
  title: { fontWeight: 'bold', marginTop: 24, marginBottom: 8 },
  subtitle: { fontSize: 16 },
})
```

- `alignItems: 'center'` центрирует элементы по горизонтали, `justifyContent: 'center'` — по вертикали.
- `fontWeight: 'bold'` делает текст жирным.
- Отступы `marginTop` и `marginBottom` задают расстояние вокруг заголовка.

## Упражнение 3. Приложение «Квадрант»

Создайте приложение, которое отображает информацию о компонентах React Native. Экран разделён на четыре квадранта; в каждом — название компонента и его описание в одном предложении.

### Спецификация интерфейса

- Экран разделён на четыре равные части (два ряда по два квадранта).
- В каждом квадранте: отступы `16` со всех сторон, содержимое по центру по вертикали и горизонтали.
- Первый текст (название): полужирный шрифт, отступ снизу `16`.
- Второй текст (описание): размер шрифта по умолчанию.

### Цвета квадрантов

- `#EADDFF`
- `#D0BCFF`
- `#B69DF8`
- `#F6EDFF`

### Содержимое квадрантов

```
Компонент Text
Отображает текст и поддерживает базовые стили шрифта.

Компонент Image
Отображает изображение из файла или из сети.

Компонент Row (ряд)
Компоненты View с flexDirection 'row' располагают элементы по горизонтали.

Компонент Column (колонка)
Компоненты View с flexDirection 'column' располагают элементы по вертикали.
```

### Код экрана

```tsx
import { StatusBar } from 'expo-status-bar'
import { StyleSheet, Text, View } from 'react-native'

type Quadrant = {
  title: string
  description: string
  color: string
}

const QUADRANTS: Quadrant[] = [
  { title: 'Компонент Text', description: 'Отображает текст и поддерживает базовые стили шрифта.', color: '#EADDFF' },
  { title: 'Компонент Image', description: 'Отображает изображение из файла или из сети.', color: '#D0BCFF' },
  { title: 'Компонент Row (ряд)', description: "Компоненты View с flexDirection 'row' располагают элементы по горизонтали.", color: '#B69DF8' },
  { title: 'Компонент Column (колонка)', description: "Компоненты View с flexDirection 'column' располагают элементы по вертикали.", color: '#F6EDFF' },
]

function QuadrantCard({ quadrant }: { quadrant: Quadrant }) {
  return (
    <View style={[styles.quadrant, { backgroundColor: quadrant.color }]}>
      <Text style={styles.quadrantTitle}>{quadrant.title}</Text>
      <Text style={styles.quadrantText}>{quadrant.description}</Text>
    </View>
  )
}

export default function App() {
  return (
    <View style={styles.screen}>
      <View style={styles.row}>
        <QuadrantCard quadrant={QUADRANTS[0]} />
        <QuadrantCard quadrant={QUADRANTS[1]} />
      </View>
      <View style={styles.row}>
        <QuadrantCard quadrant={QUADRANTS[2]} />
        <QuadrantCard quadrant={QUADRANTS[3]} />
      </View>
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#FFFFFF' },
  row: { flex: 1, flexDirection: 'row' },
  quadrant: { flex: 1, padding: 16, alignItems: 'center', justifyContent: 'center' },
  quadrantTitle: { fontWeight: 'bold', marginBottom: 16, textAlign: 'center' },
  quadrantText: { textAlign: 'center' },
})
```

- `flexDirection: 'row'` выстраивает квадранты в ряд, а `flex: 1` делит экран на четыре равные части.
- Массив стилей `[styles.quadrant, { backgroundColor: ... }]` объединяет общий стиль и цвет из данных.
- Компонент `QuadrantCard` принимает данные через параметр и возвращает разметку — один компонент используется четыре раза.

## Резюме

- `View` группирует компоненты и задаёт раскладку.
- `Text` отображает текст, `Image` — изображения.
- Отступы (`padding`, `margin`), размер шрифта (`fontSize`) и выравнивание (`textAlign`) задаются в стилях.
- Для раскладки в ряд и колонку используется flexbox (`flexDirection`, `alignItems`, `justifyContent`).
- Спецификации интерфейса помогают создавать единообразные экраны.
