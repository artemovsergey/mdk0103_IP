# Лекция 12. Добавление изображений (Happy Birthday)

В приложении «С днём рождения» пока есть только текст. Добавим в него праздничное изображение. В этой лекции вы научитесь подключать изображения, управлять их размером и масштабированием, а также размещать текст поверх картинки.

### Необходимые условия

- Умение создавать и запускать приложение Expo.
- Знание компонентов `Text`, `View` и `StyleSheet`.

### Что вы узнаете

- Как добавить изображение в проект (папка `assets`).
- Как отобразить изображение с помощью компонента `Image`.
- Как управлять размером и масштабированием изображения.
- Как использовать изображение в качестве фона (`ImageBackground`).
- Как подписать изображение для программ чтения с экрана.

### Что вы создадите

- Усовершенствуете приложение «С днём рождения», добавив в него изображение.

## Где хранятся изображения

В Expo все изображения и прочие файлы приложения хранятся в папке **`assets`**. Поместите туда файл с изображением (например, `party.png`).

```
happy-birthday/
├── assets/
│   ├── icon.png
│   ├── splash-icon.png
│   └── party.png      ← наше изображение
├── App.tsx
└── ...
```

## Как добавить изображение в проект

1. В папке `resources` репозитория предмета найдите файл `party.png`.
2. Скопируйте его в папку `assets` проекта.
3. Убедитесь, что в папке `assets` появился файл `party.png`.

> Имена файлов лучше давать латинскими буквами, строчными и без пробелов: `party.png`, `birthday-cake.png`. Такой файл проще подключить, и он не вызовет ошибок при сборке.

## Подключение изображения

Чтобы использовать изображение из папки `assets`, его подключают функцией `require` с путём к файлу:

```tsx
const partyImage = require('./assets/party.png');
```

Путь задаётся **относительно файла**, в котором находится код. Результат `require` передают компоненту `Image` в атрибут `source`.

## Компонент Image

Компонент `Image` отображает изображение:

```tsx
import { Image, StyleSheet, Text, View } from 'react-native';

const partyImage = require('./assets/party.png');

export default function App() {
  return (
    <View style={styles.container}>
      <Image source={partyImage} />
      <Text style={styles.title}>С днём рождения, Александр!</Text>
    </View>
  );
}
```

Обязательный атрибут — `source`, источник изображения. Также рекомендуется всегда задавать `accessibilityLabel` — текстовое описание изображения для программ чтения с экрана:

```tsx
<Image source={partyImage} accessibilityLabel="Праздничная открытка" />
```

Если изображение декоративное и не несёт смысла, описание можно не задавать: программы чтения с экрана просто прочитают текст рядом с картинкой.

## Размер изображения

Без явного размера изображение отображается в своих «натуральных» размерах, что обычно не подходит. Размер задаётся в стиле:

```tsx
const styles = StyleSheet.create({
  image: {
    width: 300,
    height: 200,
  },
});
```

```tsx
<Image source={partyImage} style={styles.image} />
```

Чтобы изображение заняло всю ширину экрана, используют `width: '100%'`:

```tsx
image: {
  width: '100%',
  height: 200,
},
```

## Масштабирование: resizeMode

Если заданные размеры не совпадают с пропорциями изображения, оно может исказиться. Свойство `resizeMode` управляет тем, как изображение подгоняется под размер:

```tsx
<Image
  source={partyImage}
  style={styles.image}
  resizeMode="cover"
/>
```

| Значение | Поведение |
|:---------|:----------|
| `cover` | заполняет область, сохраняя пропорции; края могут обрезаться |
| `contain` | полностью помещается в область, сохраняя пропорции |
| `stretch` | растягивается под размер (искажает пропорции) |
| `center` | центрируется без масштабирования |

## Изображение как фон

Часто изображение нужно растянуть на весь экран и разместить поверх него текст. Для этого используют компонент `ImageBackground`:

```tsx
import { ImageBackground, StyleSheet, Text } from 'react-native';

export default function App() {
  return (
    <ImageBackground
      source={require('./assets/party.png')}
      style={styles.container}
    >
      <Text style={styles.title}>С днём рождения!</Text>
    </ImageBackground>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#FFFFFF',
  },
});
```

`ImageBackground` — это тот же `Image`, но внутрь него можно помещать другие компоненты.

## Текст поверх изображения

Чтобы текст всегда был читаемым на пёстром фоне, его размещают на полупрозрачной подложке. Стиль `backgroundColor` принимает цвет в формате `rgba`, где последнее число — прозрачность от `0` до `1`:

```tsx
<ImageBackground
  source={partyImage}
  style={styles.background}
  resizeMode="cover"
>
  <View style={styles.overlay}>
    <Text style={styles.title}>С днём рождения, Александр!</Text>
    <Text style={styles.subtitle}>От Ирины</Text>
  </View>
</ImageBackground>
```

```tsx
overlay: {
  backgroundColor: 'rgba(0, 0, 0, 0.35)',
  paddingHorizontal: 24,
  paddingVertical: 16,
  borderRadius: 16,
  alignItems: 'center',
},
```

Подложка затемняет изображение под текстом и делает надпись контрастной. Толщину затемнения регулирует последнее число в `rgba`.

## Приложение целиком

Файл `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar';
import { ImageBackground, StyleSheet, Text, View } from 'react-native';

const partyImage = require('./assets/party.png');

export default function App() {
  return (
    <ImageBackground
      source={partyImage}
      style={styles.background}
      resizeMode="cover"
    >
      <View style={styles.overlay}>
        <Text style={styles.title}>С днём рождения, Александр!</Text>
        <Text style={styles.subtitle}>От Ирины</Text>
      </View>
      <StatusBar style="auto" />
    </ImageBackground>
  );
}

const styles = StyleSheet.create({
  background: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 16,
  },
  overlay: {
    backgroundColor: 'rgba(0, 0, 0, 0.35)',
    paddingHorizontal: 24,
    paddingVertical: 16,
    borderRadius: 16,
    alignItems: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#FFFFFF',
    textAlign: 'center',
    marginBottom: 8,
  },
  subtitle: {
    fontSize: 16,
    color: '#FFE6F0',
  },
});
```

Сохраните файл — приложение обновится автоматически. Теперь поздравление размещено поверх фотографии.

## Резюме

- Изображения хранятся в папке `assets`.
- Изображение подключается функцией `require` и отображается компонентом `Image`.
- `source` — источник изображения, `accessibilityLabel` — описание для программ чтения с экрана.
- Размер задаётся в стиле (`width`, `height`).
- `resizeMode` управляет масштабированием: `cover`, `contain`, `stretch`, `center`.
- `ImageBackground` позволяет размещать компоненты поверх изображения.
- Полупрозрачная подложка `rgba` делает текст читаемым на любом фоне.
