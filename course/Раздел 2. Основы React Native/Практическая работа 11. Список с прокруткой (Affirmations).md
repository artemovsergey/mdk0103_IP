# Практическая работа 11. Список с прокруткой (Affirmations)

В этой работе вы научитесь создавать прокручиваемый список в приложении React Native.

Вы будете работать с приложением **Affirmations** («Аффирмации»), которое отображает список позитивных утверждений с изображениями. Данные для приложения уже подготовлены — ваша задача вывести их на экран в виде аккуратных карточек.

### Необходимые условия

- Лекция 12 «Добавление изображений (Happy Birthday)».
- Знание массивов и типов в TypeScript.
- Умение создавать интерфейс с помощью компонентов `View`, `Text` и `Image`.

### Что вы узнаете

- Как описать модель данных с помощью типа TypeScript.
- Как создать карточку — элемент списка из изображения и текста.
- Как создать прокручиваемый список с помощью `FlatList` и почему он подходит для длинных списков.

### Что вы создадите

Приложение **Affirmations**, которое отображает прокручиваемый список аффирмаций.

## Подготовка проекта

1. Создайте проект Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest affirmations --template blank-typescript
cd affirmations
```

2. В папке `resources` репозитория предмета найдите изображения `image1.png`, `image2.png`, ..., `image6.png` и скопируйте их в папку `assets` проекта.

3. Запустите приложение:

```bash
npx expo start
```

Все изменения этой работы вносятся в файл `App.tsx`.

## Шаг 1. Модель данных

Каждая аффирмация состоит из текста и изображения. Опишем её тип:

```tsx
import type { ImageSourcePropType } from 'react-native'

type Affirmation = {
  text: string
  image: ImageSourcePropType
}
```

- `text` — текст аффирмации.
- `image` — источник изображения. Тип `ImageSourcePropType` подходит для картинок, подключённых функцией `require`, и подсказывает компилятору, что в это поле можно передать только изображение.

## Шаг 2. Данные приложения

Создайте массив аффирмаций. Каждый элемент содержит текст и изображение из папки `assets`:

```tsx
const affirmations: Affirmation[] = [
  { text: 'Я полон энергии и энтузиазма', image: require('./assets/image1.png') },
  { text: 'Каждый день я становлюсь лучше', image: require('./assets/image2.png') },
  { text: 'Я верю в свои силы', image: require('./assets/image3.png') },
  { text: 'У меня всё получается', image: require('./assets/image4.png') },
  { text: 'Я открыт новым возможностям', image: require('./assets/image5.png') },
  { text: 'Я благодарен за каждый день', image: require('./assets/image6.png') },
]
```

> Массив объявлен вне компонента `App`: данные не меняются при отрисовке, поэтому нет смысла создавать их заново на каждый рендер.

## Шаг 3. Карточка аффирмации

Каждый элемент списка — карточка: изображение сверху, текст под ним. Создайте компонент `AffirmationCard`:

```tsx
import { Image, Text, View } from 'react-native'

function AffirmationCard({ affirmation }: { affirmation: Affirmation }) {
  return (
    <View style={styles.card}>
      <Image source={affirmation.image} style={styles.image} />
      <Text style={styles.text}>{affirmation.text}</Text>
    </View>
  )
}
```

Стили карточки (добавьте их в объект `StyleSheet`, полностью он будет приведён на шаге 5):

```tsx
card: {
  backgroundColor: '#FFFFFF',
  borderRadius: 12,
  overflow: 'hidden',
  marginVertical: 8,
},
image: {
  width: '100%',
  height: 194,
},
text: {
  fontSize: 18,
  padding: 16,
},
```

- Компонент принимает одну аффирмацию и возвращает разметку карточки.
- `overflow: 'hidden'` обрезает изображение по скруглённым углам карточки.
- Ширина изображения `'100%'` — оно занимает всю ширину карточки, высота задана числом.

## Шаг 4. Прокручиваемый список FlatList

Для прокручиваемых списков в React Native используется компонент **`FlatList`**. Он отображает только видимые элементы, поэтому подходит и для коротких, и для длинных списков: лишние карточки не занимают память.

Основные атрибуты `FlatList`:

| Атрибут | Назначение |
|:--------|:-----------|
| `data` | массив данных |
| `renderItem` | функция, возвращающая элемент для каждого пункта списка |
| `keyExtractor` | функция, возвращающая уникальный ключ элемента |
| `contentContainerStyle` | стили внутреннего контейнера со всеми элементами |

Соберите список в компоненте `App`:

```tsx
import { FlatList } from 'react-native'

export default function App() {
  return (
    <View style={styles.container}>
      <FlatList
        data={affirmations}
        renderItem={({ item }) => <AffirmationCard affirmation={item} />}
        keyExtractor={(item, index) => index.toString()}
        contentContainerStyle={styles.list}
      />
      <StatusBar style="auto" />
    </View>
  )
}
```

- `data` — массив аффирмаций.
- `renderItem` получает объект `{ item }`, где `item` — очередная аффирмация.
- `keyExtractor` возвращает уникальный ключ для каждого элемента списка.
- `contentContainerStyle={styles.list}` добавляет отступы вокруг списка.

## Шаг 5. Полный код приложения

Ниже — полный код `App.tsx`. Соберите его из шагов 1–4:

```tsx
import { StatusBar } from 'expo-status-bar'
import { FlatList, Image, StyleSheet, Text, View } from 'react-native'
import type { ImageSourcePropType } from 'react-native'

type Affirmation = {
  text: string
  image: ImageSourcePropType
}

const affirmations: Affirmation[] = [
  { text: 'Я полон энергии и энтузиазма', image: require('./assets/image1.png') },
  { text: 'Каждый день я становлюсь лучше', image: require('./assets/image2.png') },
  { text: 'Я верю в свои силы', image: require('./assets/image3.png') },
  { text: 'У меня всё получается', image: require('./assets/image4.png') },
  { text: 'Я открыт новым возможностям', image: require('./assets/image5.png') },
  { text: 'Я благодарен за каждый день', image: require('./assets/image6.png') },
]

function AffirmationCard({ affirmation }: { affirmation: Affirmation }) {
  return (
    <View style={styles.card}>
      <Image source={affirmation.image} style={styles.image} />
      <Text style={styles.text}>{affirmation.text}</Text>
    </View>
  )
}

export default function App() {
  return (
    <View style={styles.container}>
      <FlatList
        data={affirmations}
        renderItem={({ item }) => <AffirmationCard affirmation={item} />}
        keyExtractor={(item, index) => index.toString()}
        contentContainerStyle={styles.list}
      />
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#EDE7F6',
  },
  list: {
    padding: 16,
  },
  card: {
    backgroundColor: '#FFFFFF',
    borderRadius: 12,
    overflow: 'hidden',
    marginVertical: 8,
  },
  image: {
    width: '100%',
    height: 194,
  },
  text: {
    fontSize: 18,
    padding: 16,
  },
})
```

## Резюме

- Модель данных удобно описывать отдельным типом TypeScript.
- Карточка — это компонент, который объединяет изображение и текст.
- `FlatList` создаёт прокручиваемый список из массива данных.
