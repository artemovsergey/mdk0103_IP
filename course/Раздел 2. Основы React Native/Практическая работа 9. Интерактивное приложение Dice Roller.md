# Практическая работа 9. Интерактивное приложение Dice Roller

В этой работе вы создадите интерактивное приложение **Dice Roller** («Бросок костей»): пользователь нажимает кнопку, и на экране появляется изображение случайной грани игральной кости.

Приложение разрабатывается на языке **TypeScript** с использованием фреймворка **React Native** и инструмента **Expo**. Сначала вы соберёте макет, а затем напишете логику обработки нажатия на кнопку.

### Необходимые условия

- Настроенное окружение для разработки (см. файл «Настройка окружения Expo»).
- Лекции 11 и 12: компоненты `View`, `Text`, `Image` и стили `StyleSheet`.
- Знание основ TypeScript: переменные, функции, типы данных.

### Что вы узнаете

- Как отображать изображения из папки `assets`.
- Как добавить кнопку и обработать её нажатие.
- Как хранить и обновлять данные с помощью хука `useState`.

### Что вы создадите

Приложение Dice Roller: в центре экрана — изображение кости и кнопка «Бросить кости». При нажатии на кнопку изображение меняется на случайную грань.

## Подготовка проекта

1. Скачайте стартовый проект `dice-roller-starter.zip` из папки `repositories` репозитория предмета и распакуйте архив в удобную папку. Стартовый проект содержит заготовку экрана и изображения шести граней кости в папке `assets/dice`.

2. Установите зависимости и запустите приложение:

```bash
npm install
npx expo start
```

Откройте приложение клавишей `w` в браузере или отсканируйте QR-код приложением Expo Go. Все изменения этой работы вносятся в файл `App.tsx`.

Заготовка экрана — это контейнер `View`, который занимает весь экран (`flex: 1`) и центрирует содержимое с помощью `alignItems: 'center'` и `justifyContent: 'center'`.

## Шаг 1. Компонент экрана

Приложение состоит из двух элементов: изображение кости и кнопка. Расположим их друг под другом в отдельном компоненте `DiceWithButtonAndImage`. В React Native компонент — это функция, которая возвращает разметку (JSX); имена компонентов начинаются с заглавной буквы.

```tsx
function DiceWithButtonAndImage() {
  return (
    <View style={styles.diceContainer}>
      {/* Здесь будут изображение и кнопка */}
    </View>
  );
}

export default function App() {
  return (
    <View style={styles.container}>
      <StatusBar style="auto" />
      <DiceWithButtonAndImage />
    </View>
  );
}
```

Добавьте стиль `diceContainer` в `StyleSheet.create`:

```tsx
diceContainer: {
  alignItems: 'center',
},
```

> Обратите внимание: разметка JSX заключается в круглые скобки после `return`, а компоненты записываются как `<ИмяКомпонента />`.

## Шаг 2. Изображение и кнопка

В папке `assets/dice` лежат шесть изображений: `dice_1.png` ... `dice_6.png`. Источник изображения задаётся функцией `require` с путём к файлу относительно текущего файла. Опишем все грани в виде объекта:

```tsx
import type { ImageSourcePropType } from 'react-native';

const DICE_IMAGES: Record<number, ImageSourcePropType> = {
  1: require('./assets/dice/dice_1.png'),
  2: require('./assets/dice/dice_2.png'),
  3: require('./assets/dice/dice_3.png'),
  4: require('./assets/dice/dice_4.png'),
  5: require('./assets/dice/dice_5.png'),
  6: require('./assets/dice/dice_6.png'),
};
```

Теперь добавим в компонент изображение и кнопку. Кнопка — это компонент `Pressable`: он реагирует на нажатие, а его параметр `onPress` принимает функцию, которая выполнится при нажатии (пока она пустая):

```tsx
import { Image, Pressable, StyleSheet, Text, View } from 'react-native';

function DiceWithButtonAndImage() {
  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[1]}
        style={styles.diceImage}
        accessibilityLabel="Результат броска: 1"
      />
      <Pressable style={styles.button} onPress={() => {}}>
        <Text style={styles.buttonText}>Бросить кости</Text>
      </Pressable>
    </View>
  );
}
```

Добавьте стили изображения и кнопки:

```tsx
diceImage: {
  width: 140,
  height: 140,
  marginBottom: 32,
},
button: {
  backgroundColor: '#4A3F92',
  paddingHorizontal: 24,
  paddingVertical: 14,
  borderRadius: 12,
},
buttonText: {
  color: '#FFFFFF',
  fontSize: 18,
  fontWeight: '600',
},
```

> `accessibilityLabel` — текстовое описание изображения для программ чтения с экрана. Его нужно указывать для всех значимых изображений.

## Шаг 3. Логика броска

Результат броска — число от 1 до 6, которое должно сохраняться между перерисовками экрана. Для этого в React есть хук `useState`. Сначала напишем функцию, возвращающую случайное число:

```tsx
function rollDice(): number {
  return Math.floor(Math.random() * 6) + 1;
}
```

> `Math.random()` возвращает случайное число от 0 (включительно) до 1 (не включительно). Умножив на 6 и округлив вниз, получаем число от 0 до 5, а прибавив 1 — от 1 до 6.

Добавим состояние в компонент:

```tsx
import { useState } from 'react';

const [result, setResult] = useState(1); // объявление — внутри компонента
```

- `result` — текущее значение (какой гранью повёрнута кость), `setResult` — функция обновления.
- `useState(1)` — начальное значение равно 1.

При изменении `result` React автоматически обновит интерфейс — это называется **перерисовкой** (ререндером). Осталось связать всё вместе: при нажатии записывать в состояние случайное число, а источник изображения брать из состояния.

```tsx
function DiceWithButtonAndImage() {
  const [result, setResult] = useState(1);

  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[result]}
        style={styles.diceImage}
        accessibilityLabel={`Результат броска: ${result}`}
      />
      <Pressable style={styles.button} onPress={() => setResult(rollDice())}>
        <Text style={styles.buttonText}>Бросить кости</Text>
      </Pressable>
    </View>
  );
}
```

При каждом нажатии выполняется `setResult(rollDice())`: число записывается в состояние, и изображение меняется.

## Полный код приложения

Файл `App.tsx` целиком:

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { Image, Pressable, StyleSheet, Text, View } from 'react-native';
import type { ImageSourcePropType } from 'react-native';

const DICE_IMAGES: Record<number, ImageSourcePropType> = {
  1: require('./assets/dice/dice_1.png'),
  2: require('./assets/dice/dice_2.png'),
  3: require('./assets/dice/dice_3.png'),
  4: require('./assets/dice/dice_4.png'),
  5: require('./assets/dice/dice_5.png'),
  6: require('./assets/dice/dice_6.png'),
};

function rollDice(): number {
  return Math.floor(Math.random() * 6) + 1;
}

function DiceWithButtonAndImage() {
  const [result, setResult] = useState(1);

  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[result]}
        style={styles.diceImage}
        accessibilityLabel={`Результат броска: ${result}`}
      />
      <Pressable style={styles.button} onPress={() => setResult(rollDice())}>
        <Text style={styles.buttonText}>Бросить кости</Text>
      </Pressable>
    </View>
  );
}

export default function App() {
  return (
    <View style={styles.container}>
      <StatusBar style="auto" />
      <DiceWithButtonAndImage />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#FEEDDD', alignItems: 'center', justifyContent: 'center' },
  diceContainer: { alignItems: 'center' },
  diceImage: { width: 140, height: 140, marginBottom: 32 },
  button: { backgroundColor: '#4A3F92', paddingHorizontal: 24, paddingVertical: 14, borderRadius: 12 },
  buttonText: { color: '#FFFFFF', fontSize: 18, fontWeight: '600' },
});
```

## Резюме

- Компонент в React Native — это функция, возвращающая разметку JSX.
- Макет строится из контейнеров `View`, текст выводится через `Text`.
- Стили описываются в `StyleSheet.create` и передаются в параметр `style`.
- Изображения из папки `assets` подключаются через `require` и показываются компонентом `Image`.
- Кнопка реализуется компонентом `Pressable` с обработчиком `onPress`.
- Хук `useState` хранит изменяемые данные и автоматически обновляет интерфейс.
