# Практическая работа 10. Обработка нажатия кнопки (Lemonade)

Вы создадите приложение **Lemonade**, которое позволяет «приготовить лимонад», нажимая на изображение на экране.

### Необходимые условия

- Умение создавать макет с помощью `View`, `Text` и `Image`.
- Умение делать приложение интерактивным с помощью `Pressable` и `useState` (практическая работа 9).
- Знание условных выражений и функций TypeScript.

### Что вы узнаете

- Как по-разному обрабатывать нажатия в зависимости от состояния.
- Как показывать разные изображения и тексты для каждого этапа.
- Как генерировать случайное число нажатий.

### Что вы создадите

Приложение Lemonade, которое проводит пользователя через четыре этапа приготовления лимонада.

## Обзор приложения

| Шаг | Изображение | Текст | Действие при нажатии |
|:----|:------------|:------|:---------------------|
| 1 | Лимонное дерево | «Нажмите на лимонное дерево, чтобы выбрать лимон» | перейти к шагу 2 |
| 2 | Лимон | «Продолжайте нажимать на лимон, чтобы выжать его» | после N нажатий перейти к шагу 3 |
| 3 | Стакан лимонада | «Нажмите на лимонад, чтобы выпить» | перейти к шагу 4 |
| 4 | Пустой стакан | «Нажмите на пустой стакан, чтобы начать сначала» | вернуться к шагу 1 |

Количество нажатий, нужное для выжимания лимона (шаг 2), — случайное число от 2 до 4 включительно. Оно меняется каждый раз, когда берётся новый лимон.

## Подготовка проекта

1. Создайте проект Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest lemonade --template blank-typescript
cd lemonade
npm install
```

2. Поместите в папку `assets` четыре изображения: `lemon_tree.png`, `lemon.png`, `lemonade.png`, `empty_glass.png`.

3. Запустите приложение и откройте `App.tsx`:

```bash
npx expo start
```

Строить приложение лучше постепенно: сначала макет первого шага, затем переключение между шагами, затем оставшиеся шаги, логика выжимания лимона и, наконец, визуальная полировка.

## Шаг 1. Состояние и данные

Заведём состояние `step` — номер текущего шага. По нему приложение определяет, что показывать. Текст и изображение каждого шага опишем в объекте `STEPS`:

```tsx

import type { ImageSourcePropType } from 'react-native'

  2: { text: 'Продолжайте нажимать на лимон, чтобы выжать его', image: LEMON },
  3: { text: 'Нажмите на лимонад, чтобы выпить', image: LEMONADE },
  4: { text: 'Нажмите на пустой стакан, чтобы начать сначала', image: EMPTY_GLASS },
}

export default function App() {
  const [step, setStep] = useState(1)
  const current = STEPS[step]

  // ...
}
```

- `LEMON_TREE`, `LEMON`, `LEMONADE`, `EMPTY_GLASS` — изображения из папки `assets`.
- `STEPS` — данные каждого этапа: подсказка и изображение, `step` — номер текущего шага (начальное значение `1`).

## Шаг 2. Отрисовка экрана

Отобразим изображение и текст текущего шага:

```tsx
export default function App() {
  const [step, setStep] = useState(1)
  const current = STEPS[step]

  return (
    <View style={styles.container}>
      <Text style={styles.text}>{current.text}</Text>
      <Pressable style={styles.imageBox} onPress={handlePress}>
        <Image source={current.image} style={styles.image} />
      </Pressable>
      <StatusBar style="auto" />
    </View>
  )
}
```

- `current` — данные текущего шага; при изменении `step` берётся следующая пара «текст + изображение».
- `Pressable` охватывает изображение, поэтому нажатие на картинку запускает `handlePress`.

## Шаг 3. Логика нажатия

Определим, что происходит при нажатии. Функция `handlePress` по текущему шагу решает, куда перейти. На шаге 2 нужно нажать на лимон несколько раз, поэтому добавим два состояния: сколько раз уже нажали и сколько раз нужно (случайное число от 2 до 4):

```tsx
const [squeezeCount, setSqueezeCount] = useState(0) // сколько раз уже нажали
const [squeezeTarget, setSqueezeTarget] = useState(0) // сколько раз нужно

function handlePress() {
  if (step === 1) {
    setStep(2)
    setSqueezeCount(0)
    setSqueezeTarget(Math.floor(Math.random() * 3) + 2) // 2..4
  } else if (step === 2) {
    const newCount = squeezeCount + 1
    setSqueezeCount(newCount)
    if (newCount >= squeezeTarget) {
      setStep(3)
    }
  } else if (step === 3) {
    setStep(4)
  } else {
    setStep(1)
  }
}
```

> `Math.floor(Math.random() * 3) + 2` даёт целое число от 2 до 4. Цель генерируется при переходе с дерева на лимон, поэтому каждый новый лимон требует нового числа нажатий.

## Полный код приложения

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { Image, Pressable, StyleSheet, Text, View } from 'react-native'
import type { ImageSourcePropType } from 'react-native'

const LEMON_TREE = require('./assets/lemon_tree.png')
const LEMON = require('./assets/lemon.png')
const LEMONADE = require('./assets/lemonade.png')
const EMPTY_GLASS = require('./assets/empty_glass.png')

const STEPS: Record<number, { text: string; image: ImageSourcePropType }> = {
  1: { text: 'Нажмите на лимонное дерево, чтобы выбрать лимон', image: LEMON_TREE },
  2: { text: 'Продолжайте нажимать на лимон, чтобы выжать его', image: LEMON },
  3: { text: 'Нажмите на лимонад, чтобы выпить', image: LEMONADE },
  4: { text: 'Нажмите на пустой стакан, чтобы начать сначала', image: EMPTY_GLASS },
}

export default function App() {
  const [step, setStep] = useState(1)
  const [squeezeCount, setSqueezeCount] = useState(0)
  const [squeezeTarget, setSqueezeTarget] = useState(0)

  const current = STEPS[step]

  function handlePress() {
    if (step === 1) {
      setStep(2)
      setSqueezeCount(0)
      setSqueezeTarget(Math.floor(Math.random() * 3) + 2)
    } else if (step === 2) {
      const newCount = squeezeCount + 1
      setSqueezeCount(newCount)
      if (newCount >= squeezeTarget) {
        setStep(3)
      }
    } else if (step === 3) {
      setStep(4)
    } else {
      setStep(1)
    }
  }

  return (
    <View style={styles.container}>
      <Text style={styles.text}>{current.text}</Text>
      <Pressable
        style={styles.imageBox}
        onPress={handlePress}
        accessibilityLabel={current.text}
      >
        <Image source={current.image} style={styles.image} />
      </Pressable>
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#F7F3E8', alignItems: 'center', justifyContent: 'center', padding: 16 },
  text: { fontSize: 18, textAlign: 'center', marginBottom: 32 },
  imageBox: { borderWidth: 2, borderColor: '#69CDD8', borderRadius: 4, padding: 8 },
  image: { width: 160, height: 160, resizeMode: 'contain' },
})
```

## Резюме

- `useState` хранит состояние, которое меняется при взаимодействии.
- По значению состояния приложение решает, что показывать (условная логика).
- `Pressable` делает любой компонент интерактивным через `onPress`.
- Случайные числа генерируются через `Math.random()`.
