# Практическая работа 12. Построение сетки с прокруткой

В этой работе вы примените `FlatList` для построения **сетки** — списка, в котором элементы расположены в несколько колонок.

Вы создадите приложение **Courses** («Курсы») с нуля. Оно показывает темы курсов: изображение, название и количество связанных курсов. Сетка из карточек — распространённый приём в мобильных приложениях: экран вмещает больше информации, чем при обычном списке в одну колонку.

### Необходимые условия

- Практическая работа 11 «Список с прокруткой (Affirmations)».
- Умение использовать `FlatList`, `Image` и `StyleSheet`.

### Что вы узнаете

- Как вывести несколько колонок в `FlatList` с помощью атрибута `numColumns`.
- Как задать отступы между колонками с помощью `columnWrapperStyle`.
- Как добавить значок из набора `@expo/vector-icons`.

### Что вы создадите

Приложение **Courses** с прокручиваемой сеткой из двух колонок.

## Подготовка проекта

1. Создайте проект Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest courses --template blank-typescript
cd courses
```

2. В папке `resources` репозитория предмета найдите изображения тем (`architecture.png`, `crafts.png`, `business.png`, `culinary.png`, `design.png`, `fashion.png`, `film.png`, `gaming.png`, `drawing.png`, `lifestyle.png`, `music.png`, `painting.png`, `photography.png`, `tech.png`) и скопируйте их в папку `assets` проекта.

3. Установите библиотеку значков:

```bash
npx expo install @expo/vector-icons
```

Все изменения этой работы вносятся в файл `App.tsx`.

## Шаг 1. Модель данных

Каждая тема курса содержит три части информации. Опишем её тип:

```tsx
import type { ImageSourcePropType } from 'react-native'

type Topic = {
  title: string
  courseCount: number
  image: ImageSourcePropType
}
```

- `title` — название темы.
- `courseCount` — количество курсов в теме.

## Шаг 3. Карточка темы

Элемент сетки — карточка с изображением, значком, количеством курсов и названием. Создайте компонент `TopicCard`:

```tsx
import { MaterialCommunityIcons } from '@expo/vector-icons'
import { Image, Text, View } from 'react-native'

function TopicCard({ topic }: { topic: Topic }) {
  return (
    <View style={styles.card}>
      <Image source={topic.image} style={styles.image} />
      <View style={styles.info}>
        <View style={styles.countRow}>
          <MaterialCommunityIcons name="grain" size={16} color="#616161" />
          <Text style={styles.count}>{topic.courseCount} курсов</Text>
        </View>
        <Text style={styles.title}>{topic.title}</Text>
      </View>
    </View>
  )
}
```

- `MaterialCommunityIcons` — набор значков из библиотеки `@expo/vector-icons`; значок `grain` выполняет декоративную роль.
- Строка со значком и количеством курсов — это `View` с направлением `flexDirection: 'row'`.

Стили карточки (все стили полностью приведены на шаге 5):

```tsx
card: {
  flex: 1,
  backgroundColor: '#FFFFFF',
  borderRadius: 12,
  overflow: 'hidden',
},
image: { width: '100%', height: 112 },
info: { padding: 12 },
countRow: {
  flexDirection: 'row',
  alignItems: 'center',
  gap: 4,
},
count: { fontSize: 12, color: '#616161' },
title: { fontSize: 16, fontWeight: 'bold', marginTop: 4 },
```

- `flex: 1` заставляет карточки делить ширину строки поровну.

## Шаг 4. Сетка из двух колонок

Чтобы список стал сеткой, добавьте `FlatList` два атрибута: `numColumns` — количество колонок, и `columnWrapperStyle` — стиль ряда карточек:

```tsx
<FlatList
  data={topics}
  renderItem={({ item }) => <TopicCard topic={item} />}
  keyExtractor={(item) => item.title}
  numColumns={2}
  columnWrapperStyle={styles.row}
  contentContainerStyle={styles.list}
/>
```

- `numColumns={2}` задаёт две колонки. Попробуйте значение `3` и посмотрите, что получится.
- `columnWrapperStyle` описывает стиль **строки** сетки и работает только при `numColumns` больше единицы.
- В стилях ряда заданы `gap: 12` (отступы между карточками по горизонтали) и `marginBottom: 12` (отступы между рядами); стили `row` и `list` приведены на шаге 5.

## Шаг 5. Полный код приложения

Ниже — полный код `App.tsx`. Соберите его из шагов 1–4:

```tsx
import { MaterialCommunityIcons } from '@expo/vector-icons'
import { StatusBar } from 'expo-status-bar'
import { FlatList, Image, StyleSheet, Text, View } from 'react-native'
import type { ImageSourcePropType } from 'react-native'

type Topic = {
  title: string
  courseCount: number
  image: ImageSourcePropType
}

const topics: Topic[] = [
  { title: 'Архитектура', courseCount: 58, image: require('./assets/architecture.png') },
  { title: 'Ремёсла', courseCount: 121, image: require('./assets/crafts.png') },
  { title: 'Бизнес', courseCount: 78, image: require('./assets/business.png') },
  { title: 'Кулинария', courseCount: 118, image: require('./assets/culinary.png') },
  { title: 'Дизайн', courseCount: 423, image: require('./assets/design.png') },
  { title: 'Мода', courseCount: 92, image: require('./assets/fashion.png') },
  { title: 'Кино', courseCount: 165, image: require('./assets/film.png') },
  { title: 'Игры', courseCount: 164, image: require('./assets/gaming.png') },
  { title: 'Рисование', courseCount: 326, image: require('./assets/drawing.png') },
  { title: 'Стиль жизни', courseCount: 305, image: require('./assets/lifestyle.png') },
  { title: 'Музыка', courseCount: 212, image: require('./assets/music.png') },
  { title: 'Живопись', courseCount: 172, image: require('./assets/painting.png') },
  { title: 'Фотография', courseCount: 321, image: require('./assets/photography.png') },
  { title: 'Технологии', courseCount: 118, image: require('./assets/tech.png') },
]

function TopicCard({ topic }: { topic: Topic }) {
  return (
    <View style={styles.card}>
      <Image source={topic.image} style={styles.image} />
      <View style={styles.info}>
        <View style={styles.countRow}>
          <MaterialCommunityIcons name="grain" size={16} color="#616161" />
          <Text style={styles.count}>{topic.courseCount} курсов</Text>
        </View>
        <Text style={styles.title}>{topic.title}</Text>
      </View>
    </View>
  )
}

export default function App() {
  return (
    <View style={styles.container}>
      <FlatList
        data={topics}
        renderItem={({ item }) => <TopicCard topic={item} />}
        keyExtractor={(item) => item.title}
        numColumns={2}
        columnWrapperStyle={styles.row}
        contentContainerStyle={styles.list}
      />
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#F5F5F5',
  },
  list: { padding: 16 },
  row: {
    gap: 12,
    marginBottom: 12,
  },
  card: {
    flex: 1,
    backgroundColor: '#FFFFFF',
    borderRadius: 12,
    overflow: 'hidden',
  },
  image: { width: '100%', height: 112 },
  info: { padding: 12 },
  countRow: {
    flexDirection: 'row',
    alignItems: 'center',
    gap: 4,
  },
  count: { fontSize: 12, color: '#616161' },

})
```

## Резюме

- `numColumns` превращает `FlatList` в сетку.
- `flex: 1` у карточки и `columnWrapperStyle` делают колонки одинаковыми и ровными.
- `columnWrapperStyle` применяется только при `numColumns` больше единицы.
- Значки из `@expo/vector-icons` добавляются установкой пакета и компонентом нужного набора.
