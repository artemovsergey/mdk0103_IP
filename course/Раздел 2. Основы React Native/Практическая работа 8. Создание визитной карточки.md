# Практическая работа 8. Создание визитной карточки

В этой работе вы создадите приложение «Визитная карточка»: экран с фотографией, именем, профессией и контактными данными. В отличие от предыдущих работ, здесь больше решений вы принимаете сами — цвета, отступы и содержимое карточки вы подберёте на свой вкус.

### Необходимые условия

- Лекции 11 и 12 «Введение в React Native» и «Добавление изображений».
- Умение выводить текст и изображения и оформлять их с помощью `StyleSheet`.
- Умение располагать элементы с помощью flexbox.

### Что вы узнаете

- Как строить макет из отдельных компонентов.
- Как располагать элементы в ряд (`flexDirection: 'row'`) и в колонку.
- Как оформлять блоки отступами, рамками и скруглениями.
- Как передавать данные в компонент через параметры.

### Что вы создадите

Приложение «Визитная карточка» с фотографией, именем, профессией и списком контактов.

## Подготовка проекта

1. Создайте проект Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest business-card --template blank-typescript
cd business-card
```

2. Подготовьте изображение для карточки: положите своё фото `photo.png` в папку `assets` проекта. Если фотографии нет, используйте значок из шаблона `assets/icon.png`.

3. Запустите приложение:

```bash
npx expo start
```

Откройте приложение клавишей `w` в браузере или отсканируйте QR-код приложением Expo Go. Все изменения этой работы вносятся в файл `App.tsx`.

## Шаг 1. Эскиз карточки

Когда вы начинаете новый проект, полезно сначала представить, как элементы интерфейса сочетаются друг с другом. Нарисуйте карточку на бумаге: фото, имя, профессия, контакты. Не бойтесь менять эскиз — в коде легко поправить любую деталь.

Разделим экран на две части:

- Верхняя — фотография, имя и профессия.
- Нижняя — контактные данные.

Каждую часть оформим отдельным блоком `View`, а строки контактов — повторно используемым компонентом.

## Шаг 2. Данные визитки

Опишем изображение и контакты. Данные, которые не меняются, объявляем вне компонента `App`:

```tsx
const photo = require('./assets/photo.png')

type Contact = {
  label: string
  value: string
}

const CONTACTS: Contact[] = [
  { label: 'Телефон', value: '+7 900 123-45-67' },
  { label: 'Почта', value: 'ivanov@example.com' },
  { label: 'Telegram', value: '@ivanov' },
]
```

- `photo` — источник изображения для компонента `Image`.
- `Contact` — тип контактной строки: подпись и значение.
- `CONTACTS` — массив контактов. Впишите свои данные.

## Шаг 3. Компонент контактной строки

Каждый контакт выглядит одинаково: слева подпись, справа значение. Опишем это отдельным компонентом `ContactRow`:

```tsx
function ContactRow({ contact }: { contact: Contact }) {
  return (
    <View style={styles.contactRow}>
      <Text style={styles.contactLabel}>{contact.label}</Text>
      <Text style={styles.contactValue}>{contact.value}</Text>
    </View>
  )
}
```

- Компонент принимает один контакт и возвращает разметку строки.
- `flexDirection: 'row'` (добавим в стилях) расположит подпись и значение по горизонтали, а `justifyContent: 'space-between'` разведёт их по краям.

## Шаг 4. Полный код приложения

Ниже — полный код `App.tsx`. Соберите его из шагов 2–3:

```tsx
import { StatusBar } from 'expo-status-bar'
import { Image, StyleSheet, Text, View } from 'react-native'

const photo = require('./assets/photo.png')

type Contact = {
  label: string
  value: string
}

const CONTACTS: Contact[] = [
  { label: 'Телефон', value: '+7 900 123-45-67' },
  { label: 'Почта', value: 'ivanov@example.com' },
  { label: 'Telegram', value: '@ivanov' },
]

function ContactRow({ contact }: { contact: Contact }) {
  return (
    <View style={styles.contactRow}>
      <Text style={styles.contactLabel}>{contact.label}</Text>
      <Text style={styles.contactValue}>{contact.value}</Text>
    </View>
  )
}

export default function App() {
  return (
    <View style={styles.screen}>
      <View style={styles.card}>
        <Image source={photo} style={styles.photo} accessibilityLabel="Фотография владельца визитки" />
        <Text style={styles.name}>Александр Иванов</Text>
        <Text style={styles.role}>Разработчик мобильных приложений</Text>
      </View>

      <View style={styles.contacts}>
        {CONTACTS.map((contact) => (
          <ContactRow key={contact.label} contact={contact} />
        ))}
      </View>

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: {
    flex: 1,
    backgroundColor: '#EDE7F6',
    alignItems: 'center',
    justifyContent: 'center',
    padding: 24,
  },
  card: {
    alignItems: 'center',
    backgroundColor: '#FFFFFF',
    borderRadius: 24,
    padding: 32,
    width: '100%',
    marginBottom: 24,
  },
  photo: {
    width: 120,
    height: 120,
    borderRadius: 60,
    marginBottom: 16,
  },
  name: {
    fontSize: 24,
    fontWeight: 'bold',
    marginBottom: 4,
  },
  role: {
    fontSize: 16,
    color: '#666666',
  },
  contacts: {
    backgroundColor: '#FFFFFF',
    borderRadius: 16,
    padding: 16,
    width: '100%',
    gap: 12,
  },
  contactRow: {
    flexDirection: 'row',
    justifyContent: 'space-between',
  },
  contactLabel: {
    fontSize: 16,
    color: '#666666',
  },
  contactValue: {
    fontSize: 16,
    fontWeight: '600',
  },
})
```

- `styles.card` — белая карточка со скруглёнными углами; `alignItems: 'center'` центрирует фото и тексты.
- `borderRadius: 60` у фотографии делает её круглой (половина от ширины и высоты).
- `CONTACTS.map(...)` создаёт строку контактов для каждого элемента массива; `key` помогает React отличать элементы списка.

## Резюме

- Макет удобно собирать из отдельных блоков `View` и собственных компонентов.
- `flexDirection: 'row'` и `justifyContent: 'space-between'` располагают элементы по горизонтали.
- `borderRadius`, `padding` и `backgroundColor` оформляют блоки.
- Данные передаются в компонент через параметры, а массив контактов выводится с помощью `map`.
