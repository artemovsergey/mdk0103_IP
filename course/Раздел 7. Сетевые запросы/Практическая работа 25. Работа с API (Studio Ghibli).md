### Что вы создадите

## API студии Ghibli

Список фильмов отдаёт открытый API студии Ghibli по адресу:

```tsx
const API_URL = 'https://ghibliapi.vercel.app/films'
```

Ответ — плоский JSON-массив объектов (в отличие от вложенной структуры архива NASA из практической работы 24, преобразование не потребуется):

```json
[
  {
    "id": "2baf70d1-42bb-4437-b551-e5fed5a87abe",
    "title": "Castle in the Sky",
    "director": "Hayao Miyazaki",
    "description": "The orphan Sheeta inherited a mysterious crystal that links her to the mythical sky-kingdom of Laputa...",
    "image": "https://image.tmdb.org/t/p/w600_and_h900_bestv2/npOnzAbLh6VOIu3naU5QaEcTepo.jpg"
  }
]
```

- `id` — идентификатор фильма (строка);
- `title` — название;
- `director` — режиссёр;
- `description` — описание;
- `image` — адрес постера.

Кроме них сервис отдаёт и другие поля — например, `release_date` (год выпуска) и `rt_score` (рейтинг). Поле `id` уникально, поэтому именно его используем ключом элемента списка.

```tsx
type Film = {
  id: string

  director: string
  description: string
  image: string
}
```

Названия полей должны совпадать с именами полей в JSON — тогда разбор ответа пройдёт без дополнительных преобразований.

## Шаг 3. Состояния экрана и загрузка данных

Для загрузки из сети нужны три состояния: данные (`films`), признак загрузки (`loading`) и текст ошибки (`error`). Запрос выполняет асинхронная функция: перед запросом сбрасываем прошлую ошибку и включаем индикатор, а в `finally` выключаем его в любом случае:

```tsx
const [films, setFilms] = useState<Film[]>([])
const [loading, setLoading] = useState(true)
const [error, setError] = useState('')

const loadFilms = async () => {
  setLoading(true)
  setError('')

  try {
    const response = await fetch(API_URL)

    if (!response.ok) {
      throw new Error(`Сервер вернул код ${response.status}`)
    }

    const data = (await response.json()) as Film[]
    setFilms(data)
  } catch (e) {
    setError(e instanceof Error ? e.message : 'Не удалось загрузить данные')
  } finally {
    setLoading(false)
  }
}
```

Такая же схема использовалась в практической работе 20 — теперь вы применяете её к новому API.

## Шаг 4. Экран со списком

Один фильм оформлен отдельным компонентом `FilmCard`: сверху постер, под ним название, режиссёр и описание — его код есть в полном листинге. Экран показывает ровно одно из трёх состояний: индикатор, ошибку с кнопкой повтора или список:

```tsx
{loading && <ActivityIndicator size="large" color="#0057B8" style={styles.loader} />}

{!loading && error !== '' && (
  <View style={styles.center}>
    <Text style={styles.error}>{error}</Text>
    <Button title="Повторить" onPress={loadFilms} />
  </View>
)}

{!loading && error === '' && (
  <FlatList
    data={films}
    keyExtractor={(item) => item.id}
    renderItem={({ item }) => <FilmCard film={item} />}
  />
)}
```

Кнопка «Повторить» вызывает ту же функцию загрузки, что и при открытии экрана.

## Шаг 5. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { ActivityIndicator, Button, FlatList, Image, StyleSheet, Text, View } from 'react-native'

type Film = {
  id: string
  title: string
  director: string
  description: string
  image: string
}

const API_URL = 'https://ghibliapi.vercel.app/films'

function FilmCard({ film }: { film: Film }) {
  return (
    <View style={styles.card}>
      <Image source={{ uri: film.image }} style={styles.image} />
      <View style={styles.cardBody}>
        <Text style={styles.filmTitle}>{film.title}</Text>
        <Text style={styles.director}>{film.director}</Text>
        <Text style={styles.description} numberOfLines={4}>
          {film.description}
        </Text>
      </View>
    </View>
  )
}

export default function App() {
  const [films, setFilms] = useState<Film[]>([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState('')

  const loadFilms = async () => {
    setLoading(true)
    setError('')

    try {
      const response = await fetch(API_URL)

      if (!response.ok) {
        throw new Error(`Сервер вернул код ${response.status}`)
      }

      const data = (await response.json()) as Film[]
      setFilms(data)
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Не удалось загрузить данные')
    } finally {
      setLoading(false)
    }
  }

  useEffect(() => {
    loadFilms()
  }, [])

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Studio Ghibli</Text>
      <Text style={styles.subtitle}>Данные получены из открытого API</Text>

      {loading && <ActivityIndicator size="large" color="#0057B8" style={styles.loader} />}

      {!loading && error !== '' && (
        <View style={styles.center}>
          <Text style={styles.error}>{error}</Text>
          <Button title="Повторить" onPress={loadFilms} />
        </View>
      )}

      {!loading && error === '' && (
        <FlatList
          data={films}
          keyExtractor={(item) => item.id}
          contentContainerStyle={styles.list}
          renderItem={({ item }) => <FilmCard film={item} />}
        />
      )}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 48, paddingHorizontal: 16 },
  title: { fontSize: 24, fontWeight: 'bold' },
  subtitle: { color: '#555555', marginBottom: 12 },
  loader: { marginTop: 32 },
  center: { alignItems: 'center', gap: 12, marginTop: 32 },
  error: { color: '#C62828', textAlign: 'center' },
  list: { paddingBottom: 24 },
  card: { backgroundColor: '#FFFFFF', borderRadius: 12, marginBottom: 12, overflow: 'hidden' },
  image: { width: '100%', height: 180, backgroundColor: '#E0E0E0' },
  cardBody: { padding: 12, gap: 4 },
  filmTitle: { fontSize: 18, fontWeight: 'bold' },
  director: { color: '#0057B8', fontSize: 14 },
  description: { color: '#444444', lineHeight: 20 },
})
```

## Резюме

- С новым API работают по той же схеме: адрес, тип ответа, запрос, состояния экрана.
- Названия полей типа TypeScript повторяют имена полей JSON-ответа.
- Данные передаются элементам списка через свойства; кнопка повтора вызывает ту же функцию загрузки.
- `try` / `catch` / `finally` разделяют успех, ошибку и завершение загрузки.
