# Практическая работа 26. Создание приложения Книжная полка

В этой работе вы создадите приложение **Книжная полка**: поиск книг по названию и список карточек с обложками. Данные приходят из открытой базы **Open Library** — публичного API, который не требует регистрации и ключей.

### Пререквизиты

- Практические работы 24 и 25 «Загрузка и отображение изображений» и «Работа с API».
- Умение выполнять запрос через `fetch` и обрабатывать состояния загрузки и ошибки.
- Умение выводить списки через `FlatList` и изображения через `Image`.

### Что вы узнаете

- Как передавать параметры запроса: поисковую строку, лимит и список полей.
- Как кодировать текст запроса функцией `encodeURIComponent`.
- Как показать карточку книги с обложкой, автором и годом издания.
- Как отличать пустой результат поиска от ситуации, когда поиск ещё не выполнялся.

### Что вы создадите

Приложение **Книжная полка** с полем поиска, кнопкой «Найти» и списком карточек книг: обложка, название, автор и год первого издания.

## Как устроен поиск в Open Library

Адрес поиска состоит из базового пути и параметров после знака `?`:

`https://openlibrary.org/search.json?q=harry+potter&limit=20&fields=key,title,author_name,cover_i,first_publish_year`

- `q` — поисковый запрос (название книги, автор);
- `limit=20` — сколько результатов вернуть;
- `fields` — какие поля нужны; без него сервер присылает десятки лишних полей, и ответ становится очень большим.

Ответ — объект с массивом `docs`:

```json
{
  "numFound": 4063,
  "docs": [
    { "key": "/works/OL82563W", "title": "Harry Potter and the Philosopher's Stone", "author_name": ["J. K. Rowling"], "cover_i": 15155833, "first_publish_year": 1997 }
  ]
}
```

- `key` — идентификатор книги (подойдёт как ключ списка); `title` — название;
- `author_name` — массив авторов; `cover_i` — номер обложки; `first_publish_year` — год первого издания (эти поля могут отсутствовать).

Обложка по номеру строится отдельным адресом: `https://covers.openlibrary.org/b/id/15155833-M.jpg`.

## Шаг 2. Типы и состояния

Опишем книгу и ответ сервера; необязательные поля помечаем знаком `?`: `author_name`, `cover_i` и `first_publish_year` могут отсутствовать в ответе. TypeScript заставит проверить их перед использованием — иначе приложение упадёт на книге без обложки или автора.

Состояние `books` хранит результат поиска: `null` означает «поиск ещё не выполнялся», пустой массив — «ничего не найдено». Так приложение различает эти две ситуации. Типы и состояния объявлены в полном листинге ниже.

## Шаг 3. Функция поиска

В адрес подставляем текст запроса, закодированный через `encodeURIComponent`: пробелы и русские буквы нельзя помещать в адрес напрямую. Параметр `fields` сокращает ответ до нужных полей:

```tsx
const SEARCH_URL = 'https://openlibrary.org/search.json'
const COVERS_URL = 'https://covers.openlibrary.org/b/id'

async function searchBooks(query: string): Promise<Book[]> {
  const url =
    `${SEARCH_URL}?q=${encodeURIComponent(query)}` +
    '&limit=20&fields=key,title,author_name,cover_i,first_publish_year'
  const response = await fetch(url)

  if (!response.ok) {
    throw new Error(`Сервер вернул код ${response.status}`)
  }

  const data = (await response.json()) as SearchResponse
  return data.docs
}
```

## Шаг 4. Обработчик и экран

Обработчик проверяет, что строка не пустая (`query.trim()` убирает пробелы по краям), включает индикатор, вызывает `searchBooks` и раскладывает результат по состояниям. В `catch` список сбрасывается, а ошибка показывается пользователю.

Экран показывает ровно одно из состояний: индикатор, ошибку с кнопкой «Повторить», сообщение «Ничего не найдено» или список. Обложка есть не у всех книг: если номера `cover_i` нет, показывается серая заглушка, а несколько авторов собираются в строку через `join(', ')`.

## Шаг 5. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { ActivityIndicator, FlatList, Image, Pressable, StyleSheet, Text, TextInput, View } from 'react-native'

type Book = {
  key: string
  title: string
  author_name?: string[]
  cover_i?: number
  first_publish_year?: number
}

type SearchResponse = {
  docs: Book[]
}

const SEARCH_URL = 'https://openlibrary.org/search.json'
const COVERS_URL = 'https://covers.openlibrary.org/b/id'

async function searchBooks(query: string): Promise<Book[]> {
  const url =
    `${SEARCH_URL}?q=${encodeURIComponent(query)}` +
    '&limit=20&fields=key,title,author_name,cover_i,first_publish_year'
  const response = await fetch(url)

  if (!response.ok) {
    throw new Error(`Сервер вернул код ${response.status}`)
  }

  const data = (await response.json()) as SearchResponse
  return data.docs
}

function BookCard({ book }: { book: Book }) {
  return (
    <View style={styles.card}>
      {book.cover_i ? (
        <Image source={{ uri: `${COVERS_URL}/${book.cover_i}-M.jpg` }} style={styles.cover} />
      ) : (
        <View style={[styles.cover, styles.coverPlaceholder]}>
          <Text style={styles.coverPlaceholderText}>Нет обложки</Text>
        </View>
      )}
      <View style={styles.cardBody}>
        <Text style={styles.bookTitle}>{book.title}</Text>
        <Text style={styles.author}>{book.author_name ? book.author_name.join(', ') : 'Автор неизвестен'}</Text>
        <Text style={styles.year}>{book.first_publish_year ? `Первое издание: ${book.first_publish_year}` : 'Год издания неизвестен'}</Text>
      </View>
    </View>
  )
}

export default function App() {
  const [query, setQuery] = useState('')
  const [books, setBooks] = useState<Book[] | null>(null)
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState('')
  const handleSearch = async () => {
    const text = query.trim()
    if (text === '') {
      setError('Введите название книги')
      return
    }

    setLoading(true)
    setError('')
    try {
      const result = await searchBooks(text)
      setBooks(result)
    } catch (e) {
      setBooks(null)
      setError(e instanceof Error ? e.message : 'Не удалось загрузить книги')
    } finally {
      setLoading(false)
    }
  }

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Книжная полка</Text>

      <View style={styles.searchRow}>
        <TextInput
          style={styles.input}
          value={query}
          onChangeText={setQuery}
          placeholder="Например, мастер и маргарита"
          onSubmitEditing={handleSearch}
        />
        <Pressable style={styles.button} onPress={handleSearch} disabled={loading}>
          <Text style={styles.buttonText}>Найти</Text>
        </Pressable>
      </View>

      {loading && <ActivityIndicator size="large" color="#0057B8" style={styles.loader} />}

      {!loading && error !== '' && (
        <View style={styles.center}>
          <Text style={styles.error}>{error}</Text>
          <Pressable style={styles.button} onPress={handleSearch}>
            <Text style={styles.buttonText}>Повторить</Text>
          </Pressable>
        </View>
      )}

      {!loading && error === '' && books !== null && (
        <FlatList
          data={books}
          keyExtractor={(item) => item.key}
          renderItem={({ item }) => <BookCard book={item} />}
          ListEmptyComponent={
            <Text style={styles.message}>Ничего не найдено. Измените запрос.</Text>
          }
        />
      )}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 48, paddingHorizontal: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 12 },
  searchRow: { flexDirection: 'row', gap: 8, marginBottom: 16 },
  input: { flex: 1, backgroundColor: '#FFFFFF', borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, paddingHorizontal: 12, paddingVertical: 10, fontSize: 16 },
  button: { backgroundColor: '#0057B8', borderRadius: 8, paddingHorizontal: 20, justifyContent: 'center', minHeight: 44 },
  buttonText: { color: '#FFFFFF', fontSize: 16, fontWeight: 'bold' },
  loader: { marginTop: 32 },
  center: { alignItems: 'center', gap: 12, marginTop: 32 },
  error: { color: '#C62828', textAlign: 'center' },
  message: { color: '#555555', textAlign: 'center' },
  card: { flexDirection: 'row', backgroundColor: '#FFFFFF', borderRadius: 12, marginBottom: 12, padding: 12, gap: 12 },
  cover: { width: 64, height: 96, borderRadius: 6, backgroundColor: '#E0E0E0' },
  coverPlaceholder: { alignItems: 'center', justifyContent: 'center', padding: 4 },
  coverPlaceholderText: { color: '#777777', fontSize: 12, textAlign: 'center' },
  cardBody: { flex: 1, gap: 4 },
  bookTitle: { fontSize: 16, fontWeight: 'bold' },
  author: { color: '#444444' },
  year: { color: '#777777', fontSize: 13 },
})
```

Разберём ключевые моменты:

- кнопка «Повторить» вызывает `handleSearch` — повторный запрос с тем же текстом;
- `keyExtractor` использует `item.key` — идентификатор книги из ответа;
- `ListEmptyComponent` показывает сообщение, когда массив `books` пуст, а `null` в начале означает, что поиск ещё не выполнялся.

## Резюме

- Параметры запроса передаются после знака `?`; поисковую строку кодируют через `encodeURIComponent`.
- Параметр `fields` сокращает ответ API до нужных полей, а необязательные поля описывают знаком `?` и проверяют перед выводом.
