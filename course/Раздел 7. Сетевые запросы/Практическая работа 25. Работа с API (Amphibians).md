### Что вы создадите

Приложение **Amphibians** — список карточек земноводных с изображением, названием, видом и описанием, загруженных с веб-сервиса.

## API земноводных

Данные о земноводных отдаёт учебный веб-сервис по адресу:

```tsx
const API_URL = 'https://android-kotlin-fun-mars-server.appspot.com/amphibians'
```

Ответ — JSON-массив объектов:

```json
[
  {
    "name": "Great Basin Spadefoot",
    "type": "Toad",
    "description": "This toad spends most of its life underground.",
    "img_src": "https://developer.android.com/.../great-basin-spadefoot.png"
  }
]
```

- `name` — название животного;
- `type` — вид (жаба, лягушка и тому подобное);
- `description` — описание;
- `img_src` — адрес изображения.

Поля `id` в ответе нет, поэтому ключом элемента списка станет название: в этих данных оно уникально.

## Шаг 2. Тип данных

Опишем тип, соответствующий ответу сервиса:

```tsx
type Amphibian = {
  name: string
  type: string
  description: string
  img_src: string
}
```

Названия полей должны совпадать с именами полей в JSON — тогда разбор ответа пройдёт без дополнительных преобразований.

## Шаг 3. Состояния экрана и загрузка данных

Для загрузки из сети нужны три состояния: данные (`amphibians`), признак загрузки (`loading`) и текст ошибки (`error`). Запрос выполняет асинхронная функция: перед запросом сбрасываем прошлую ошибку и включаем индикатор, а в `finally` выключаем его в любом случае:

```tsx
const [amphibians, setAmphibians] = useState<Amphibian[]>([])
const [loading, setLoading] = useState(true)
const [error, setError] = useState('')

const loadAmphibians = async () => {
  setLoading(true)
  setError('')

  try {
    const response = await fetch(API_URL)

    if (!response.ok) {
      throw new Error(`Сервер вернул код ${response.status}`)
    }

    const data = (await response.json()) as Amphibian[]
    setAmphibians(data)
  } catch (e) {
    setError(e instanceof Error ? e.message : 'Не удалось загрузить данные')
  } finally {
    setLoading(false)
  }
}
```

Такая же схема использовалась в практической работе 20 — теперь вы применяете её к новому API.

## Шаг 4. Экран со списком

Один житель списка оформлен отдельным компонентом `AmphibianCard`: сверху изображение, под ним название, вид и описание — его код есть в полном листинге. Экран показывает ровно одно из трёх состояний: индикатор, ошибку с кнопкой повтора или список:

```tsx
{loading && <ActivityIndicator size="large" color="#0057B8" style={styles.loader} />}

{!loading && error !== '' && (
  <View style={styles.center}>
    <Text style={styles.error}>{error}</Text>
    <Button title="Повторить" onPress={loadAmphibians} />
  </View>
)}

{!loading && error === '' && (
  <FlatList
    data={amphibians}
    keyExtractor={(item) => item.name}
    renderItem={({ item }) => <AmphibianCard amphibian={item} />}
  />
)}
```

Кнопка «Повторить» вызывает ту же функцию загрузки, что и при открытии экрана.

## Шаг 5. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { ActivityIndicator, Button, FlatList, Image, StyleSheet, Text, View } from 'react-native'

type Amphibian = {
  name: string
  type: string
  description: string
  img_src: string
}

const API_URL = 'https://android-kotlin-fun-mars-server.appspot.com/amphibians'

function AmphibianCard({ amphibian }: { amphibian: Amphibian }) {
  return (
    <View style={styles.card}>
      <Image source={{ uri: amphibian.img_src }} style={styles.image} />
      <View style={styles.cardBody}>
        <Text style={styles.name}>{amphibian.name}</Text>
        <Text style={styles.type}>{amphibian.type}</Text>
        <Text style={styles.description}>{amphibian.description}</Text>
      </View>
    </View>
  )
}

export default function App() {
  const [amphibians, setAmphibians] = useState<Amphibian[]>([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState('')

  const loadAmphibians = async () => {
    setLoading(true)
    setError('')

    try {
      const response = await fetch(API_URL)

      if (!response.ok) {
        throw new Error(`Сервер вернул код ${response.status}`)
      }

      const data = (await response.json()) as Amphibian[]
      setAmphibians(data)
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Не удалось загрузить данные')
    } finally {
      setLoading(false)
    }
  }

  useEffect(() => {
    loadAmphibians()
  }, [])

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Земноводные</Text>
      <Text style={styles.subtitle}>Данные получены из открытого API</Text>

      {loading && <ActivityIndicator size="large" color="#0057B8" style={styles.loader} />}

      {!loading && error !== '' && (
        <View style={styles.center}>
          <Text style={styles.error}>{error}</Text>
          <Button title="Повторить" onPress={loadAmphibians} />
        </View>
      )}

      {!loading && error === '' && (
        <FlatList
          data={amphibians}
          keyExtractor={(item) => item.name}
          contentContainerStyle={styles.list}
          renderItem={({ item }) => <AmphibianCard amphibian={item} />}
        />
      )}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 48, paddingHorizontal: 16 },
  title: { fontSize: 24, fontWeight: 'bold' },
  subtitle: { color: '#555555', marginBottom: 12 },
  loader: { marginTop: 32 },
  center: { alignItems: 'center', gap: 12, marginTop: 32 },
  error: { color: '#C62828', textAlign: 'center' },
  list: { paddingBottom: 24 },
  card: { backgroundColor: '#FFFFFF', borderRadius: 12, marginBottom: 12, overflow: 'hidden' },
  image: { width: '100%', height: 180, backgroundColor: '#E0E0E0' },
  cardBody: { padding: 12, gap: 4 },
  name: { fontSize: 18, fontWeight: 'bold' },
  type: { color: '#0057B8', fontSize: 14 },
  description: { color: '#444444', lineHeight: 20 },
})
```

## Резюме

- С новым API работают по той же схеме: адрес, тип ответа, запрос, состояния экрана.
- Названия полей типа TypeScript повторяют имена полей JSON-ответа.
- Данные передаются элементам списка через свойства; кнопка повтора вызывает ту же функцию загрузки.
- `try` / `catch` / `finally` разделяют успех, ошибку и завершение загрузки.
