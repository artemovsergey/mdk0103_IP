## Теоретическая часть

### Условные выражения if/else
Конструкция `if/else` позволяет выполнять различные блоки кода в зависимости от условия:

```ts
if (условие) {
  // код, если условие истинно
} else {
  // код, если условие ложно
}
```

Условие - это выражение, которое даёт `true` или `false`. Например:

```ts
const temperature = 25

if (temperature > 20) {
  console.log("На улице тепло")
} else {
  console.log("На улице прохладно")
}
```

### Операторы сравнения
| Оператор | Значение |
|:--|:--|
| `===` | равно |
| `!==` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

В TypeScript сравнение записывают через `===`, а не через `==`: строгое равенство не выполняет неожиданных преобразований типов.

### Логические операторы
Несколько условий можно объединять:

```ts
const age = 20
const isBlocked = false

if (age >= 18 && age < 65) console.log("Взрослый пользователь") // && - «и»
if (age < 7 || age > 70) console.log("Льготная категория")       // || - «или»
if (!isBlocked) console.log("Доступ разрешён")                   // ! - «не»
```

### Цепочка else if
Когда вариантов больше двух, используют цепочку `else if`:

```ts
function timeOfDay(hour: number): string {
  if (hour < 6) return "Ночь"
  if (hour < 12) return "Утро"
  if (hour < 18) return "День"
  if (hour < 24) return "Вечер"
  return "Неверное время"
}
```

Как только одно из условий выполняется, функция возвращает результат и остальные проверки пропускаются.

### Множественное ветвление с switch
Конструкция `switch` заменяет длинную цепочку `else if`, когда сравнивается одно значение:

```ts
switch (dayOfWeek) {
  case 1:
    console.log("Понедельник")
    break
  case 2:
    console.log("Вторник")
    break
  default:
    console.log("Другой день")
}
```

- `case` - одно из возможных значений;
- `break` завершает `switch`, иначе выполнение продолжится со следующего `case`;
- `default` срабатывает, если ни один `case` не подошёл.

Несколько значений можно объединить в один `case`, перечислив их подряд.

### Тернарный оператор
Если нужно выбрать одно из двух значений, удобен тернарный оператор:

```ts
const x = 5
const result = x > 0 ? "Positive" : "Negative"
console.log(result) // Positive
```

### Оператор нулевого слияния ??
Если значение может быть `null` или `undefined`, используют `??` - он подставляет запасное значение:

```ts
const userName: string | null = null
console.log(userName ?? "Гость") // Гость
```

## Практический пример

**Задача:** написать программу, которая определяет время суток по заданному часу.

**Шаг 1.** Создайте папку проекта и файл `main.ts`:

```bash
cd C:\Projects
mkdir pr02-conditions
cd pr02-conditions
```

**Шаг 2.** Запишите в `main.ts` код:

```ts
// Функция определяет время суток по часу (от 0 до 23)
function timeOfDay(hour: number): string {
  if (hour < 0 || hour > 23) return "Неверное время"
  if (hour < 6) return "Ночь"
  if (hour < 12) return "Утро"
  if (hour < 18) return "День"
  return "Вечер"
}

const hour = 14
console.log(`Сейчас ${hour} ч. - ${timeOfDay(hour)}`)
```

**Шаг 3.** Запустите программу:

```bash
node main.ts
```

**Вывод:**

```
Сейчас 14 ч. - День
```

**Шаг 4.** Измените значение `hour` на `3`, затем на `25` и запустите программу снова. Убедитесь, что для неверного часа выводится сообщение «Неверное время».

## Резюме
- Конструкция `if/else` выполняет разные блоки кода в зависимости от условия.
- Несколько условий объединяются операторами `&&`, `||` и `!`.
- Сравнивать значения принято строгим равенством `===`.
- `switch` удобен, когда сравнивается одно значение с несколькими вариантами.
- Тернарный оператор выбирает одно из двух значений, а `??` подставляет запасное значение вместо `null` или `undefined`.
- Для проверки диапазона удобно использовать цепочку `else if` с возвратом результата.
