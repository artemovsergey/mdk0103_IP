# Практическая работа 6. Асинхронность в TypeScript

До сих пор программы выполнялись строго по порядку: одна строка за другой. Такой код называется **синхронным**. Но в приложениях часто нужно выполнять долгие операции - запрос к серверу, чтение файла, загрузку данных, - не «замораживая» программу на время ожидания. Для этого используется **асинхронное программирование**. На этой практической работе вы научитесь работать с `Promise`, `async`/`await` и запускать задачи параллельно.

## Тема
Основы асинхронного программирования в TypeScript: `setTimeout`, `Promise`, `async`/`await`, обработка ошибок, параллельное выполнение.

## Цель
Научиться писать асинхронный код на TypeScript: откладывать выполнение задач, работать с `Promise`, обрабатывать ошибки через `try/catch` и запускать несколько задач одновременно.

## Теоретическая часть

### setTimeout и асинхронность
Асинхронная операция не блокирует выполнение остального кода. Функция `setTimeout` откладывает выполнение функции на заданное время (в миллисекундах):

```ts
console.log("Начало")

setTimeout(() => {
  console.log("Прошло 2 секунды")
}, 2000)

console.log("Конец")
```

Вывод:

```
Начало
Конец
Прошло 2 секунды
```

Обратите внимание: «Конец» печатается **до** сообщения внутри `setTimeout`, хотя в коде он стоит после. Программа не ждёт завершения отложенной задачи, а продолжает выполняться дальше.

Отменить отложенную задачу можно функцией `clearTimeout`.

### Promise
**Promise** (обещание) - это объект, представляющий результат операции, которая завершится в будущем. У Promise есть два возможных исхода:

- **успех** (fulfilled) - операция завершилась с результатом;
- **ошибка** (rejected) - операция завершилась неудачей.

Создадим функцию, возвращающую Promise:

```ts
function fetchData(): Promise<string> {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Данные получены"), 1000)
  })
}
```

- `new Promise(...)` создаёт Promise;
- `resolve(значение)` сообщает, что операция завершилась успешно, и передаёт результат;
- `reject(ошибка)` сообщает, что операция завершилась неудачей.

### async и await
Ключевое слово `await` заставляет функцию дождаться завершения Promise, а `async` помечает функцию, внутри которой можно использовать `await`:

```ts
async function main(): Promise<void> {
  console.log("Загрузка...")
  const data = await fetchData()
  console.log(data)
}

main()
```

Вывод:

```
Загрузка...
Данные получены
```

- `async function` - объявление асинхронной функции;
- `await fetchData()` - «подожди, пока Promise завершится, и верни результат»;
- асинхронная функция всегда возвращает Promise.

### Обработка ошибок: try/catch
Если асинхронная операция может завершиться ошибкой, её ловят конструкцией `try/catch`:

```ts
function fetchWithError(): Promise<string> {
  return new Promise((resolve, reject) => {
    setTimeout(() => reject("Сервер недоступен"), 1000)
  })
}

async function main(): Promise<void> {
  try {
    console.log(await fetchWithError())
  } catch (error) {
    console.log(`Ошибка: ${error}`)
  }
}
```

Вывод:

```
Ошибка: Сервер недоступен
```

### Параллельное выполнение: Promise.all
Иногда нужно запустить несколько независимых задач одновременно и дождаться их всех. Для этого используется `Promise.all`:

```ts
async function main(): Promise<void> {
  const [a, b] = await Promise.all([fetchData(), fetchData()])
  console.log(a, b)
}

main()
```

Обе задачи запускаются одновременно, а `await` дожидается их завершения. Если хотя бы один Promise завершится ошибкой, `Promise.all` также завершится ошибкой.

`Promise.race` возвращает результат первого завершившегося Promise - его используют для ограничения времени ожидания.

## Практический пример

**Задача:** имитировать параллельное скачивание двух файлов и вывести результаты.

**Шаг 1.** Создайте папку проекта и файл `main.ts`:

```bash
cd C:\Projects
mkdir pr06-async
cd pr06-async
```

**Шаг 2.** Запишите в `main.ts` код:

```ts
// Вспомогательная функция: ждёт заданное количество миллисекунд
function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

// Имитация скачивания файла
async function download(file: string): Promise<string> {
  console.log(`Скачивание ${file}...`)
  await delay(1000)
  return `${file} скачан`
}

async function main(): Promise<void> {
  const start = Date.now()

  const results = await Promise.all([download("a.txt"), download("b.txt")])
  results.forEach((r) => console.log(r))

  console.log(`Всего времени: ${Date.now() - start} мс`)
}

main()
```

**Шаг 3.** Запустите программу:

```bash
node main.ts
```

**Вывод (обе задачи выполняются параллельно, поэтому общее время около одной секунды, а не двух):**

```
Скачивание a.txt...
Скачивание b.txt...
a.txt скачан
b.txt скачан
Всего времени: 1004 мс
```

## Резюме
- Синхронный код выполняется по порядку, асинхронный - не блокирует программу.
- `setTimeout` откладывает выполнение функции, `clearTimeout` отменяет его.
- `Promise` представляет результат будущей операции и завершается успехом (`resolve`) или ошибкой (`reject`).
- `async`/`await` позволяют писать асинхронный код так же последовательно, как синхронный.
- Ошибки асинхронных операций ловятся конструкцией `try/catch`.
- `Promise.all` запускает несколько задач параллельно и ждёт их все, `Promise.race` - только первую завершившуюся.
