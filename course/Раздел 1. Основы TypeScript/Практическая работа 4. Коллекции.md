# Практическая работа 4. Коллекции

Одно значение в переменной хранить удобно, но в реальных приложениях данные почти всегда идут группами: список переписок, набор оценок, таблица «город - население». ## Теоретическая часть

Коллекции - это структуры данных, которые позволяют хранить группы элементов. Основные типы коллекций в TypeScript:

- **Массив** (`Array`) - упорядоченная коллекция элементов, доступ по индексу.
- **`Set`** - коллекция уникальных элементов.
- **`Map`** - коллекция пар «ключ - значение».

### Массивы

Массив создаётся перечислением элементов в квадратных скобках:

```ts
const planets = ["Mercury", "Venus", "Earth", "Mars"]
```

Основные приёмы работы:

```ts
planets.push("Jupiter")          // добавить элемент в конец
planets.pop()                    // удалить последний элемент
planets.length                   // количество элементов
planets[2]                       // элемент с индексом 2 (Earth)
planets.includes("Mars")         // есть ли элемент в массиве
planets.indexOf("Venus")         // индекс элемента (-1, если не найден)
```

### Функции высшего порядка

По массиву можно пройти не только циклом, но и с помощью функций, которые принимают другую функцию:

```ts
const numbers = [1, 2, 3, 4, 5]

numbers.forEach((n) => console.log(n))          // выполнить действие для каждого
const doubled = numbers.map((n) => n * 2)       // [2, 4, 6, 8, 10]
const even = numbers.filter((n) => n % 2 === 0) // [2, 4]
const sum = numbers.reduce((acc, n) => acc + n, 0) // 15
```

- `map` создаёт новый массив, преобразуя каждый элемент;
- `filter` оставляет только элементы, подходящие под условие;
- `reduce` сворачивает массив в одно значение;
- методы не меняют исходный массив, а возвращают новый.

### Множество Set

`Set` хранит только уникальные значения:

```ts
const tags = new Set<string>(["учебное", "важное", "учебное"])
console.log(tags.size)         // 2 - повтор не сохранился
tags.add("новое")              // добавить элемент
tags.has("важное")             // true - проверка наличия
```

### Словарь Map

`Map` хранит пары «ключ - значение» и запоминает порядок добавления:

```ts
const moons = new Map<string, number>([
  ["Earth", 1],
  ["Mars", 2],
])

console.log(moons.get("Mars")) // 2
moons.set("Jupiter", 95)       // добавить или обновить пару
moons.has("Earth")             // true
console.log(moons.size)        // 3
```

Перебрать `Map` можно циклом `for...of`:

```ts
for (const [planet, count] of moons) {
  console.log(`${planet}: ${count}`)
}
```

## Практический пример

**Задача:** показать работу с массивом и словарём.

**Шаг 1.** Создайте папку проекта и файл `main.ts`:

```bash
cd C:\Projects
mkdir pr04-collections
cd pr04-collections
```

**Шаг 2.** Запишите в `main.ts` код:

```ts
// Пример работы с массивом
const planets = ["Mercury", "Venus", "Earth", "Mars"]
planets.push("Jupiter")
console.log(`Third planet: ${planets[2]}`)
console.log(`Всего планет в списке: ${planets.length}`)

// Пример работы со словарём
const moons = new Map<string, number>([
  ["Earth", 1],
  ["Mars", 2],
])
console.log(`Moons of Mars: ${moons.get("Mars")}`)

moons.set("Jupiter", 95)
for (const [planet, count] of moons) {
  console.log(`${planet} - спутников: ${count}`)
}

// Пример работы с множеством
const unique = new Set<number>([1, 2, 2, 3, 3, 3])
console.log(`Уникальных чисел: ${unique.size}`)
```

**Шаг 3.** Запустите программу:

```bash
node main.ts
```

**Вывод:**

```
Third planet: Earth
Всего планет в списке: 5
Moons of Mars: 2
Earth - спутников: 1
Mars - спутников: 2
Jupiter - спутников: 95
Уникальных чисел: 3
```

**Шаг 4.** Добавьте в массив ещё одну планету через `push`, а в словарь - новую пару через `set`.

## Резюме
- Массив хранит элементы по порядку, доступ - по индексу, нумерация с нуля.
- `push`/`pop` добавляют и удаляют элементы, `length` возвращает количество.
- `map`, `filter` и `reduce` обрабатывают массив, не изменяя исходный.
- `Set` хранит только уникальные элементы, `Map` - пары «ключ - значение».
- Словарь перебирается циклом `for...of` по парам `[ключ, значение]`.
- Для проверки наличия элемента служат методы `includes` (массив), `has` (Set и Map).
