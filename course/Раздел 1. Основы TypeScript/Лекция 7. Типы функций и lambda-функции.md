# Лекция 7. Типы функций и lambda-функции

В TypeScript функция - такое же значение, как число или строка. Её можно сохранить в переменную, передать другой функции как аргумент и вернуть из функции. Функции без имени называют **лямбда-функциями** (или стрелочными функциями), а функции, которые принимают другие функции или возвращают их, - **функциями высшего порядка**.

В мобильных приложениях этот приём встречается постоянно: обработчик нажатия кнопки, сортировка списка, форматирование данных - всё это функции, переданные как значения.

## Что вы узнаете

- Как сохранять функции в переменных.
- Как описывать тип функции.
- Как передавать функцию в другую функцию (callback).
- Как возвращать функцию из функции.
- Как работать с необязательными функциями-параметрами.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Функция как значение

Функцию можно присвоить переменной - в этом случае стрелочную функцию записывают без имени:

```ts
const greet = (name: string): void => {
  console.log(`Привет, ${name}!`)
}

greet("Иван")   // Привет, Иван!
```

`greet` - это переменная, которая хранит функцию. Обратите внимание на стрелку `=>` - так записывается **стрелочная функция**. Скобки в вызове `greet("Иван")` означают, что функцию выполняют; без скобок её значение просто передаётся дальше.

## Тип функции

У функции, как у любого значения, есть тип. Он описывает параметры и возвращаемое значение:

```ts
const add: (a: number, b: number) => number = (a, b) => a + b
const print: (text: string) => void = (text) => console.log(text)
```

Разберём тип `(a: number, b: number) => number`:

- в круглых скобках - типы параметров;
- после стрелки `=>` - тип результата.

Тип можно вынести в отдельный псевдоним:

```ts
type Operation = (a: number, b: number) => number

const add: Operation = (a, b) => a + b
const multiply: Operation = (a, b) => a * b
```

Когда переменная уже имеет тип `Operation`, типы параметров `a` и `b` повторять не нужно - TypeScript выводит их сам.

## Функция как аргумент (callback)

Функцию можно передать в другую функцию как аргумент. Такая функция называется **callback** (функция обратного вызова):

```ts
function apply(a: number, b: number, operation: (x: number, y: number) => number): number {
  return operation(a, b)
}

console.log(apply(3, 4, (x, y) => x + y))   // 7
console.log(apply(3, 4, (x, y) => x * y))   // 12
```

`apply` принимает три параметра, третий из которых - функция. Внутри она вызывает переданную функцию со значениями `a` и `b`.

## Функция, возвращающая функцию

Функция может возвращать другую функцию. Так появляются «настраиваемые» функции:

```ts
function createMultiplier(factor: number): (n: number) => number {
  return (n) => n * factor
}

const double = createMultiplier(2)
const triple = createMultiplier(3)

console.log(double(5))   // 10
console.log(triple(5))   // 15
```

`createMultiplier` запоминает `factor` и возвращает новую функцию, которая умножает свой аргумент на это число.

## Короткая запись стрелочной функции

Если тело функции состоит из одного выражения, фигурные скобки и `return` можно опустить:

```ts
// Длинная запись
const double = (n: number): number => {
  return n * 2
}

// Короткая запись (эквивалентна)
const double = (n: number): number => n * 2
```

Отдельный случай - функция сразу возвращает объект. Тогда объект берут в круглые скобки:

```ts
const makePoint = (x: number, y: number) => ({ x, y })

console.log(makePoint(1, 2))   // { x: 1, y: 2 }
```

Без круглых скобок фигурные скобки `{ ... }` TypeScript воспринял бы как тело функции, а не как объект.

## Лямбда в функциях высшего порядка

Лямбда-функции чаще всего используют с функциями высшего порядка - например, при работе с массивами:

```ts
const numbers = [1, 2, 3, 4, 5]

numbers.forEach((n) => console.log(n))

const squares = numbers.map((n) => n * n)
console.log(squares)   // [ 1, 4, 9, 16, 25 ]
```

Внутри `forEach` и `map` мы передаём лямбду `(n) => ...`, которая выполняется для каждого элемента. Подробнее эти функции разбираются в лекции о функциях высшего порядка и коллекциях.

## Повторение действия несколько раз

Готовой функции `repeat`, как в некоторых языках, в TypeScript нет - но её легко написать:

```ts
function repeat(times: number, action: (index: number) => void): void {
  for (let i = 0; i < times; i++) {
    action(i)
  }
}

repeat(3, (i) => console.log(`Итерация ${i}`))
```

Вывод:

```
Итерация 0
Итерация 1
Итерация 2
```

`repeat` - функция высшего порядка: она принимает функцию `action` и сама решает, сколько раз её вызвать.

## Необязательный параметр-функция

Иногда функцию-аргумент передают не всегда. Тогда параметр делают необязательным с помощью знака `?`:

```ts
function trickOrTreat(
  isTrick: boolean,
  extraTreat?: (quantity: number) => string,
): () => void {
  const trick = () => console.log("Конфет нет!")
  const treat = () => console.log("Угощайтесь!")

  if (isTrick) {
    return trick
  }

  if (extraTreat) {
    console.log(extraTreat(5))
  }
  return treat
}
```

Проверка `if (extraTreat)` гарантирует, что функция существует, - только после неё её можно вызвать. Есть и короткая запись с оператором `?.`:

```ts
extraTreat?.(5)
```

Если значение равно `undefined`, вызов просто пропускается.

Использование:

```ts
const treatFunction = trickOrTreat(false, (quantity) => `${quantity} монет`)
const trickFunction = trickOrTreat(true)

treatFunction()
trickFunction()
```

Вывод:

```
5 монет
Угощайтесь!
Конфет нет!
```

## Программа целиком

Создайте файл `main.ts`:

```ts
type Operation = (a: number, b: number) => number

function calculate(a: number, b: number, operation: Operation): number {
  return operation(a, b)
}

const operations: Operation[] = [(x, y) => x + y, (x, y) => x * y]

operations.forEach((operation) => {
  console.log(`Результат: ${calculate(10, 5, operation)}`)
})
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Результат: 15
Результат: 50
```

## Резюме

- Функцию можно хранить в переменной и передавать как аргумент.
- Стрелочная функция записывается как `(параметры) => выражение`.
- Тип функции описывается как `(параметры) => тип_результата`.
- Функция, переданная в другую функцию, называется callback.
- Функция может возвращать другую функцию.
- Необязательный параметр-функция обозначается знаком `?`.
- Функции высшего порядка упрощают работу с массивами.
