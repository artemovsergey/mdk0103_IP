# Лекция 10. Асинхронность

До сих пор наши программы выполнялись строго по порядку: одна строка за другой. Такой код называется **синхронным**. Но мобильному приложению часто нужно выполнять долгие операции - запрос к серверу, чтение файла, ожидание таймера, - и при этом не «замораживать» интерфейс. Для этого применяется **асинхронное программирование**.

В TypeScript для него есть `Promise`, ключевые слова `async`/`await` и функция `setTimeout`. На этом занятии вы научитесь писать асинхронный код, обрабатывать ошибки и запускать несколько задач одновременно.

## Что вы узнаете

- Чем асинхронный код отличается от синхронного.
- Как отложить выполнение функции с помощью `setTimeout`.
- Как создавать и использовать `Promise`.
- Как писать асинхронные функции с `async`/`await`.
- Как обрабатывать ошибки конструкцией `try/catch`.
- Как запускать задачи параллельно с `Promise.all`.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Синхронный код

В синхронном коде каждая строка выполняется после завершения предыдущей:

```ts
console.log("Первый")
console.log("Второй")
console.log("Третий")
```

Вывод:

```
Первый
Второй
Третий
```

Пока выполняется одна строка, следующая ждёт. Если операция долгая, программа «замирает» - именно так возникает подвисание интерфейса, когда приложение ждёт ответа от сервера.

## Асинхронный код и setTimeout

Асинхронная операция не блокирует выполнение остального кода. Функция `setTimeout` откладывает выполнение функции на заданное время (в миллисекундах):

```ts
console.log("Начало")

setTimeout(() => {
  console.log("Прошло 2 секунды")
}, 2000)

console.log("Конец")
```

Вывод:

```
Начало
Конец
Прошло 2 секунды
```

Обратите внимание: «Конец» печатается **до** сообщения внутри `setTimeout`, хотя в коде он стоит после. Программа не ждёт завершения отложенной задачи, а продолжает выполняться. Когда время таймера истекает, отложенная функция ставится в очередь и выполняется, как только основной код закончится.

## Promise

**Promise** (обещание) - это объект, представляющий результат операции, которая завершится в будущем. У Promise есть два возможных исхода:

- **успех** (fulfilled) - операция завершилась с результатом;
- **ошибка** (rejected) - операция завершилась неудачей.

Создадим функцию, которая возвращает Promise и завершается успешно через секунду:

```ts
function fetchData(): Promise<string> {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve("Данные получены")
    }, 1000)
  })
}
```

- `new Promise(...)` создаёт Promise;
- `resolve(значение)` сообщает об успешном завершении и передаёт результат.

Promise можно обрабатывать методом `then`, но в современном коде чаще используют `async`/`await`.

## async и await

Ключевое слово `await` заставляет функцию дождаться завершения Promise, а `async` помечает функцию, внутри которой можно использовать `await`:

```ts
async function main(): Promise<void> {
  console.log("Загрузка...")
  const data = await fetchData()
  console.log(data)
}

main()
```

Вывод:

```
Загрузка...
Данные получены
```

- `async function` - объявление асинхронной функции.
- `await fetchData()` - «подожди, пока Promise завершится, и верни результат».
- Асинхронная функция всегда возвращает Promise, поэтому её тип указывают как `Promise<void>` или `Promise<string>`.

Важно: `await` не блокирует программу полностью - он приостанавливает только текущую функцию, а остальной код продолжает работу.

## Обработка ошибок: try/catch

Если асинхронная операция может завершиться с ошибкой, её отклоняют вызовом `reject`. Ошибку в асинхронном коде ловят конструкцией `try/catch`:

```ts
function fetchWithError(): Promise<string> {
  return new Promise((_, reject) => {
    setTimeout(() => {
      reject(new Error("Сервер недоступен"))
    }, 1000)
  })
}

async function main(): Promise<void> {
  try {
    const data = await fetchWithError()
    console.log(data)
  } catch (error) {
    const message = error instanceof Error ? error.message : String(error)
    console.log(`Ошибка: ${message}`)
  }
}

main()
```

Вывод:

```
Ошибка: Сервер недоступен
```

- `reject(new Error(...))` сообщает о неудачном завершении операции;
- `try` содержит код, где может произойти ошибка;
- `catch (error)` выполняется, если в `try` произошла ошибка.

Обратите внимание: значение `error` имеет тип `unknown`, поэтому перед использованием его проверяют через `instanceof Error`. Так TypeScript гарантирует, что свойство `message` действительно существует.

Ошибку можно бросить и вручную - оператором `throw`. Такую ошибку поймает тот же `try/catch`.

## Параллельное выполнение: Promise.all

Иногда нужно запустить несколько независимых задач одновременно и дождаться их всех. Для этого используется `Promise.all`:

```ts
async function main(): Promise<void> {
  const [a, b] = await Promise.all([fetchData(), fetchData()])
  console.log(a, b)
}

main()
```

Обе задачи запускаются одновременно, а `await` дожидается их завершения. Если бы мы написали два `await` подряд, операции выполнялись бы последовательно - вдвое дольше. `Promise.all` возвращает массив результатов в том же порядке, в котором были переданы Promise.

## Имитация задержки

Полезная утилита для примеров и тестов - функция, которая «ждёт» заданное время:

```ts
function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

async function main(): Promise<void> {
  console.log("Ждём...")
  await delay(1000)
  console.log("Готово")
}

main()
```

## Практический пример: прогноз погоды

Соберём пример, в котором две независимые «сетевые» операции выполняются параллельно:

```ts
function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

async function getForecast(): Promise<string> {
  await delay(1000)
  return "Солнечно"
}

async function getTemperature(): Promise<string> {
  await delay(1000)
  return "30°C"
}

async function getWeatherReport(): Promise<string> {
  const [forecast, temperature] = await Promise.all([
    getForecast(),
    getTemperature(),
  ])
  return `${forecast}, ${temperature}`
}

async function main(): Promise<void> {
  console.log("Прогноз погоды")
  console.log(await getWeatherReport())
  console.log("Хорошего дня!")
}

main()
```

Вывод (обе операции занимают около одной секунды суммарно):

```
Прогноз погоды
Солнечно, 30°C
Хорошего дня!
```

Если одна из операций может завершиться с ошибкой, обработайте её внутри `getWeatherReport`:

```ts
async function getWeatherReport(): Promise<string> {
  const forecast = await getForecast()

  try {
    const temperature = await getTemperature()
    return `${forecast}, ${temperature}`
  } catch (error) {
    console.log(`Не удалось получить температуру: ${error}`)
    return `${forecast}, температура неизвестна`
  }
}
```

Так прогноз всё равно будет показан, даже если второй запрос не удался.

## Программа целиком

Создайте файл `main.ts`:

```ts
function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

async function download(file: string): Promise<string> {
  console.log(`Скачивание ${file}...`)
  await delay(1000)
  return `${file} скачан`
}

async function main(): Promise<void> {
  const results = await Promise.all([download("a.txt"), download("b.txt")])
  results.forEach((result) => console.log(result))
}

main()
```

Запустите:

```bash
node main.ts
```

Вывод (обе задачи выполняются параллельно):

```
Скачивание a.txt...
Скачивание b.txt...
a.txt скачан
b.txt скачан
```

## Резюме

- Синхронный код выполняется по порядку, асинхронный - не блокирует программу.
- `setTimeout` откладывает выполнение функции на заданное время.
- `Promise` представляет результат будущей операции: успех или ошибку.
- `async`/`await` позволяют писать асинхронный код так же просто, как синхронный.
- Ошибки асинхронных операций ловятся конструкцией `try/catch`.
- `Promise.all` запускает несколько задач параллельно и возвращает все результаты.
