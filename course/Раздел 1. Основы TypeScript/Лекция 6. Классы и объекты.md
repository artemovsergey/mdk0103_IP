# Лекция 6. Классы и объекты

До сих пор мы хранили данные в отдельных переменных и коллекциях. Но в реальных программах данные и действия над ними связаны между собой: у телевизора есть имя и громкость, а также действия «включить», «переключить канал». Для объединения данных и действий служат **классы** - основа объектно-ориентированного программирования (ООП).

Класс похож на чертёж дома: сам чертёж - не дом, а инструкция по его постройке. **Объект** - это «дом», созданный по чертежу. На этом занятии вы научитесь объявлять классы, создавать объекты и использовать основные принципы ООП.

## Что вы узнаете

- Как объявлять классы и создавать их экземпляры (объекты).
- Как задавать свойства, методы и конструктор.
- Как использовать модификаторы доступа (инкапсуляция).
- Как применять наследование и интерфейсы.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Определение класса

Класс - это шаблон, по которому создаются объекты. Он описывает, какие **свойства** (данные) и **методы** (функции) будут у объектов.

```ts
class SmartDevice {
  name: string
  status: string

  constructor(name: string) {
    this.name = name
    this.status = "offline"
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} включён`)
  }

  turnOff(): void {
    this.status = "off"
    console.log(`${this.name} выключен`)
  }
}
```

Разберём объявление:

- `class SmartDevice` - объявление класса. Имена классов записывают в стиле PascalCase: каждое слово с заглавной буквы.
- `name: string` и `status: string` - свойства (данные объекта).
- `constructor(name: string)` - специальный метод, который вызывается при создании объекта и задаёт начальные значения.
- `turnOn`, `turnOff` - методы (действия объекта).
- `this` - ссылка на текущий объект, для которого вызван метод или конструктор.

## Создание объектов

**Объект** (экземпляр класса) создаётся оператором `new`:

```ts
const tv = new SmartDevice("Телевизор")
tv.turnOn()        // Телевизор включён
tv.turnOff()       // Телевизор выключен
```

Можно создать сколько угодно объектов одного класса: у каждого будут собственные значения свойств.

## Инкапсуляция и модификаторы доступа

**Инкапсуляция** - принцип ООП, по которому внутренние данные объекта скрыты от внешнего кода, а доступ к ним идёт через методы. Для этого используют модификаторы доступа:

| Модификатор | Доступ |
|:------------|:-------|
| `public` (по умолчанию) | из любого места |
| `private` | только внутри класса |
| `protected` | внутри класса и его наследников |

```ts
class SmartTv {
  name: string
  private volume: number

  constructor(name: string) {
    this.name = name
    this.volume = 5
  }

  increaseVolume(): void {
    if (this.volume < 10) {
      this.volume++
    }
    console.log(`Громкость: ${this.volume}`)
  }
}
```

Свойство `volume` объявлено как `private`, поэтому извне оно недоступно:

```ts
const tv = new SmartTv("Телевизор")
tv.increaseVolume()      // Громкость: 6
// tv.volume = 100       // Ошибка: свойство private
```

Изменить громкость можно только методом - значит, он может проверить значение.

## Геттеры и сеттеры

Отдельные методы для чтения и записи свойства можно заменить **аксессорами**: `get` вызывается при чтении, `set` - при присваивании. Это позволяет проверять значение прямо при записи:

```ts
class SmartLamp {
  private brightnessValue = 50

  get brightness(): number {
    return this.brightnessValue
  }

  set brightness(value: number) {
    if (value >= 0 && value <= 100) {
      this.brightnessValue = value
    } else {
      console.log("Яркость должна быть от 0 до 100")
    }
  }
}

const lamp = new SmartLamp()
lamp.brightness = 80
console.log(lamp.brightness)   // 80

lamp.brightness = 150          // Яркость должна быть от 0 до 100
console.log(lamp.brightness)   // 80 - значение не изменилось
```

Снаружи аксессоры выглядят как обычное свойство: `lamp.brightness = 80`. Скрытое свойство `brightnessValue` при этом защищено от некорректных значений.

## Наследование

**Наследование** - принцип ООП, позволяющий создать новый класс на основе существующего. Новый класс (наследник) получает свойства и методы родителя и может добавлять свои.

В TypeScript наследование задаётся ключевым словом `extends`, а переопределение метода - `override`:

```ts
class SmartDevice {
  name: string
  protected status: string

  constructor(name: string) {
    this.name = name
    this.status = "off"
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} включён`)
  }
}

class SmartTvDevice extends SmartDevice {
  private volume: number

  constructor(name: string) {
    super(name)          // вызов конструктора родителя
    this.volume = 5
  }

  override turnOn(): void {
    super.turnOn()       // вызов метода родителя
    console.log(`Громкость: ${this.volume}`)
  }
}

const tv = new SmartTvDevice("Телевизор")
tv.turnOn()
```

Вывод:

```
Телевизор включён
Громкость: 5
```

- `extends` - наследование от родительского класса.
- `super(name)` - вызов конструктора родителя (обязателен, если у родителя есть конструктор с параметрами).
- `super.turnOn()` - вызов метода родителя.
- `override` - пометка переопределённого метода: TypeScript проверит, что такой метод действительно есть у родителя.

## IS-A и HAS-A

При проектировании классов различают два вида отношений:

- **IS-A** («является») - наследование. Телевизор **является** умным устройством: `class SmartTvDevice extends SmartDevice`.
- **HAS-A** («содержит») - композиция. Умный дом **содержит** список устройств:

```ts
class SmartHome {
  private devices: SmartDevice[] = []

  addDevice(device: SmartDevice): void {
    this.devices.push(device)
    console.log(`Устройство ${device.name} добавлено`)
  }

  turnOnAll(): void {
    this.devices.forEach((device) => device.turnOn())
  }
}
```

Класс `SmartHome` не наследуется от `SmartDevice`, а хранит коллекцию устройств - это отношение HAS-A.

## Интерфейсы

**Интерфейс** описывает форму объекта: какие свойства и методы у него должны быть, но не содержит реализации. Класс реализует интерфейс ключевым словом `implements`:

```ts
interface Switchable {
  turnOn(): void
  turnOff(): void
}

class Lamp implements Switchable {
  turnOn(): void {
    console.log("Лампа: свет включён")
  }

  turnOff(): void {
    console.log("Лампа: свет выключен")
  }
}
```

Класс, реализующий интерфейс, обязан определить все его методы, иначе TypeScript выдаст ошибку. Интерфейсы задают общий «договор»: код, работающий со `Switchable`, может включать и выключать любое устройство, не зная его деталей.

## Программа целиком

Создайте файл `main.ts`:

```ts
class SmartDevice {
  name: string

  constructor(name: string) {
    this.name = name
  }

  turnOn(): void {
    console.log(`${this.name} включён`)
  }
}

class SmartTvDevice extends SmartDevice {
  private volume: number

  constructor(name: string) {
    super(name)
    this.volume = 5
  }

  increaseVolume(): void {
    this.volume++
    console.log(`Громкость: ${this.volume}`)
  }
}

class SmartHome {
  private devices: SmartDevice[] = []

  addDevice(device: SmartDevice): void {
    this.devices.push(device)
  }

  turnOnAll(): void {
    this.devices.forEach((device) => device.turnOn())
  }
}

const home = new SmartHome()
const tv = new SmartTvDevice("Телевизор")

home.addDevice(tv)
home.turnOnAll()      // Телевизор включён
tv.increaseVolume()   // Громкость: 6
```

Запустите:

```bash
node main.ts
```

## Резюме

- Класс объединяет свойства и методы; объект создаётся через `new`.
- Конструктор задаёт начальные значения свойств и вызывается при создании объекта.
- Инкапсуляция скрывает данные с помощью `private` и `protected`.
- Геттеры и сеттеры (`get`/`set`) позволяют проверять значения при чтении и записи.
- Наследование (`extends`) позволяет переиспользовать код родителя, `super` вызывает его конструктор или метод, а `override` помечает переопределённый метод.
- Интерфейсы (`implements`) описывают форму класса.
- Отношения между классами бывают IS-A (наследование) и HAS-A (композиция).
