## Теоретическая часть

Циклы позволяют выполнять блок кода многократно. В TypeScript есть три основных типа циклов:

- **`for`** - используется для повторения с заданным числом итераций.
- **`while`** - выполняется, пока условие истинно.
- **`do-while`** - выполняется хотя бы один раз, а затем проверяет условие.

### Цикл for

```ts
// Вывести числа от 1 до 5
for (let i = 1; i <= 5; i++) {
  console.log(i)
}
```

Разберём заголовок цикла:

- `let i = 1` - счётчик, который выполняется один раз перед началом;
- `i <= 5` - условие: цикл работает, пока оно истинно;
- `i++` - шаг: что сделать со счётчиком после каждой итерации.

### Цикл while

```ts
let x = 5
while (x > 0) {
  console.log(x)
  x--
}
```

Условие проверяется **перед** каждой итерацией. Если оно сразу ложно, тело цикла не выполнится ни разу.

### Цикл do-while

```ts
let y = 0
do {
  console.log(y)
  y++
} while (y < 3)
```

Условие проверяется **после** итерации, поэтому тело цикла выполнится хотя бы один раз, даже если условие изначально ложно.

### Перебор массива: for...of

Самый удобный способ пройти по всем элементам массива - цикл `for...of`:

```ts
const fruits = ["яблоко", "банан", "вишня"]

for (const fruit of fruits) {
  console.log(fruit)
}
```

### Перебор с индексом

Когда нужен номер элемента, используют обычный `for`:

```ts
const fruits = ["яблоко", "банан", "вишня"]

for (let i = 0; i < fruits.length; i++) {
  console.log(`${i + 1}. ${fruits[i]}`)
}
```

`fruits.length` - количество элементов, а `fruits[i]` - элемент с индексом `i`. Нумерация начинается с нуля, поэтому для вывода «по-человечески» прибавляем единицу.

### break и continue

- `break` досрочно завершает цикл;
- `continue` пропускает текущую итерацию и переходит к следующей.

```ts
for (let i = 1; i <= 10; i++) {
  if (i === 5) break   // остановиться на 5
  if (i % 2 === 0) continue // пропустить чётные
  console.log(i)       // 1, 3
}
```

## Практический пример

**Задача:** вывести список планет двумя способами и обратный отсчёт.

**Шаг 1.** Создайте папку проекта и файл `main.ts`:

```bash
cd C:\Projects
mkdir pr03-loops
cd pr03-loops
```

**Шаг 2.** Запишите в `main.ts` код:

```ts
const planets = ["Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune"]

// Перебор массива циклом for...of
console.log("Planets in solar system:")
for (const planet of planets) {
  console.log(planet)
}

// Перебор массива с индексом
console.log("\nPlanets with index:")
for (let i = 0; i < planets.length; i++) {
  console.log(`Planet ${i + 1}: ${planets[i]}`)
}

// Обратный отсчёт циклом while
let count = 5
console.log("\nCountdown:")
while (count > 0) {
  console.log(count)
  count--
}
console.log("Старт!")
```

## Резюме
- `for` подходит, когда известно число повторений, `while` - когда важнее условие, `do-while` гарантирует хотя бы одну итерацию.
- `for...of` перебирает элементы массива, обычный `for` - ещё и их индексы.
- `break` завершает цикл досрочно, `continue` пропускает текущую итерацию.
- Свойство `length` хранит количество элементов массива.
- Счётчик цикла удобно использовать в вычислениях: `i + 1`, `i % 2` и других.
