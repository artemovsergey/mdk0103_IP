# Лекция 1. Создание и использование переменных в TypeScript

В приложениях, которые вы используете на телефоне, одни части остаются неизменными, а другие меняются. Например, в приложении «Настройки» названия категорий («Сеть и интернет», «Подключённые устройства») всегда одинаковы, а в новостном приложении заголовки, источники и время публикации меняются постоянно.

Как написать код так, чтобы содержимое менялось со временем? Нельзя переписывать программу каждый раз, когда появляется новая новость. Ответ - использовать **переменные**: ячейки памяти, содержимое которых может меняться.

На этом занятии вы научитесь писать код с использованием переменных, чтобы определённые части программы могли меняться без переписывания кода.

## Что вы будете создавать

- Небольшие программы на TypeScript, использующие переменные.

## Что вы узнаете

- Как объявить переменную и изменить её значение.
- Как выбрать подходящий тип данных.
- Как добавлять комментарии к коду.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).

## Как запускать примеры

Программы этого раздела не требуют мобильного приложения - это обычные скрипты, которые выполняются в Node.js. Node.js умеет запускать файлы TypeScript напрямую.

Создайте файл `main.ts` и запишите в него код. Запустить его можно командой:

```bash
node main.ts
```

Вывод программы появляется в терминале. Ошибки типов подчёркиваются красным прямо в редакторе VS Code.

## Переменные и типы данных

**Переменная** - это контейнер для одного значения. Представьте её как коробку с этикеткой. Этикетка - это имя переменной. Обращаясь к коробке по имени, вы получаете доступ к значению, которое в ней хранится.

Зачем хранить значение в переменной, а не использовать напрямую? Если в коде везде записаны конкретные значения, программа работает только для этого частного случая. Например, письмо «Дорогая Лорен, было приятно встретиться в офисе...» подходит только Лорен. Гораздо эффективнее создать шаблон: «Дорогой {имя}, было приятно встретиться в {место}...» - и заполнять пустые места.

Точно так же и в программе: вместо конкретных значений используют переменные `name`, `articleDate` и т. д., чтобы код работал для любых данных.

## Типы данных

Когда вы решаете, какие данные будут храниться в переменной, важно указать их тип. Основные типы данных в TypeScript:

| Тип TypeScript | Какие данные хранит | Примеры значений |
|:---------------|:--------------------|:-----------------|
| `string` | Текст | `"Добавить"`, `"Поиск"`, `"Войти"` |
| `number` | Числа (целые и дробные) | `32`, `1293490`, `2.5`, `-59281` |
| `boolean` | Логическое значение | `true`, `false` |

В TypeScript все числа — и целые, и дробные — имеют один тип `number`.

Пример: название места - текст (`string`), звёздный рейтинг - дробное число (`number`), количество отзывов - целое число (`number`), а «сохранил ли пользователь место» - логическое значение (`boolean`).

## Объявление переменной

Прежде чем использовать переменную, её нужно объявить. При объявлении вы даёте переменной имя и, при необходимости, тип.

```ts
const count: number = 2
```

Разберём это объявление по частям:

- `const` - ключевое слово, с которого начинается объявление.
- `count` - имя переменной.
- `: number` - тип данных (его можно опускать, см. ниже).
- `=` - оператор присваивания.
- `2` - начальное значение.

### Ключевые слова const и let

В TypeScript переменную можно объявить двумя способами:

```ts
const count: number = 2   // значение нельзя изменить
let total: number = 0     // значение можно изменить
```

- `const` - значение не изменяется. Рекомендуется использовать по умолчанию.
- `let` - значение можно менять.

### Имя переменной

Имя должно описывать данные, которые хранит переменная. Принято использовать стиль **camelCase**: первое слово со строчной буквы, остальные слова с заглавной, без пробелов.

Примеры: `numberOfEmails`, `cityName`, `bookPublicationDate`.

### Оператор присваивания

Знак `=` называется оператором присваивания. Значение справа от него сохраняется в переменную слева.

### Начальное значение

Значение должно соответствовать типу. Нельзя сохранить строку `"Hello"` в переменную типа `number` - TypeScript выдаст ошибку.

## Вывод типа

TypeScript умеет определять тип переменной по начальному значению, поэтому тип можно не указывать:

```ts
const count = 2          // тип number определён автоматически
const name = "Иван"      // тип string определён автоматически
```

Это называется **вывод типа**. Код становится короче, а результат тот же.

## Шаблонные строки

Чтобы вывести значение переменной внутри строки, используйте **шаблонные строки** (обратные кавычки) и выражение `${...}`:

```ts
const count = 2
console.log(`У вас ${count} непрочитанных сообщения.`)
```

Вывод:

```
У вас 2 непрочитанных сообщения.
```

Внутри `${}` можно записывать не только имя переменной, но и целое выражение:

```ts
const unreadCount = 5
const readCount = 100
console.log(`Всего сообщений: ${unreadCount + readCount}.`)
```

Вывод:

```
Всего сообщений: 105.
```

## Математические операции

С числами (тип `number`) можно выполнять арифметические операции:

```ts
const a = 10
const b = 3

console.log(a + b)   // 13 - сложение
console.log(a - b)   // 7  - вычитание
console.log(a * b)   // 30 - умножение
console.log(a / b)   // 3.333... - деление
console.log(a % b)   // 1  - остаток от деления
console.log(a ** 2)  // 100 - возведение в степень
```

## Обновление переменных

Если нужно изменить значение переменной, её объявляют через `let`:

```ts
let cartTotal = 0
cartTotal = 20
console.log(`Итого: ${cartTotal}`)
```

Если объявить переменную через `const` и попытаться её изменить, TypeScript выдаст ошибку:

```ts
const cartTotal = 0
cartTotal = 20   // Ошибка: нельзя присвоить значение константе
```

## Комментарии

Комментарии - это пояснения в коде, которые игнорируются при выполнении. Они помогают себе и другим разработчикам понять код.

```ts
// Однострочный комментарий

/*
  Многострочный
  комментарий
*/
```

## Резюме

- Переменная - это контейнер для хранения значения.
- `const` - неизменяемая переменная, `let` - изменяемая.
- Основные типы данных: `string`, `number`, `boolean`.
- Тип можно не указывать - TypeScript выводит его сам.
- Для подстановки значений в строку используют шаблонные строки `` `...${выражение}...` ``.
- Программы запускаются командой `node main.ts`.
