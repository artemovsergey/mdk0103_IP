## Теоретическая часть

### Класс и объект
Класс - это шаблон, который описывает свойства (данные) и методы (функции) будущих объектов. Конструктор вызывается при создании объекта и задаёт начальные значения свойств, а `this` ссылается на текущий объект:

```ts
class SmartDevice {
  name: string
  status: string = "online"

  constructor(name: string) {
    this.name = name
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} is turned on`)
  }
}

const device = new SmartDevice("ЖК-телевизор")
device.turnOn()
```

Объект (экземпляр класса) создаётся ключевым словом `new`. Тип `void` означает, что метод ничего не возвращает.

### Модификаторы доступа
- `public` - доступен отовсюду (по умолчанию);
- `private` - только внутри класса;
- `protected` - внутри класса и его наследников;
- `readonly` - задаётся только при создании объекта.

Так работает **инкапсуляция**: внутренние данные защищены, а доступ к ним идёт через методы.

### Наследование
`extends` создаёт класс на основе существующего: наследник получает свойства и методы родителя, может добавить свои и переопределить родительские. Ключевое слово `super` вызывает конструктор или метод родителя:

```ts
class SmartTvDevice extends SmartDevice {
  constructor(name: string) {
    super(name) // вызов конструктора родителя
  }

  override turnOn(): void {
    super.turnOn() // вызов метода родителя
    console.log("TV is ready")
  }
}
```

## Практический пример

**Задача:** создать систему управления умным домом с устройствами разных типов.

**Шаг 1.** Создайте папку проекта и файл `main.ts`:

```bash
cd C:\Projects
mkdir pr05-classes
cd pr05-classes
```

**Шаг 2.** Запишите в `main.ts` код:

```ts
// Базовый класс для всех умных устройств
class SmartDevice {
  name: string
  protected status: string = "online"

  constructor(name: string) {
    this.name = name
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} is turned on`)
  }

  turnOff(): void {
    this.status = "off"
    console.log(`${this.name} is turned off`)
  }
}

// Класс для умного телевизора
class SmartTvDevice extends SmartDevice {
  private volume: number = 5

  constructor(name: string) {
    super(name)
  }

  increaseVolume(): void {
    if (this.volume < 10) this.volume++
    console.log(`Volume increased to ${this.volume}`)
  }

  override turnOn(): void {
    super.turnOn()
    console.log(`TV is ready with volume ${this.volume}`)
  }
}

// Класс для умной лампы
class SmartLightDevice extends SmartDevice {
  private brightness: number = 50

  constructor(name: string) {
    super(name)
  }

  increaseBrightness(): void {
    if (this.brightness < 100) this.brightness += 10
    console.log(`Brightness increased to ${this.brightness}`)
  }

  override turnOn(): void {
    super.turnOn()
    console.log(`Light is on with brightness ${this.brightness}`)
  }
}

// Использование классов
const tv = new SmartTvDevice("Living Room TV")
const light = new SmartLightDevice("Kitchen Light")

tv.turnOn()
light.turnOn()

tv.increaseVolume()
light.increaseBrightness()
```

**Шаг 3.** Запустите программу:

```bash
node main.ts
```

**Вывод:**

```
Living Room TV is turned on
TV is ready with volume 5
Kitchen Light is turned on
Light is on with brightness 50
Volume increased to 6
Brightness increased to 60
```

## Резюме
- Класс - это шаблон, объект - его экземпляр, создаваемый через `new`.
- Конструктор задаёт начальные значения свойств, `this` ссылается на текущий объект.
- `private` и `protected` защищают внутренние данные (инкапсуляция).
- `extends` наследует класс, `super` вызывает конструктор или метод родителя.
- Наследник может переопределять методы родителя - так один интерфейс работает по-разному у разных устройств.
