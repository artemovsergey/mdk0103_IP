# Лекция 9. Функции высшего порядка и коллекции

**Функции высшего порядка** - это функции, которые принимают другие функции как параметры и/или возвращают функцию. Они особенно полезны при работе с коллекциями: перебор, сортировка, фильтрация и преобразование списков занимают гораздо меньше кода, чем обычные циклы, а читаются лучше.

В лекции «Типы функций и lambda-функции» вы уже передавали функцию как аргумент и писали собственную функцию `repeat`. Теперь познакомитесь со встроенными функциями высшего порядка для массивов: `forEach`, `map`, `filter`, `reduce` и `sort`.

## Что вы узнаете

- Как перебирать элементы с помощью `forEach`.
- Как преобразовывать элементы с помощью `map`.
- Как отбирать элементы с помощью `filter`.
- Как сворачивать массив в одно значение с помощью `reduce`.
- Как группировать элементы по признаку.
- Как сортировать массив по свойству объекта.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Исходные данные

В примерах будем работать с меню пекарни - массивом объектов. Каждый объект описывает один вид печенья:

```ts
type Cookie = {
  name: string
  softBaked: boolean
  hasFilling: boolean
  price: number
}

const cookies: Cookie[] = [
  { name: "Шоколадное", softBaked: false, hasFilling: false, price: 1.5 },
  { name: "Овсяное", softBaked: true, hasFilling: false, price: 2.0 },
  { name: "С джемом", softBaked: true, hasFilling: true, price: 2.5 },
  { name: "Ореховое", softBaked: false, hasFilling: true, price: 2.0 },
]
```

Все функции этой лекции получают лямбда-функцию - ту самую короткую запись `(cookie) => ...`, которая выполняется для каждого элемента массива.

## forEach()

Функция `forEach` выполняет переданную функцию для каждого элемента массива. Она ничего не возвращает:

```ts
cookies.forEach((cookie) => {
  console.log(cookie.name)
})
```

Вывод:

```
Шоколадное
Овсяное
С джемом
Ореховое
```

Если при переборе нужен номер элемента, лямбда может принять второй параметр - индекс:

```ts
cookies.forEach((cookie, index) => {
  console.log(`${index + 1}. ${cookie.name}`)
})
```

Вывод:

```
1. Шоколадное
2. Овсяное
3. С джемом
4. Ореховое
```

## map()

Функция `map` преобразует каждый элемент и возвращает **новый массив** из результатов. Исходный массив не меняется:

```ts
const names = cookies.map((cookie) => cookie.name)
console.log(names)
```

Вывод:

```
[ 'Шоколадное', 'Овсяное', 'С джемом', 'Ореховое' ]
```

Длина нового массива всегда совпадает с длиной исходного: сколько элементов было, столько и стало. `map` часто применяется, чтобы получить из объектов готовые строки для интерфейса:

```ts
const menu = cookies.map((cookie) => `${cookie.name} - ${cookie.price} ₽`)
console.log(menu)
```

Вывод:

```
[ 'Шоколадное - 1.5 ₽', 'Овсяное - 2 ₽', 'С джемом - 2.5 ₽', 'Ореховое - 2 ₽' ]
```

## filter()

Функция `filter` возвращает новый массив из элементов, для которых переданная функция вернула `true`:

```ts
const softCookies = cookies.filter((cookie) => cookie.softBaked)
console.log(softCookies.map((cookie) => cookie.name))
```

Вывод:

```
[ 'Овсяное', 'С джемом' ]
```

Новый массив содержит только те печенья, у которых `softBaked` равно `true`. Элементы, для которых лямбда вернула `false`, в результат не попадают.

Условие может быть и составным:

```ts
const sweetAndCheap = cookies.filter(
  (cookie) => cookie.hasFilling && cookie.price < 2.5,
)
console.log(sweetAndCheap.map((cookie) => cookie.name))
```

Вывод:

```
[ 'Ореховое' ]
```

## reduce()

Функция `reduce` сворачивает массив в одно значение. Она принимает начальное значение и функцию-свёртку:

```ts
const totalPrice = cookies.reduce((sum, cookie) => sum + cookie.price, 0)
console.log(`Общая стоимость: ${totalPrice} ₽`)
```

Вывод:

```
Общая стоимость: 8 ₽
```

Разберём параметры:

- первый параметр лямбды (`sum`) - **аккумулятор**, накопленный результат;
- второй параметр (`cookie`) - текущий элемент;
- второй аргумент самой функции (`0`) - начальное значение аккумулятора.

Сначала `sum` равен `0`. Для каждого элемента лямбда возвращает новое значение аккумулятора, которое передаётся в следующий вызов. Когда элементы заканчиваются, `reduce` возвращает последнее значение.

## Группировка с помощью reduce

Готовой функции `groupBy` в TypeScript нет, но группировку легко построить на `reduce`. Сгруппируем печенье по признаку «мягкое / хрустящее»:

```ts
const grouped = cookies.reduce((groups, cookie) => {
  const key = cookie.softBaked ? "мягкое" : "хрустящее"
  if (!groups[key]) {
    groups[key] = []
  }
  groups[key].push(cookie.name)
  return groups
}, {} as Record<string, string[]>)

console.log(grouped)
```

Вывод:

```
{ хрустящее: [ 'Шоколадное', 'Ореховое' ], мягкое: [ 'Овсяное', 'С джемом' ] }
```

- `Record<string, string[]>` - тип объекта-словаря: ключи-строки, значения - массивы строк.
- `{} as Record<string, string[]>` подсказывает TypeScript тип начального значения.
- `if (!groups[key])` создаёт пустой массив при первой встрече с новым ключом.

Готовый словарь удобно перебирать циклом `for...of`, с которым вы познакомились в лекции о коллекциях:

```ts
for (const [key, names] of Object.entries(grouped)) {
  console.log(`${key}: ${names.join(", ")}`)
}
```

## sort()

Функция `sort` сортирует массив. Чтобы отсортировать по определённому полю, передают **функцию сравнения**:

```ts
const sorted = [...cookies].sort((a, b) => a.price - b.price)
console.log(sorted.map((cookie) => `${cookie.name} - ${cookie.price} ₽`))
```

Вывод:

```
[ 'Шоколадное - 1.5 ₽', 'Овсяное - 2 ₽', 'Ореховое - 2 ₽', 'С джемом - 2.5 ₽' ]
```

Функция сравнения возвращает:

- отрицательное число, если `a` должно идти раньше `b`;
- положительное число, если `a` должно идти позже `b`;
- `0`, если порядок не важен.

Запись `[...cookies]` создаёт копию массива. Это важно, потому что `sort` **изменяет исходный массив**, а `map` и `filter`, наоборот, возвращают новые. Чтобы отсортировать по убыванию, поменяйте местами `a` и `b`: `(a, b) => b.price - a.price`.

## Цепочки вызовов

Функции высшего порядка удобно объединять в цепочки - результат одной функции передаётся в другую:

```ts
const expensiveSoftNames = cookies
  .filter((cookie) => cookie.softBaked)
  .filter((cookie) => cookie.price >= 2)
  .map((cookie) => cookie.name)

console.log(expensiveSoftNames)   // [ 'Овсяное', 'С джемом' ]
```

Читается цепочка сверху вниз: «взять мягкое печенье», «оставить то, что дороже двух рублей», «получить названия». Каждый вызов возвращает массив, поэтому цепочку можно продолжать.

## Сводка функций

| Функция | Что делает | Возвращает |
|:--------|:-----------|:-----------|
| `forEach` | выполняет функцию для каждого элемента | ничего (`void`) |
| `map` | преобразует каждый элемент | новый массив |
| `filter` | отбирает элементы по условию | новый массив |
| `reduce` | сворачивает массив в одно значение | одно значение |
| `sort` | сортирует элементы | отсортированный массив (изменяет исходный) |

## Программа целиком

Создайте файл `main.ts`:

```ts
type Cookie = {
  name: string
  softBaked: boolean
  hasFilling: boolean
  price: number
}

const cookies: Cookie[] = [
  { name: "Шоколадное", softBaked: false, hasFilling: false, price: 1.5 },
  { name: "Овсяное", softBaked: true, hasFilling: false, price: 2.0 },
  { name: "С джемом", softBaked: true, hasFilling: true, price: 2.5 },
  { name: "Ореховое", softBaked: false, hasFilling: true, price: 2.0 },
]

const softNames = cookies
  .filter((cookie) => cookie.softBaked)
  .map((cookie) => cookie.name)
console.log(`Мягкое печенье: ${softNames.join(", ")}`)

const total = cookies.reduce((sum, cookie) => sum + cookie.price, 0)
console.log(`Общая стоимость: ${total} ₽`)

const cheapest = [...cookies].sort((a, b) => a.price - b.price)[0]
console.log(`Самое дешёвое: ${cheapest.name}`)
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Мягкое печенье: Овсяное, С джемом
Общая стоимость: 8 ₽
Самое дешёвое: Шоколадное
```

## Резюме

- Функция высшего порядка принимает другую функцию как параметр или возвращает её.
- `forEach` - перебор элементов без возврата результата.
- `map` - преобразование элементов в новый массив той же длины.
- `filter` - отбор элементов по условию.
- `reduce` - сворачивание массива в одно значение; на нём же строят группировку.
- `sort` - сортировка по функции сравнения; она изменяет исходный массив.
- Функции объединяются в цепочки, что делает код коротким и понятным.
