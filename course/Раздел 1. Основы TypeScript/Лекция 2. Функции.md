# Лекция 2. Функции

В программировании часто бывает нужно выполнить один и тот же блок кода несколько раз. Например, приложение поздравляет каждого пользователя, печатает заголовок для каждого экрана или считает количество символов в каждой введённой строке. Вместо того чтобы копировать один и тот же код, его выносят в **функцию** - именованный блок кода, который можно вызвать в нужном месте программы.

Функции - главный строительный блок приложений. Из функций собираются экраны, обработчики нажатий и вспомогательная логика. На этом занятии вы научитесь объявлять функции, передавать в них данные и получать результат.

## Что вы узнаете

- Как объявлять и вызывать функции.
- Как передавать данные в функцию (параметры) и получать результат (возвращаемое значение).
- Чем параметр отличается от аргумента.
- Как задавать значения по умолчанию.
- Как записывать функции короче - стрелочными функциями.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Зачем нужны функции

Посмотрите на программу, которая поздравляет двух собак с днём рождения:

```ts
console.log("С днём рождения, Ровер!")
console.log("Тебе уже 5 лет!")
console.log("С днём рождения, Рекс!")
console.log("Тебе уже 2 года!")
```

Код работает, но в нём много повторов: чтобы добавить третью собаку, придётся снова скопировать две строки. Если понадобится изменить текст поздравления, придётся править каждую копию.

Вынесем поздравление в функцию:

```ts
function birthdayGreeting(name: string, age: number): string {
  return `С днём рождения, ${name}! Тебе уже ${age} лет!`
}

console.log(birthdayGreeting("Ровер", 5))
console.log(birthdayGreeting("Рекс", 2))
```

Теперь текст поздравления хранится в одном месте, а вызывать его можно сколько угодно раз с разными данными. У функций есть и другие преимущества:

- **Повторное использование кода.** Вместо копирования вызывается одна и та же функция.
- **Читаемость.** Имя функции объясняет, что делает код: `calculateArea` понятнее, чем формула внутри `console.log`.
- **Удобство сопровождения.** Исправление в функции автоматически применяется ко всем её вызовам.

## Объявление и вызов функции

Функция объявляется ключевым словом `function`, после которого идут имя, список параметров в круглых скобках и тело в фигурных скобках:

```ts
function greet(name: string): void {
  console.log(`Привет, ${name}!`)
}
```

- `function` - ключевое слово, с которого начинается объявление.
- `greet` - имя функции.
- `name: string` - параметр: имя и тип данных, которые функция принимает.
- `: void` - тип возвращаемого значения. `void` означает, что функция ничего не возвращает.
- Тело в фигурных скобках выполняется при каждом вызове.

Функция вызывается по имени, а в скобках передаются аргументы:

```ts
greet("Иван")    // Привет, Иван!
greet("Мария")   // Привет, Мария!
```

Объявление функции само по себе ничего не выполняет: код запускается только в момент вызова. Имена функций принято записывать в стиле camelCase и начинать с глагола: `calculateArea`, `printGreeting`, `sendMessage`.

## Возвращаемое значение

Чтобы функция вернула результат, используется оператор `return`. Тип результата указывается после списка параметров:

```ts
function add(a: number, b: number): number {
  return a + b
}

const sum = add(3, 4)
console.log(sum)   // 7
```

Когда выполняется `return`, функция завершает работу и передаёт значение в то место, где была вызвана. Результат можно сохранить в переменную или сразу передать дальше:

```ts
console.log(add(10, 20))   // 30
```

Код после `return` не выполняется:

```ts
function isPositive(number: number): boolean {
  return number > 0
  console.log("Эта строка никогда не выполнится")
}
```

Если функция не возвращает значение явно, её тип - `void`. Например, функция `greet` только печатает текст в консоль.

## Параметры и аргументы

Важно различать два термина:

- **Параметр** - переменная в объявлении функции: `function greet(name: string)`.
- **Аргумент** - значение, которое передаётся при вызове: `greet("Иван")`.

У функции может быть несколько параметров, в том числе разных типов:

```ts
function formatPrice(amount: number, currency: string): string {
  return `${amount} ${currency}`
}

console.log(formatPrice(1500, "₽"))   // 1500 ₽
```

Аргументы разделяются запятыми и передаются в том же порядке, в котором объявлены параметры. В TypeScript нет именованных аргументов, поэтому порядок важен:

```ts
console.log(formatPrice(1500, "₽"))   // правильно: 1500 ₽
console.log(formatPrice("₽", 1500))   // ошибка типа: аргументы перепутаны
```

Функции без параметров тоже возможны:

```ts
function printLine(): void {
  console.log("----------")
}

printLine()
```

## Параметры по умолчанию

Параметру можно задать значение по умолчанию. Если аргумент не передан, используется оно:

```ts
function greet(name: string = "Гость"): void {
  console.log(`Привет, ${name}!`)
}

greet()          // Привет, Гость!
greet("Иван")    // Привет, Иван!
```

Параметры со значениями по умолчанию принято ставить в конец списка, иначе вызывать функцию неудобно. Чтобы применить значение по умолчанию, когда параметр нужно «пропустить», передают `undefined`:

```ts
function createUser(name: string = "Гость", age: number = 18): void {
  console.log(`${name}, ${age} лет`)
}

createUser(undefined, 20)   // Гость, 20 лет
```

## Стрелочные функции

В TypeScript есть более короткий способ записи функции - **стрелочная функция**. Она удобна, когда функцию нужно передать как аргумент или когда тело состоит из одного выражения:

```ts
const add = (a: number, b: number): number => {
  return a + b
}

const multiply = (a: number, b: number): number => a * b

console.log(add(3, 4))        // 7
console.log(multiply(3, 4))   // 12
```

Если тело - одно выражение, `return` и фигурные скобки можно опустить. Стрелочные функции часто передают в методы массивов:

```ts
const numbers = [1, 2, 3, 4]

const doubled = numbers.map((number) => number * 2)
console.log(doubled)   // [2, 4, 6, 8]
```

Функция `(number) => number * 2` применяется к каждому элементу массива. Подробнее о методах массивов - в лекции «Коллекции».

## Сигнатура функции

Имя функции и её параметры вместе называются **сигнатурой**. Сигнатура подсказывает, как вызвать функцию и какие данные ей нужны:

```ts
function sendMessage(text: string, recipient: string): boolean
```

Сигнатура этой функции: `sendMessage(text, recipient)`. Тип возвращаемого значения в сигнатуру не входит, но тоже важен: он говорит, что на результат можно положиться.

## Программа целиком

Соберём всё вместе. Создайте файл `main.ts`:

```ts
function birthdayGreeting(name: string, age: number): string {
  const nameGreeting = `С днём рождения, ${name}!`
  const ageGreeting = `Тебе уже ${age} лет!`
  return `${nameGreeting}\n${ageGreeting}`
}

const greeting = birthdayGreeting("Ровер", 5)
console.log(greeting)
console.log(birthdayGreeting("Рекс", 2))
```

Запустите:

```bash
node main.ts
```

Вывод:

```
С днём рождения, Ровер!
Тебе уже 5 лет!
С днём рождения, Рекс!
Тебе уже 2 года!
```

Разберём программу:

- `\n` внутри строки - это символ перевода строки, поэтому два поздравления печатаются с новой строки.
- Результат первого вызова сохранён в переменную `greeting`, результат второго - сразу передан в `console.log`.
- Одна и та же функция использована для двух разных собак.

## Резюме

- Функция - это именованный блок кода, который можно вызывать многократно.
- Объявление начинается с `function`; вызов выполняется по имени с аргументами.
- Параметры - это входные данные функции; аргументы - значения при вызове.
- `return` возвращает результат и завершает функцию; без результата тип функции - `void`.
- Параметрам можно задавать значения по умолчанию.
- Стрелочные функции - короткая запись, удобная для передачи в другие функции.
