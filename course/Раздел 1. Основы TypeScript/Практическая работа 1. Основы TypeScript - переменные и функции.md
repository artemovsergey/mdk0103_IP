# Практическая работа 1. Основы TypeScript - переменные и функции

В мобильных приложениях данные постоянно меняются: имя пользователя, количество сообщений, сумма заказа. Чтобы хранить такие данные, в программе используют **переменные**, а чтобы выполнять над ними действия - **функции**. На этой практической работе вы создадите первые программы на TypeScript, научитесь запускать их в терминале и получите шаблон отчёта, которым будете пользоваться весь курс.

## Теоретическая часть

### Переменные в TypeScript
Переменная - это контейнер для хранения данных. В TypeScript переменные объявляются с помощью ключевых слов `const` (неизменяемая) и `let` (изменяемая).

```ts
const name: string = "Иван"  // неизменяемая переменная
let age: number = 25         // изменяемая переменная
```

Разберём объявление по частям:

- `const` - ключевое слово, с которого начинается объявление;
- `name` - имя переменной;
- `: string` - тип данных (его можно не указывать - TypeScript выведет тип сам);
- `=` - оператор присваивания;
- `"Иван"` - начальное значение.

Значение `const`-переменной изменить нельзя, а `let`-переменной - можно:

```ts
let age = 25
age = 26 // так можно

const name = "Иван"
name = "Пётр" // ошибка: нельзя переприсвоить константу
```

### Основные типы данных

| Тип | Какие данные хранит | Примеры значений |
|:--|:--|:--|
| `string` | текст | `"Добавить"`, `"Поиск"` |
| `number` | целые и дробные числа | `32`, `2.5`, `-10` |
| `boolean` | логическое значение | `true`, `false` |
| `undefined` | значение не задано | `undefined` |
| `null` | намеренное отсутствие значения | `null` |

### Объявление функций
Функция - это блок кода, который выполняет определённую задачу. Функция объявляется с помощью ключевого слова `function`.

```ts
function greet(name: string): string {
  return `Привет, ${name}!`
}
```

- `greet` - имя функции;
- `name: string` - параметр и его тип;
- `: string` после скобок - тип возвращаемого значения;
- `return` - возвращает результат.

Вызов функции и её результат:

```ts
const message = greet("Иван")
console.log(message) // Привет, Иван!
```

### Стрелочные функции
Ту же функцию можно записать короче - стрелочной функцией:

```ts
const greet = (name: string): string => `Привет, ${name}!`
```

Результат вызова одинаковый, поэтому в современном коде стрелочная запись используется очень часто.

### Параметры по умолчанию
Если параметр может не передаваться, для него задают значение по умолчанию:

```ts
function greet(name: string = "гость"): string {
  return `Привет, ${name}!`
}

console.log(greet())        // Привет, гость!
console.log(greet("Анна"))  // Привет, Анна!
```

### Шаблонные строки
Для подстановки значений в текст используют обратные кавычки и выражение `${...}`:

```ts
const count = 2
console.log(`У вас ${count} непрочитанных сообщения.`) // У вас 2 непрочитанных сообщения.
```

## Практический пример

**Задача:** написать программу, которая вычисляет площадь прямоугольника.

**Шаг 1.** Создайте папку проекта и файл `main.ts`:

```bash
cd C:\Projects
mkdir pr01-typescript-basics
cd pr01-typescript-basics
```

Запишите в `main.ts` код:

```ts
// Функция вычисляет площадь прямоугольника
function calculateArea(width: number, height: number): number {
  return width * height
}

const width = 10
const height = 5
const area = calculateArea(width, height)
console.log(`Площадь прямоугольника: ${area}`)
```

**Шаг 2.** Запустите программу:

```bash
node main.ts
```

**Вывод:**

```
Площадь прямоугольника: 50
```

## Резюме
- Переменные объявляются через `const` (неизменяемые) и `let` (изменяемые).
- Основные типы данных: `string`, `number`, `boolean`, а также `undefined` и `null`.
- Функция объявляется через `function` или стрелочной записью `=>`.
- Функция может принимать параметры и возвращать результат через `return`.
- Значения подставляются в строку с помощью шаблонных строк `${...}`.
- Скрипты этого раздела запускаются командой `node main.ts`.
