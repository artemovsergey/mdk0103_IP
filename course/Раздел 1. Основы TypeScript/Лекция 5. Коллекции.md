# Лекция 5. Коллекции

Одна переменная хранит одно значение. Но часто нужно хранить целую группу данных: список планет, набор тегов или словарь «город → население». Для этого существуют **коллекции** - структуры данных для хранения групп элементов.

В мобильных приложениях коллекции встречаются повсюду: список контактов, лента новостей, результаты поиска, настройки. На этом занятии вы познакомитесь с массивами, множествами (`Set`) и словарями (`Map`), а также с циклами для перебора элементов.

## Что вы узнаете

- Как работать с массивами и их методами.
- Как перебирать элементы циклами `for`, `for...of`, `while`.
- Как использовать множества `Set` для уникальных значений.
- Как использовать словари `Map` для пар «ключ-значение».

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Массив

**Массив** - это упорядоченная коллекция элементов. В TypeScript массив объявляется в квадратных скобках:

```ts
const planets: string[] = ["Меркурий", "Венера", "Земля", "Марс"]
```

Тип `string[]` означает «массив строк». Тип можно не указывать - он выводится автоматически:

```ts
const planets = ["Меркурий", "Венера", "Земля", "Марс"]
```

### Доступ к элементам по индексу

К элементам обращаются по индексу (номеру), начиная с нуля:

```ts
console.log(planets[0])   // Меркурий
console.log(planets[2])   // Земля
```

Если обратиться к несуществующему индексу, ошибки не произойдёт - вернётся `undefined`:

```ts
console.log(planets[10])   // undefined
```

### Свойство length

Количество элементов хранится в свойстве `length`:

```ts
console.log(planets.length)   // 4
```

Последний элемент массива имеет индекс `planets.length - 1`.

### Изменение массива

Массивы можно изменять: добавлять и удалять элементы.

```ts
const numbers = [1, 2, 3]

numbers.push(4)        // добавить в конец: [1, 2, 3, 4]
numbers.pop()          // удалить последний: [1, 2, 3]
numbers.unshift(0)     // добавить в начало: [0, 1, 2, 3]
numbers.shift()        // удалить первый: [1, 2, 3]
```

Другие полезные методы:

```ts
const fruits = ["Яблоко", "Банан", "Вишня"]

console.log(fruits.includes("Банан"))   // true - есть ли элемент
console.log(fruits.indexOf("Вишня"))    // 2 - индекс элемента
console.log(fruits.indexOf("Груша"))    // -1 - элемента нет
```

Обратите внимание: массив объявлен через `const`, но его содержимое меняется. Запрет `const` относится к самой переменной - переназначить другой массив нельзя, а добавлять и удалять элементы можно.

### Методы map и filter

Два метода часто используются при работе со списками. `map` преобразует каждый элемент и возвращает новый массив:

```ts
const numbers = [1, 2, 3, 4]

const doubled = numbers.map((number) => number * 2)
console.log(doubled)   // [2, 4, 6, 8]
```

`filter` оставляет только элементы, подходящие под условие:

```ts
const numbers = [1, 2, 3, 4, 5, 6]

const even = numbers.filter((number) => number % 2 === 0)
console.log(even)   // [2, 4, 6]
```

В обоих методах передаётся стрелочная функция - та самая короткая запись из лекции «Функции».

## Цикл for

Цикл `for` выполняет блок кода несколько раз. Классическая форма:

```ts
for (let i = 0; i < 5; i++) {
  console.log(i)   // 0, 1, 2, 3, 4
}
```

Разберём части в круглых скобках:

- `let i = 0` - начальное значение счётчика.
- `i < 5` - условие продолжения: пока оно истинно, цикл работает.
- `i++` - увеличение счётчика после каждой итерации.

**Итерация** - одно выполнение тела цикла.

## Перебор массива циклом for

Массив перебирают, проходя по всем индексам:

```ts
const planets = ["Меркурий", "Венера", "Земля", "Марс"]

for (let i = 0; i < planets.length; i++) {
  console.log(`Планета ${i + 1}: ${planets[i]}`)
}
```

Индекс нужен, когда важно знать номер элемента. Если важен только сам элемент, удобнее следующий цикл.

## Цикл for...of

Более короткий способ перебора элементов:

```ts
for (const planet of planets) {
  console.log(planet)
}
```

Переменная `planet` на каждой итерации получает очередной элемент массива. Если массив называется во множественном числе (`planets`), переменную цикла принято называть в единственном (`planet`).

## Циклы while и do-while

Цикл `while` выполняется, пока условие истинно:

```ts
let count = 5

while (count > 0) {
  console.log(count)
  count--
}
```

Цикл `do-while` сначала выполняет тело, а затем проверяет условие - поэтому тело выполняется хотя бы один раз:

```ts
let x = 0

do {
  console.log(x)
  x++
} while (x < 3)
```

Будьте осторожны: если условие цикла `while` всегда истинно, цикл никогда не завершится.

## Множество Set

**Set** - коллекция уникальных элементов. Дубликаты в ней не хранятся:

```ts
const tags = new Set<string>()

tags.add("новости")
tags.add("спорт")
tags.add("новости")   // дубликат - не добавится

console.log(tags.size)              // 2
console.log(tags.has("спорт"))      // true
tags.delete("спорт")                // удалить элемент
console.log(tags.has("спорт"))      // false
```

Создать множество сразу из массива:

```ts
const numbers = new Set([1, 2, 2, 3, 3, 3])
console.log(numbers)   // Set(3) { 1, 2, 3 }
```

Множество полезно, когда нужно быстро проверить наличие элемента и исключить повторы, например при сборе тегов статьи.

## Словарь Map

**Map** - коллекция пар «ключ-значение». Каждый ключ связан со значением:

```ts
const population = new Map<string, number>([
  ["Москва", 12600000],
  ["Санкт-Петербург", 5400000],
])

console.log(population.get("Москва"))   // 12600000
console.log(population.get("Казань"))   // undefined - ключа нет

population.set("Казань", 1250000)       // добавить пару
console.log(population.get("Казань"))   // 1250000
console.log(population.size)            // 3
population.delete("Казань")             // удалить пару
console.log(population.has("Казань"))   // false
```

Перебор словаря:

```ts
for (const [city, people] of population) {
  console.log(`${city}: ${people}`)
}
```

В квадратных скобках указываются сразу ключ и значение. Словарь удобен, когда данные ищутся по имени, а не по номеру: например, число спутников у планеты.

## Что выбрать

| Коллекция | Когда использовать |
|:----------|:-------------------|
| Массив `[]` | Данные упорядочены, важен порядок и номер элемента |
| `Set` | Нужны только уникальные значения, часты проверки «есть ли элемент» |
| `Map` | Данные хранятся парами «ключ-значение» |

## Программа целиком

Создайте файл `main.ts`:

```ts
const planets = ["Меркурий", "Венера", "Земля", "Марс"]

console.log("Планеты солнечной системы:")
for (const planet of planets) {
  console.log(planet)
}

const moons = new Map<string, number>([
  ["Земля", 1],
  ["Марс", 2],
])

console.log(`Спутников у Марса: ${moons.get("Марс")}`)

const uniqueTags = new Set(["космос", "наука", "космос"])
console.log(`Уникальных тегов: ${uniqueTags.size}`)
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Планеты солнечной системы:
Меркурий
Венера
Земля
Марс
Спутников у Марса: 2
Уникальных тегов: 2
```

Разберём программу:

- Цикл `for...of` печатает каждую планету по очереди.
- `moons.get("Марс")` возвращает значение по ключу - число 2.
- В `Set` слово «космос» добавлено дважды, но хранится один раз, поэтому `size` равен 2.

## Резюме

- Массив - упорядоченная коллекция элементов с доступом по индексу.
- `push`, `pop`, `includes`, `indexOf`, `map`, `filter` - основные методы массивов.
- Цикл `for` перебирает по счётчику, `for...of` - по элементам.
- `while` и `do-while` выполняются, пока условие истинно.
- `Set` хранит только уникальные значения.
- `Map` хранит пары «ключ-значение» и быстро ищет значение по ключу.
