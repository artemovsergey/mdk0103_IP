# Лекция 3. Условные выражения

Программа не всегда выполняется строка за строкой. Часто поведение зависит от условий: если пользователь нажал кнопку - выполнить одно, иначе - другое. Для этого используются **условные выражения** - они позволяют коду принимать решения.

Светофор на дороге, уровень заряда батареи, оценка за экзамен - всё это примеры ситуаций, в которых программе нужно выбрать один вариант из нескольких. На этом занятии вы научитесь управлять ходом программы с помощью `if`/`else`, тернарного оператора и `switch`.

## Что вы узнаете

- Как выполнять код по условию с помощью `if` и `else`.
- Как проверять несколько условий подряд с помощью `else if`.
- Как выбирать одно из двух значений тернарным оператором.
- Как обрабатывать несколько вариантов с помощью `switch`.
- Как сравнивать значения и объединять условия логическими операторами.

## Что вам понадобится

- Компьютер с установленным Node.js (версия LTS) и редактор VS Code (см. файл «Настройка окружения Expo»).
- Файл `main.ts` для примеров. Запуск: `node main.ts`.

## Булевы значения

Условие - это выражение, которое вычисляется в `true` (истина) или `false` (ложь). Такой тип данных называется **boolean**. Проверить результат сравнения можно прямо в консоли:

```ts
console.log(5 > 3)   // true
console.log(5 < 3)   // false
```

Оператор `>` сравнивает два значения и возвращает булев результат. Его можно сохранить в переменную и использовать в условии:

```ts
const isWarm = 25 > 20
console.log(isWarm)   // true
```

## Операторы сравнения

Для сравнения значений используются операторы:

| Оператор | Значение | Пример (результат) |
|:---------|:---------|:-------------------|
| `===` | равно | `5 === 5` → `true` |
| `!==` | не равно | `5 !== 3` → `true` |
| `>` | больше | `5 > 3` → `true` |
| `<` | меньше | `10 < 5` → `false` |
| `>=` | больше или равно | `5 >= 5` → `true` |
| `<=` | меньше или равно | `4 <= 3` → `false` |

> В TypeScript для сравнения используется строгое равенство `===` (тройной знак). Оно проверяет и значение, и тип. Обычное `==` может давать неожиданные результаты: например, считает строку `"5"` равной числу `5`. Поэтому используйте только `===` и `!==`.

Сравнивать можно не только числа, но и строки:

```ts
const color = "Красный"

console.log(color === "Красный")   // true
console.log(color === "Зелёный")   // false
```

## Логические операторы

Условия объединяются логическими операторами:

```ts
const a = true
const b = false

console.log(a && b)   // false - логическое И
console.log(a || b)   // true  - логическое ИЛИ
console.log(!a)       // false - логическое НЕ
```

- `&&` - «И»: истинно, только если истинны оба условия.
- `||` - «ИЛИ»: истинно, если истинно хотя бы одно условие.
- `!` - «НЕ»: меняет значение на противоположное.

Логические операторы помогают проверять диапазоны:

```ts
const number = 7

console.log(number >= 1 && number <= 10)   // true
```

Запись `number >= 1 && number <= 10` читается как «число от 1 до 10 включительно».

## Условный оператор if

Конструкция `if` выполняет блок кода, только если условие истинно:

```ts
const trafficLightColor = "Красный"

if (trafficLightColor === "Красный") {
  console.log("Стоп")
}
```

Если условие ложно, блок пропускается, и программа продолжает работу со следующей строки. Добавим `else`, чтобы обработать противоположный случай:

```ts
const trafficLightColor = "Зелёный"

if (trafficLightColor === "Красный") {
  console.log("Стоп")
} else {
  console.log("Можно ехать")
}
```

Вывод:

```
Можно ехать
```

## Несколько условий: else if

Когда вариантов больше двух, между `if` и `else` добавляют ветки `else if`:

```ts
const trafficLightColor = "Жёлтый"

if (trafficLightColor === "Красный") {
  console.log("Стоп")
} else if (trafficLightColor === "Жёлтый") {
  console.log("Медленно")
} else if (trafficLightColor === "Зелёный") {
  console.log("Ехать")
} else {
  console.log("Неизвестный сигнал светофора")
}
```

Проверки выполняются сверху вниз, и выполняется только блок первой истинной ветки - остальные пропускаются. Ветка `else` необязательна: она выполняется, когда ни одно условие не совпало.

### Логические ошибки

Даже работающая программа может вести себя неправильно. Если ветка `else` перехватывает лишние случаи, появляется **логическая ошибка**:

```ts
const trafficLightColor = "Сломан"

if (trafficLightColor === "Красный") {
  console.log("Стоп")
} else {
  console.log("Ехать")   // ошибка: "Сломан" тоже попадает сюда
}
```

Программа запустится и напечатает «Ехать», хотя светофор не работает. Компилятор о такой ошибке не сообщит - её замечает только человек. Исправление - проверять ожидаемые значения явно:

```ts
if (trafficLightColor === "Красный") {
  console.log("Стоп")
} else if (trafficLightColor === "Жёлтый") {
  console.log("Медленно")
} else if (trafficLightColor === "Зелёный") {
  console.log("Ехать")
} else {
  console.log("Неизвестный сигнал светофора")
}
```

Теперь при неожиданном значении программа честно сообщит об ошибке.

## Тернарный оператор

Короткую запись «если-иначе» даёт **тернарный оператор**:

```
условие ? значение1 : значение2
```

Он выбирает одно из двух значений:

```ts
const age = 20
const access = age >= 18 ? "Разрешено" : "Запрещено"

console.log(access)   // Разрешено
```

Тернарный оператор удобен, когда нужно именно значение, а не выполнение блока кода. Если веток больше двух или код в них длинный, лучше использовать `if`/`else` - читаемость важнее краткости.

## Оператор switch

Когда переменная сравнивается с несколькими конкретными значениями, удобен `switch`:

```ts
const grade = 5

switch (grade) {
  case 5:
    console.log("Отлично")
    break
  case 4:
    console.log("Хорошо")
    break
  case 3:
    console.log("Удовлетворительно")
    break
  default:
    console.log("Другая оценка")
}
```

- `case значение:` - проверка на совпадение.
- `break` - выход из `switch`. Без него выполнение «провалится» в следующую ветку.
- `default` - выполняется, если ни один случай не совпал.

Несколько значений можно объединить. Например, янтарный сигнал светофора означает то же, что и жёлтый:

```ts
switch (trafficLightColor) {
  case "Красный":
    console.log("Стоп")
    break
  case "Жёлтый":
  case "Янтарный":
    console.log("Медленно")
    break
  case "Зелёный":
    console.log("Ехать")
    break
  default:
    console.log("Неизвестный сигнал светофора")
}
```

Для значений «Жёлтый» и «Янтарный» выполняется один и тот же блок.

## Вложенные условия

Условия можно вкладывать друг в друга, когда решение зависит от нескольких факторов:

```ts
const isOnline = true
const hasSubscription = false

if (isOnline) {
  if (hasSubscription) {
    console.log("Доступ к материалам открыт")
  } else {
    console.log("Нужна подписка")
  }
} else {
  console.log("Нет соединения с интернетом")
}
```

Вложенные условия быстро усложняют код. Если возможно, объединяйте проверки логическими операторами: `if (isOnline && hasSubscription)`.

## Программа целиком

Создайте файл `main.ts`:

```ts
function timeOfDay(hour: number): string {
  if (hour < 6) {
    return "Ночь"
  } else if (hour < 12) {
    return "Утро"
  } else if (hour < 18) {
    return "День"
  } else if (hour < 24) {
    return "Вечер"
  } else {
    return "Неверное время"
  }
}

console.log(`Сейчас: ${timeOfDay(14)}`)
console.log(`Сейчас: ${timeOfDay(22)}`)
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Сейчас: День
Сейчас: Вечер
```

## Резюме

- Условие вычисляется в `true` или `false` (тип `boolean`).
- Сравнение выполняется операторами `===`, `!==`, `>`, `<`, `>=`, `<=`.
- Логические операторы `&&`, `||`, `!` объединяют условия.
- `if`/`else if`/`else` выполняют код по условию.
- Ошибки, при которых программа работает, но результат неверен, называются логическими.
- Тернарный оператор `?:` выбирает одно из двух значений.
- `switch` удобен для сравнения с несколькими конкретными значениями.
