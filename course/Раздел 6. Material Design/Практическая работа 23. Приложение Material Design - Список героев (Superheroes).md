# Практическая работа 23. Приложение Material Design - Список героев (Superheroes)

В этой работе вы примените принципы Material Design и создадите приложение **Superheroes** — прокручиваемый список супергероев с собственной темой: палитрой, шрифтом и формами.

### Пререквизиты

- Лекция 18 «Material Design (Woof)».
- Умение выводить списки через `FlatList` и хранить состояние через `useState`.

### Что вы узнаете

- Как разложить приложение по файлам: модель, репозиторий, тема.
- Как собрать собственную палитру для светлой и тёмной тем.
- Как подключить собственный шрифт и применить его ко всей типографике.
- Как оформить элемент списка карточкой с изображением.

### Что вы создадите

Приложение **Superheroes**: список героев, где у каждого — изображение, имя и описание, а верхняя панель позволяет переключать тему.

## Начало работы

Создайте проект и установите библиотеки:

```bash
npx create-expo-app@latest superheroes --template blank-typescript
cd superheroes
npx expo install react-native-paper expo-font @expo-google-fonts/cabin
```

Создайте в корне проекта две папки: `model` — для данных, `theme` — для настроек темы.

## Шаг 1. Изображения героев

Подготовьте шесть изображений и сохраните их в папку `assets` под именами `hero1.png`, `hero2.png`, …, `hero6.png`. Подойдут любые картинки: рисунки, значки, фотографии. Если своих изображений нет, скопируйте `assets/icon.png` шесть раз под нужными именами — код менять не придётся.

## Шаг 2. Модель данных

Создайте файл `model/Hero.ts`:

```tsx
export type Hero = {
  id: string
  name: string
  description: string
  image: any
}
```

Создайте файл `model/HeroesRepository.ts` с данными о героях:

```tsx
import { Hero } from './Hero'

export const heroes: Hero[] = [
  { id: '1', name: 'Nick the Night and Day', description: 'The Mobile Hero', image: require('../assets/hero1.png') },
  { id: '2', name: 'Reality Protector', description: 'Understands the absolute truth', image: require('../assets/hero2.png') },
  { id: '3', name: 'Andre the Giant', description: 'Mimics the light and night', image: require('../assets/hero3.png') },
  { id: '4', name: 'Benjamin the Brave', description: 'Harnesses the power of canary', image: require('../assets/hero4.png') },
  { id: '5', name: 'Magnificent Maru', description: 'Effortlessly glides in to save the day', image: require('../assets/hero5.png') },
  { id: '6', name: 'Dynamic Yasmine', description: 'Ability to shift to any form', image: require('../assets/hero6.png') },
]
```

- `Hero` описывает одного героя.
- `image` — изображение из папки `assets`, подключённое функцией `require`.
- Данные вынесены в отдельный файл: экран не зависит от конкретного списка.

## Шаг 3. Цветовая палитра

Создайте файл `theme/Colors.ts`. Свою палитру можно подобрать в Material Theme Builder (https://m3.material.io/theme-builder#/custom), а для начала возьмите пример:

```tsx
export const colors = {
  light: {
    primary: '#466800',
    onPrimary: '#FFFFFF',
    primaryContainer: '#C6F181',
    background: '#FEFCF5',
    surface: '#FEFCF5',
    onSurface: '#1B1C18',
  },
  dark: {
    primary: '#ABD468',
    onPrimary: '#223600',
    primaryContainer: '#344E00',
    background: '#1B1C18',
    surface: '#1B1C18',
    onSurface: '#E4E3DB',
  },
}
```

## Шаг 4. Типографика

Создайте файл `theme/Typography.ts` — шрифт Cabin для всей темы:

```tsx
import { configureFonts } from 'react-native-paper'

export const typography = configureFonts({
  config: {
    fontFamily: 'Cabin_400Regular',
  },
})
```

## Шаг 5. Формы и тема

Соберите тему из палитры, шрифта и скруглений. Создайте файл `theme/Theme.ts`:

```tsx
import { MD3DarkTheme, MD3LightTheme } from 'react-native-paper'
import { colors } from './Colors'
import { typography } from './Typography'

export const lightTheme = {
  ...MD3LightTheme,
  roundness: 8,
  fonts: typography,
  colors: { ...MD3LightTheme.colors, ...colors.light },
}

export const darkTheme = {
  ...MD3DarkTheme,
  roundness: 8,
  fonts: typography,
  colors: { ...MD3DarkTheme.colors, ...colors.dark },
}
```

`roundness` задаёт скругление углов у карточек и панели. Попробуйте значения `4`, `8` и `16`.

## Шаг 6. Карточка героя

Каждый элемент списка — карточка Material: изображение слева, имя и описание справа. В `App.tsx` добавьте компонент:

```tsx
function HeroCard({ hero }: { hero: Hero }) {
  return (
    <Card style={styles.card}>
      <View style={styles.row}>
        <Image source={hero.image} style={styles.image} />
        <View style={styles.info}>
          <Text variant="titleLarge" style={styles.name}>
            {hero.name}
          </Text>
          <Text variant="bodyMedium">{hero.description}</Text>
        </View>
      </View>
    </Card>
  )
}
```

## Шаг 7. Главный экран

Экран собирает всё вместе: тему, верхнюю панель и список. Полный код `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { FlatList, Image, StyleSheet, View } from 'react-native'
import { Cabin_400Regular, Cabin_700Bold, useFonts } from '@expo-google-fonts/cabin'
import { Appbar, Card, PaperProvider, Text } from 'react-native-paper'
import { Hero } from './model/Hero'
import { heroes } from './model/HeroesRepository'
import { darkTheme, lightTheme } from './theme/Theme'

function HeroCard({ hero }: { hero: Hero }) {
  return (
    <Card style={styles.card}>
      <View style={styles.row}>
        <Image source={hero.image} style={styles.image} />
        <View style={styles.info}>
          <Text variant="titleLarge" style={styles.name}>
            {hero.name}
          </Text>
          <Text variant="bodyMedium">{hero.description}</Text>
        </View>
      </View>
    </Card>
  )
}

function SuperheroesApp() {
  const [fontsLoaded] = useFonts({ Cabin_400Regular, Cabin_700Bold })
  const [isDark, setIsDark] = useState(false)

  if (!fontsLoaded) {
    return null
  }

  return (
    <PaperProvider theme={isDark ? darkTheme : lightTheme}>
      <Appbar.Header>
        <Appbar.Content title="Superheroes" />
        <Appbar.Action
          icon={isDark ? 'weather-sunny' : 'weather-night'}
          onPress={() => setIsDark(!isDark)}
        />
      </Appbar.Header>

      <FlatList
        data={heroes}
        keyExtractor={(item) => item.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => <HeroCard hero={item} />}
      />
    </PaperProvider>
  )
}

export default function App() {
  return (
    <>
      <SuperheroesApp />
      <StatusBar style="auto" />
    </>
  )
}

const styles = StyleSheet.create({
  list: { padding: 16 },
  card: { marginBottom: 16 },
  row: { flexDirection: 'row', padding: 16, alignItems: 'center' },
  image: { width: 72, height: 72, borderRadius: 8, marginRight: 16 },
  info: { flex: 1 },
  name: { marginBottom: 4 },
})
```

Разберём главное:

- `useFonts` загружает шрифт Cabin; пока шрифт не готов, экран не показывается.
- `PaperProvider` передаёт тему всем компонентам — панель и карточки оформляются автоматически.
- `Appbar.Action` переключает светлую и тёмную темы.
- `FlatList` выводит героев, а `HeroCard` рисует каждого.

## Проверьте работу

1. Запустите `npx expo start` и откройте приложение на телефоне или в браузере.
2. В списке должны быть шесть карточек с изображениями, именами и описаниями.
3. Нажмите иконку темы в верхней панели — фон, карточки и текст сменят цвета.
4. Убедитесь, что текст набран шрифтом Cabin, а углы карточек скруглены.

## Резюме

- Данные приложения удобно хранить в модели и репозитории — отдельно от экрана.
- Тема собирается из цветов, типографики и форм в одном месте.
- `PaperProvider` делает тему доступной всем компонентам Paper.
- `Appbar`, `Card` и `Text` с `variant` — готовые компоненты Material Design.
- Собственный шрифт подключается через `expo-font` и `configureFonts`.
