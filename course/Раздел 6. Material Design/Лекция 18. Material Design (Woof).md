# Лекция 18. Material Design (Woof)

Material Design — это система дизайна, созданная Google для качественного и последовательного пользовательского интерфейса. В ней собраны рекомендации по цветам, типографике и формам, а также готовые компоненты: верхняя панель, карточки, кнопки.

В этой лекции вы примените Material Design в React Native с помощью библиотеки **React Native Paper** и создадите приложение **Woof** — список собак с карточками и переключателем светлой и тёмной темы.

### Необходимые условия

- Умение создавать макеты (`View`, `Text`) и задавать стили через `StyleSheet`.
- Умение выводить списки через `FlatList`.
- Базовое понимание свойств (props) компонентов.

### Что вы узнаете

- Как установить и настроить React Native Paper.
- Как задать светлую и тёмную тему и собственную цветовую палитру.
- Как настроить типографику и подключить собственный шрифт.
- Как добавить верхнюю панель приложения и карточки.

### Что вы создадите

Приложение **Woof**, которое показывает список собак и поддерживает переключение светлой и тёмной темы.

## Установка React Native Paper

Создайте проект и установите библиотеки:

```bash
npx create-expo-app@latest woof --template blank-typescript
cd woof
npx expo install react-native-paper expo-font @expo-google-fonts/cabin
```

- `react-native-paper` — реализация Material Design 3 для React Native: готовые компоненты и тема.
- `expo-font` и `@expo-google-fonts/cabin` — загрузка собственного шрифта Cabin.

## Провайдер темы PaperProvider

Тема Paper применяется ко всему приложению через компонент **`PaperProvider`**:

```tsx
import { PaperProvider } from 'react-native-paper'

export default function App() {
  return (
    <PaperProvider>
      <WoofApp />
    </PaperProvider>
  )
}
```

Все компоненты Paper внутри провайдера автоматически получают цвета и типографику темы. Без `PaperProvider` компоненты не будут оформлены.

## Светлая и тёмная темы

Paper поставляется с готовыми темами **`MD3LightTheme`** и **`MD3DarkTheme`**. Создадим собственные на их основе — переопределим основные цвета:

```tsx
import { MD3DarkTheme, MD3LightTheme } from 'react-native-paper'

const lightTheme = {
  ...MD3LightTheme,
  colors: {
    ...MD3LightTheme.colors,
    primary: '#7D5260',
    secondary: '#625B71',
  },
}

const darkTheme = {
  ...MD3DarkTheme,
  colors: {
    ...MD3DarkTheme.colors,
    primary: '#D0BCFF',
    secondary: '#CCC2DC',
  },
}
```

Цвета в тема-системе Material собраны в роли:

- `primary` — ключевые элементы: выделенные иконки, активные элементы навигации.
- `secondary` — менее заметные элементы и акценты.
- `background` — фон экрана.
- `surface` — поверхности карточек и панелей.
- `onPrimary`, `onSurface` — текст и иконки поверх соответствующего цвета.

Чтобы интерфейс подхватил тему, передайте её в провайдер: `theme={isDark ? darkTheme : lightTheme}`.

Системная тема телефона доступна через хук `useColorScheme`:

```tsx
import { useState } from 'react'
import { useColorScheme } from 'react-native'

const systemScheme = useColorScheme()
const [isDark, setIsDark] = useState(systemScheme === 'dark')
```

Теперь приложение стартует в системной теме, а пользователь может переключить её вручную.

## Типографика

В Paper текст выводится компонентом `Text` со свойством `variant`. Вариант сам задаёт размер, насыщенность и межстрочный интервал:

```tsx
import { Text } from 'react-native-paper'

<Text variant="titleLarge">Рекс</Text>
<Text variant="bodyMedium">Весёлый и активный пёс.</Text>
```

Часто используемые варианты: `displayLarge` и `headlineMedium` — крупные заголовки, `titleLarge` — заголовок карточки, `bodyLarge` и `bodyMedium` — основной текст, `labelSmall` — подписи.

### Собственный шрифт

Подключим шрифт Cabin. Загрузим его хуком `useFonts`, а затем передадим семейство шрифта в тему через `configureFonts`:

```tsx
import { Cabin_400Regular, Cabin_700Bold, useFonts } from '@expo-google-fonts/cabin'
import { configureFonts, MD3LightTheme } from 'react-native-paper'

const fonts = configureFonts({ config: { fontFamily: 'Cabin_400Regular' } })

const theme = {
  ...MD3LightTheme,
  fonts,
}
```

Пока шрифт не загружен, приложение лучше не показывать: хук возвращает `fontsLoaded`, и до загрузки компонент возвращает `null`.

## Верхняя панель приложения

Компонент **`Appbar`** — верхняя панель Material с заголовком и действиями:

```tsx
import { Appbar } from 'react-native-paper'

<Appbar.Header>
  <Appbar.Content title="Woof" />
  <Appbar.Action
    icon={isDark ? 'weather-sunny' : 'weather-night'}
    onPress={() => setIsDark(!isDark)}
  />
</Appbar.Header>
```

`Appbar.Action` принимает имя иконки из набора Material Community Icons. Иконки `weather-sunny` и `weather-night` переключают тему.

## Карточки со списком собак

Список строится знакомым компонентом `FlatList`, а каждый элемент — карточкой `Card`:

```tsx
import { Card, Text } from 'react-native-paper'

function DogCard({ dog }: { dog: Dog }) {
  return (
    <Card style={styles.card}>
      <Card.Title title={dog.name} subtitle={`${dog.age} лет`} />
      <Card.Content>
        <Text variant="bodyMedium">{dog.description}</Text>
      </Card.Content>
    </Card>
  )
}
```

- `Card.Title` — заголовок и подзаголовок карточки.
- `Card.Content` — содержимое карточки.
- Цвет фона карточки берётся из темы (`surface`), поэтому при переключении темы он меняется автоматически.

## Полный код

Соберём всё вместе. Замените содержимое `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { FlatList, StyleSheet, useColorScheme } from 'react-native'
import {
  Appbar,
  Card,
  configureFonts,
  MD3DarkTheme,
  MD3LightTheme,
  PaperProvider,
  Text,
} from 'react-native-paper'
import { Cabin_400Regular, Cabin_700Bold, useFonts } from '@expo-google-fonts/cabin'

type Dog = { id: string; name: string; age: number; description: string }

const dogs: Dog[] = [
  { id: '1', name: 'Рекс', age: 3, description: 'Весёлый и активный пёс.' },
  { id: '2', name: 'Лесси', age: 5, description: 'Умная и спокойная собака.' },
  { id: '3', name: 'Барон', age: 2, description: 'Любит бегать и играть.' },
]

const fonts = configureFonts({ config: { fontFamily: 'Cabin_400Regular' } })

const lightTheme = {
  ...MD3LightTheme,
  fonts,
  roundness: 8,
  colors: {
    ...MD3LightTheme.colors,
    primary: '#7D5260',
    secondary: '#625B71',
  },
}

const darkTheme = {
  ...MD3DarkTheme,
  fonts,
  roundness: 8,
  colors: {
    ...MD3DarkTheme.colors,
    primary: '#D0BCFF',
    secondary: '#CCC2DC',
  },
}

function WoofApp() {
  const systemScheme = useColorScheme()
  const [isDark, setIsDark] = useState(systemScheme === 'dark')
  const theme = isDark ? darkTheme : lightTheme

  return (
    <PaperProvider theme={theme}>
      <Appbar.Header>
        <Appbar.Content title="Woof" />
        <Appbar.Action
          icon={isDark ? 'weather-sunny' : 'weather-night'}
          onPress={() => setIsDark(!isDark)}
        />
      </Appbar.Header>

      <FlatList
        data={dogs}
        keyExtractor={(item) => item.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <Card style={styles.card}>
            <Card.Title title={item.name} subtitle={`${item.age} лет`} />
            <Card.Content>
              <Text variant="bodyMedium">{item.description}</Text>
            </Card.Content>
          </Card>
        )}
      />
    </PaperProvider>
  )
}

export default function App() {
  const [fontsLoaded] = useFonts({ Cabin_400Regular, Cabin_700Bold })

  if (!fontsLoaded) {
    return null
  }

  return (
    <>
      <WoofApp />
      <StatusBar style="auto" />
    </>
  )
}

const styles = StyleSheet.create({
  list: { padding: 16 },
  card: { marginBottom: 16 },
})
```

Разберём ключевые моменты:

- `configureFonts` создаёт набор стилей шрифта, а `fonts` подключается к обеим темам.
- `useFonts` загружает файлы шрифта; до завершения загрузки возвращаем `null`.
- `useColorScheme` задаёт начальное значение `isDark`.
- `PaperProvider` получает актуальную тему, а `Appbar` и `Card` оформляются автоматически.
- `FlatList` выводит массив `dogs`, а `keyExtractor` использует `id`.

## Резюме

- Material Design задаёт цвета, типографику, формы и готовые компоненты.
- `PaperProvider` применяет тему ко всем компонентам Paper.
- `MD3LightTheme` и `MD3DarkTheme` — готовые темы для светлого и тёмного оформления.
- `configureFonts` и `useFonts` подключают собственный шрифт.
- `Appbar` — верхняя панель, `Card` и `Card.Title` — карточки, `Text` с `variant` — оформленный текст.
- Цвета меняются в одном месте — в теме, а компоненты подхватывают их автоматически.
