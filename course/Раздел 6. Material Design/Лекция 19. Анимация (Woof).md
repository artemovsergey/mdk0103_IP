# Лекция 19. Анимация (Woof)

Анимация делает приложение живым и понятным: она подсказывает, что произошло на экране, смягчает резкие изменения и привлекает внимание к важному. Когда карточка раскрывается мгновенно, взгляд не успевает уследить за изменением, — плавное движение решает эту проблему.

В этой лекции вы добавите анимацию в приложение **Woof** из лекции 18: карточки собак будут плавно раскрываться и показывать хобби собаки. Используется встроенный модуль **Animated** из React Native — ничего дополнительно устанавливать не нужно.

### Необходимые условия

- Приложение Woof из лекции 18 «Material Design (Woof)».
- Состояние через `useState` и хук `useRef`.
- Знакомство с эффектами `useEffect` (лекция 14 «Жизненный цикл приложения»).

### Что вы узнаете

- Как работает встроенный модуль `Animated`.
- Как создать `Animated.Value` и запустить анимацию через `Animated.timing` и `Animated.spring`.
- Как получать из прогресса анимации углы, прозрачность и размеры через `interpolate`.
- Как повторять анимацию через `Animated.loop`.
- Как выбрать значение `useNativeDriver`.

### Что вы создадите

Приложение **Woof** с раскрывающимися карточками: по нажатию появляется блок «Хобби», стрелка поворачивается, а все изменения происходят плавно.

## Модуль Animated

`Animated` — часть ядра React Native:

```tsx
import { Animated } from 'react-native'
```

Работа с модулем состоит из четырёх шагов:

1. Создать **`Animated.Value`** — число, которым управляет анимация.
2. Запустить **анимацию** (`Animated.timing`, `Animated.spring`, `Animated.loop`).
3. Превратить значение в конкретный стиль через **интерполяцию** (`interpolate`).
4. Применить стиль к **`Animated.View`**, **`Animated.Text`** или **`Animated.Image`**.

## Animated.Value

Значение создаётся один раз за время жизни компонента — для этого используется `useRef`:

```tsx
import { useRef } from 'react'
import { Animated } from 'react-native'

const progress = useRef(new Animated.Value(0)).current
```

- `progress` — «ручка» анимации; обычно это число от `0` до `1`.
- `useRef` сохраняет значение между перерисовками: при каждом рендере создаётся только один `Animated.Value`.

## Animated.timing

`Animated.timing` меняет значение до заданного за указанное время:

```tsx
Animated.timing(progress, {
  toValue: 1,
  duration: 600,
  useNativeDriver: true,
}).start()
```

Плавное появление элемента при открытии экрана запускают в `useEffect` — после первого рендера:

```tsx
const opacity = useRef(new Animated.Value(0)).current

useEffect(() => {
  Animated.timing(opacity, {
    toValue: 1,
    duration: 800,
    useNativeDriver: true,
  }).start()
}, [opacity])
```

Массив зависимостей `[opacity]` не даёт запускать анимацию повторно. Готовое значение подставляется в стиль: `style={{ opacity }}`.

## useNativeDriver

Свойство `useNativeDriver` указывает, кто выполняет анимацию:

- `true` — значение считает нативная часть приложения. Подходит для `opacity` и `transform` (сдвиг, масштаб, поворот).
- `false` — значение считается в JavaScript. Нужно для размеров (`height`, `width`, `maxHeight`), отступов и цвета.

## Интерполяция

Интерполяция превращает прогресс (`0…1`) в нужные стилю значения. Один `Animated.Value` может одновременно управлять углом поворота и высотой:

```tsx
const rotation = progress.interpolate({
  inputRange: [0, 1],
  outputRange: ['0deg', '180deg'],
})

const height = progress.interpolate({
  inputRange: [0, 1],
  outputRange: [0, 96],
})
```

- `inputRange` — значения прогресса.
- `outputRange` — соответствующие им числа, строки или цвета.

## Animated.spring

Пружинная анимация (`Animated.spring`) движется по законам физики: значение «догоняет» цель с ускорением и мягким торможением. Характер движения задают параметры:

- `friction` — трение: чем меньше значение, тем заметнее отскок.
- `tension` — натяжение: чем больше значение, тем быстрее движение.

```tsx
Animated.spring(progress, {
  toValue: 1,
  friction: 7,
  tension: 40,
  useNativeDriver: false,
}).start()
```

## Animated.loop

`Animated.loop` повторяет анимацию бесконечно. Внутри удобно собрать `Animated.sequence` — цепочку анимаций. Пример пульсирующей надписи:

```tsx
const scale = useRef(new Animated.Value(1)).current

useEffect(() => {
  const pulse = Animated.loop(
    Animated.sequence([
      Animated.timing(scale, { toValue: 1.1, duration: 500, useNativeDriver: true }),
      Animated.timing(scale, { toValue: 1, duration: 500, useNativeDriver: true }),
    ])
  )

  pulse.start()

  return () => pulse.stop()
}, [scale])
```

Масштаб применяется через `transform`: `style={{ transform: [{ scale }] }}`. Возврат `() => pulse.stop()` из `useEffect` останавливает анимацию, когда экран закрывается.

## Пример: раскрывающиеся карточки Woof

Добавим каждой собаке хобби, скрытое, пока карточка свёрнута. Прогресс `progress` хранит состояние раскрытия: `0` — свёрнута, `1` — раскрыта.

При нажатии на карточку меняем состояние `expanded` и запускаем пружину к `1` или `0`:

```tsx
function toggle() {
  const next = !expanded
  setExpanded(next)

  Animated.spring(progress, {
    toValue: next ? 1 : 0,
    friction: 7,
    tension: 40,
    useNativeDriver: false,
  }).start()
}
```

Интерполированные значения сразу обновляют несколько стилей: высоту и прозрачность блока с хобби, а также угол поворота стрелки-указателя. Блок обрезается через `overflow: 'hidden'`, пока высота маленькая, поэтому текст не «вылезает» за пределы карточки.

## Полный код

Для краткости используем готовые темы MD3: если в лекции 18 вы меняли палитру, подставьте свои `lightTheme` и `darkTheme`. Замените содержимое `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar'
import { useRef, useState } from 'react'
import { Animated, FlatList, Pressable, StyleSheet, View } from 'react-native'
import {
  Appbar,
  Card,
  MD3DarkTheme,
  MD3LightTheme,
  PaperProvider,
  Text,
  useTheme,
} from 'react-native-paper'

type Dog = { id: string; name: string; age: number; hobby: string }

const dogs: Dog[] = [
  { id: '1', name: 'Рекс', age: 3, hobby: 'Любит приносить мяч и плавать в озере.' },
  { id: '2', name: 'Лесси', age: 5, hobby: 'Обожает долгие прогулки в парке.' },
  { id: '3', name: 'Барон', age: 2, hobby: 'Гоняет мяч по двору и учит новые команды.' },
]

function DogCard({ dog }: { dog: Dog }) {
  const theme = useTheme()
  const [expanded, setExpanded] = useState(false)
  const progress = useRef(new Animated.Value(0)).current

  const hobbyHeight = progress.interpolate({ inputRange: [0, 1], outputRange: [0, 96] })
  const hobbyOpacity = progress.interpolate({ inputRange: [0, 1], outputRange: [0, 1] })
  const chevronRotation = progress.interpolate({
    inputRange: [0, 1],
    outputRange: ['0deg', '180deg'],
  })

  function toggle() {
    const next = !expanded
    setExpanded(next)

    Animated.spring(progress, {
      toValue: next ? 1 : 0,
      friction: 7,
      tension: 40,
      useNativeDriver: false,
    }).start()
  }

  return (
    <Card style={styles.card}>
      <Pressable onPress={toggle} style={styles.header}>
        <View style={styles.info}>
          <Text variant="titleLarge">{dog.name}</Text>
          <Text variant="bodyMedium">{`Возраст: ${dog.age}`}</Text>
        </View>
        <Animated.Text
          style={[
            styles.chevron,
            { color: theme.colors.primary, transform: [{ rotate: chevronRotation }] },
          ]}
        >
          ▾
        </Animated.Text>
      </Pressable>

      <Animated.View style={{ height: hobbyHeight, opacity: hobbyOpacity, overflow: 'hidden' }}>
        <View style={styles.hobby}>
          <Text variant="labelMedium">Хобби</Text>
          <Text variant="bodyLarge">{dog.hobby}</Text>
        </View>
      </Animated.View>
    </Card>
  )
}

export default function App() {
  const [isDark, setIsDark] = useState(false)

  return (
    <PaperProvider theme={isDark ? MD3DarkTheme : MD3LightTheme}>
      <Appbar.Header>
        <Appbar.Content title="Woof" />
        <Appbar.Action
          icon={isDark ? 'weather-sunny' : 'weather-night'}
          onPress={() => setIsDark(!isDark)}
        />
      </Appbar.Header>

      <FlatList
        data={dogs}
        keyExtractor={(item) => item.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => <DogCard dog={item} />}
      />

      <StatusBar style="auto" />
    </PaperProvider>
  )
}

const styles = StyleSheet.create({
  list: { padding: 16 },
  card: { marginBottom: 16 },
  header: { flexDirection: 'row', alignItems: 'center', padding: 16 },
  info: { flex: 1 },
  chevron: { fontSize: 20 },
  hobby: { paddingHorizontal: 16, paddingBottom: 16, gap: 4 },
})
```

Обратите внимание:

- `useNativeDriver: false` — потому что анимируется высота.
- Переменная `progress` своя у каждой карточки: у каждого компонента `DogCard` независимая анимация.

## Типичные ошибки

- **Забыли `.start()`.** Без вызова `.start()` анимация не запускается.
- **Создают `Animated.Value` без `useRef`.** Тогда при каждой перерисовке появляется новое значение, и анимация сбрасывается.
- **Ставят `useNativeDriver: true` для высоты.** Размеры поддерживаются только при `useNativeDriver: false`.

## Резюме

- `Animated` — встроенный модуль React Native, устанавливать ничего не нужно.
- `Animated.Value` создаётся через `useRef` и хранит прогресс анимации.
- `Animated.timing` меняет значение за время, `Animated.spring` — по законам пружины, `Animated.loop` повторяет анимацию.
- `interpolate` превращает прогресс в углы, прозрачность, высоту и другие стили.
- `useNativeDriver: true` ускоряет анимации прозрачности и трансформаций, а для размеров нужен `false`.
- Анимацию запускает метод `.start()`, а бесконечную анимацию останавливают при закрытии экрана.
