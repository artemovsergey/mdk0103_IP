# Лекция 24. SQL и базы данных

Многие приложения хранят данные прямо на устройстве: заметки, списки дел, будильники, историю тренировок. Чтобы данные не исчезали после закрытия приложения, их записывают в **базу данных**. На этом занятии вы познакомитесь с языком SQL и научитесь работать с локальной базой **SQLite** через пакет **expo-sqlite**.

### Пререквизиты

- Умение работать с TypeScript (лекции 1–10).
- Базовое понимание структур данных: массивы и объекты.

### Что вы узнаете

- Что такое реляционная база данных и таблица.
- Как выполнять основные SQL-операции: `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
- Как фильтровать, сортировать и группировать данные.
- Как читать и записывать данные через `expo-sqlite`.

### Что вы создадите

Приложение со списком пользователей: записи сохраняются в локальную базу данных и не исчезают после перезапуска.

## Что такое база данных

База данных — это организованная коллекция структурированной информации. **Реляционная** база данных хранит данные в **таблицах**, каждая из которых похожа на лист электронной таблицы.

- **Столбец** (column) — отдельное поле записи, например `name` или `age`.
- **Строка** (row) — одна запись, например данные одного пользователя.
- **Первичный ключ** (primary key) — столбец, который однозначно определяет строку. Обычно это `id`.

Проектируя приложение, вы сначала продумываете таблицы и их столбцы, а затем работаете с данными через запросы.

## Что такое SQL

**SQL** (Structured Query Language) — язык запросов для реляционных баз данных. Запросы читаются почти как английские фразы: `SELECT name FROM users WHERE age > 18` означает «выбрать имена пользователей старше 18 лет».

| Операция | SQL | Пример |
|---|---|---|
| Создание таблицы | `CREATE TABLE` | `CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)` |
| Добавление строки | `INSERT INTO` | `INSERT INTO users (name, age) VALUES ('Анна', 25)` |
| Чтение данных | `SELECT` | `SELECT * FROM users WHERE age > 20` |
| Обновление | `UPDATE` | `UPDATE users SET age = 26 WHERE name = 'Анна'` |
| Удаление | `DELETE` | `DELETE FROM users WHERE id = 1` |

Каждая операция состоит из **ключевого слова** (`SELECT`, `INSERT`, ...), **таблицы** и, при необходимости, **условия** (`WHERE`).

## Типы данных и ограничения

При создании таблицы каждому столбцу задают тип:

| Тип | Значение | Пример |
|---|---|---|
| `INTEGER` | Целое число | возраст, количество |
| `REAL` | Дробное число | цена |
| `TEXT` | Строка | имя, название |
| `BLOB` | Двоичные данные | изображение |

Полезные ограничения:

- `PRIMARY KEY AUTOINCREMENT` — уникальный номер строки, который база увеличивает автоматически.
- `NOT NULL` — столбец обязателен для заполнения.

## SQLite в React Native

Установите пакет:

```bash
npx expo install expo-sqlite
```

`npx expo install` подбирает версию библиотеки, совместимую с вашей версией Expo, поэтому для пакетов Expo используется именно эта команда, а не `npm install`.

### Открытие базы

```tsx
import * as SQLite from 'expo-sqlite'

const db = await SQLite.openDatabaseAsync('app.db')
```

Файл базы `app.db` создаётся автоматически при первом открытии и хранится в папке приложения. Все методы базы **асинхронные**, поэтому вызывать их нужно с `await` внутри `async`-функций.

### Создание таблицы

Для запросов, которые не принимают параметров, удобен `execAsync` — он выполняет одну или несколько инструкций сразу:

```tsx
await db.execAsync(`
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age INTEGER NOT NULL
  )
`)
```

`IF NOT EXISTS` защищает от ошибки при повторном запуске: если таблица уже есть, инструкция просто пропускается.

### Вставка данных

Для записи строк используют `runAsync`. Значения передаются через знаки `?` — это **параметризованный запрос**:

```tsx
await db.runAsync('INSERT INTO users (name, age) VALUES (?, ?)', 'Иван', 30)
```

Подставлять значения в строку запроса вручную (`VALUES ('${name}', ...)`) нельзя: так в базу попадают опасные данные, и приложение становится уязвимо к **SQL-инъекции**. Параметры `?` надёжно экранируют значения.

### Чтение данных

```tsx
const rows = await db.getAllAsync<User>('SELECT * FROM users')
// rows: [{ id: 1, name: 'Иван', age: 30 }, ...]
```

Тип `<User>` указывает, какой формы строки вернутся. Для одной строки используйте `getFirstAsync`, например для запроса с агрегатной функцией.

## Фильтрация и сортировка

Условие задаёт предложение `WHERE`, порядок — `ORDER BY`, количество строк — `LIMIT`:

```tsx
const adults = await db.getAllAsync<User>('SELECT * FROM users WHERE age >= 18')
const byName = await db.getAllAsync<User>('SELECT * FROM users ORDER BY name ASC')
const youngest = await db.getAllAsync<User>('SELECT * FROM users ORDER BY age LIMIT 3')
```

`ASC` — по возрастанию, `DESC` — по убыванию. Операторы сравнения: `=`, `!=`, `>`, `<`, `>=`, `<=`. Для поиска по образцу применяют `LIKE 'А%'` — «начинается с буквы А».

## Агрегатные функции и DISTINCT

Агрегатные функции вычисляют значение по всем строкам:

```tsx
const stat = await db.getFirstAsync<{ count: number; avgAge: number | null }>(
  'SELECT COUNT(*) AS count, AVG(age) AS avgAge FROM users'
)
```

- `COUNT(*)` — количество строк.
- `AVG(age)` — среднее значение столбца.
- `MIN` и `MAX` — минимальное и максимальное значение.
- `SUM` — сумма значений.

Вместе с `GROUP BY` функции считают статистику по группам, а `DISTINCT` убирает повторяющиеся значения:

```tsx
const byAge = await db.getAllAsync<{ age: number; count: number }>(
  'SELECT age, COUNT(*) AS count FROM users GROUP BY age'
)

const ages = await db.getAllAsync<{ age: number }>(
  'SELECT DISTINCT age FROM users ORDER BY age'
)
```

## Обновление и удаление

```tsx
await db.runAsync('UPDATE users SET age = ? WHERE id = ?', 31, 1)
await db.runAsync('DELETE FROM users WHERE id = ?', 1)
```

Будьте внимательны с `WHERE`: запрос без условия изменит или удалит **все** строки таблицы.

## Полный пример

Соберём приложение: список пользователей с формой добавления и кнопкой удаления. Создайте проект и установите пакет:

```bash
npx create-expo-app@latest sqlite-users --template blank-typescript
cd sqlite-users
npx expo install expo-sqlite
npx expo start
```

Все изменения вносятся в файл `App.tsx`:

```tsx
import { useEffect, useState } from 'react'
import { Button, FlatList, StyleSheet, Text, TextInput, View } from 'react-native'
import * as SQLite from 'expo-sqlite'

type User = { id: number; name: string; age: number }

let database: SQLite.SQLiteDatabase | null = null

async function openDatabase(): Promise<SQLite.SQLiteDatabase> {
  if (database) return database

  database = await SQLite.openDatabaseAsync('app.db')
  await database.execAsync(`
    CREATE TABLE IF NOT EXISTS users (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      age INTEGER NOT NULL
    )
  `)
  return database
}

export default function App() {
  const [users, setUsers] = useState<User[]>([])
  const [name, setName] = useState('')
  const [age, setAge] = useState('')

  async function loadUsers() {
    const db = await openDatabase()
    setUsers(await db.getAllAsync<User>('SELECT * FROM users ORDER BY name'))
  }

  useEffect(() => {
    loadUsers()
  }, [])

  async function addUser() {
    if (name === '' || age === '') return

    const db = await openDatabase()
    await db.runAsync('INSERT INTO users (name, age) VALUES (?, ?)', name, parseInt(age) || 0)
    setName('')
    setAge('')
    await loadUsers()
  }

  async function deleteUser(id: number) {
    const db = await openDatabase()
    await db.runAsync('DELETE FROM users WHERE id = ?', id)
    await loadUsers()
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>База данных SQLite</Text>

      <TextInput style={styles.input} value={name} onChangeText={setName} placeholder="Имя" />
      <TextInput
        style={styles.input}
        value={age}
        onChangeText={setAge}
        placeholder="Возраст"
        keyboardType="numeric"
      />
      <Button title="Добавить" onPress={addUser} />

      <FlatList
        data={users}
        keyExtractor={(item) => String(item.id)}
        renderItem={({ item }) => (
          <View style={styles.row}>
            <Text>
              {item.name}, {item.age} лет
            </Text>
            <Button title="Удалить" color="red" onPress={() => deleteUser(item.id)} />
          </View>
        )}
      />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, paddingTop: 60 },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  input: { borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, padding: 12, marginBottom: 12 },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 12, borderBottomWidth: 1, borderBottomColor: '#EEEEEE' },
})
```

Разберём ключевые моменты:

- `openDatabase` открывает базу один раз и сохраняет соединение в переменной `database` — при следующих вызовах база уже готова.
- `loadUsers` вызывается при старте через `useEffect` и после каждого изменения данных.
- `parseInt(age) || 0` превращает введённый текст в число, а пустое поле даёт `0`.
- `runAsync` выполняет запись, `getAllAsync` — чтение.
- Кнопка «Удалить» передаёт `id` строки в параметр запроса `WHERE id = ?`.

## Частые ошибки

- **Забыли `await`.** Все методы базы асинхронные: без `await` следующая строка выполнится раньше записи данных.
- **Собрали запрос конкатенацией строк.** Используйте `?` — это защищает от SQL-инъекций.
- **Не обновили состояние после записи.** После `INSERT`, `UPDATE` и `DELETE` прочитайте данные заново и вызовите `setUsers`.
- **Открываете базу при каждом рендере.** Открывайте её один раз и переиспользуйте соединение.

## Резюме

- Реляционная база данных хранит данные в таблицах со столбцами и строками.
- SQL — язык запросов: `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
- `WHERE`, `ORDER BY` и `LIMIT` фильтруют, сортируют и ограничивают выборку.
- Агрегатные функции, `GROUP BY` и `DISTINCT` помогают считать статистику.
- `expo-sqlite` даёт методы `execAsync`, `runAsync`, `getAllAsync` и `getFirstAsync`.
- Параметры `?` защищают запросы от SQL-инъекций.
