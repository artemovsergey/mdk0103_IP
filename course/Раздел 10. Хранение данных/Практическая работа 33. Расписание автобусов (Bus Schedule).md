# Практическая работа 33. Расписание автобусов (Bus Schedule)

Закрепим работу с SQLite на большом примере: приложение **Bus Schedule** показывает автобусные остановки и время отправлений. Данные хранятся в базе, а при первом запуске загружаются из JSON-файла.

### Пререквизиты

- Практические работы 31 и 32.
- Умение выводить списки через `FlatList` и переключать экраны по состоянию.

### Что вы узнаете

- Как загружать данные из JSON-файла в SQLite при первом запуске.
- Как строить запросы с `DISTINCT` и `WHERE`.
- Как организовать два экрана на одном состоянии.

### Что вы создадите

Приложение «Расписание автобусов»: список остановок, а по нажатию — время отправлений выбранной остановки.

## Шаг 1. Создание проекта и данных

```bash
npx create-expo-app@latest bus-schedule --template blank-typescript
cd bus-schedule
npx expo install expo-sqlite
npx expo start
```

Создайте файл `assets/schedule.json` с начальным расписанием:

```json
[
  { "id": 1, "stop": "Улица Ленина", "time": "08:00" },
  { "id": 2, "stop": "Центральная площадь", "time": "08:15" },
  { "id": 3, "stop": "Парк Победы", "time": "08:30" },
  { "id": 4, "stop": "Улица Ленина", "time": "09:00" },
  { "id": 5, "stop": "Центральная площадь", "time": "09:15" }
]
```

Каждый элемент — одна запись: остановка и время отправления. Одно и то же название встречается несколько раз — это нормально для расписания.

## Шаг 2. База данных и загрузка расписания

```tsx
import * as SQLite from 'expo-sqlite'
import scheduleData from './assets/schedule.json'

type ScheduleEntry = { id: number; stop: string; time: string }

let database: SQLite.SQLiteDatabase | null = null

async function getDatabase(): Promise<SQLite.SQLiteDatabase> {
  if (database) return database

  database = await SQLite.openDatabaseAsync('bus-schedule.db')
  await database.execAsync(`
    CREATE TABLE IF NOT EXISTS schedule (
      id INTEGER PRIMARY KEY,
      stop TEXT NOT NULL,
      time TEXT NOT NULL
    )
  `)

  const count = await database.getFirstAsync<{ count: number }>(
    'SELECT COUNT(*) AS count FROM schedule'
  )

  if (count && count.count === 0) {
    for (const entry of scheduleData) {
      await database.runAsync(
        'INSERT INTO schedule (id, stop, time) VALUES (?, ?, ?)',
        entry.id,
        entry.stop,
        entry.time
      )
    }
  }

  return database
}
```

- `database` хранит открытое соединение: база открывается только один раз.
- `COUNT(*)` проверяет, пуста ли таблица: начальные данные загружаются только при первом запуске, а `INSERT` в цикле переносит записи из JSON в таблицу.

Уникальные остановки и расписание одной остановки возвращают два запроса:

```tsx
await db.getAllAsync('SELECT DISTINCT stop FROM schedule ORDER BY stop')
await db.getAllAsync('SELECT * FROM schedule WHERE stop = ? ORDER BY time', stop)
```

Функции `getStops` и `getSchedule` с этими запросами появятся в полном коде ниже.

## Шаг 3. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { Button, FlatList, Pressable, StyleSheet, Text, View } from 'react-native'
import * as SQLite from 'expo-sqlite'
import scheduleData from './assets/schedule.json'

type ScheduleEntry = { id: number; stop: string; time: string }

let database: SQLite.SQLiteDatabase | null = null

async function getDatabase(): Promise<SQLite.SQLiteDatabase> {
  if (database) return database

  database = await SQLite.openDatabaseAsync('bus-schedule.db')
  await database.execAsync(`
    CREATE TABLE IF NOT EXISTS schedule (
      id INTEGER PRIMARY KEY,
      stop TEXT NOT NULL,
      time TEXT NOT NULL
    )
  `)

  const count = await database.getFirstAsync<{ count: number }>(
    'SELECT COUNT(*) AS count FROM schedule'
  )

  if (count && count.count === 0) {
    for (const entry of scheduleData) {
      await database.runAsync(
        'INSERT INTO schedule (id, stop, time) VALUES (?, ?, ?)',
        entry.id,
        entry.stop,
        entry.time
      )
    }
  }

  return database
}

async function getStops(): Promise<string[]> {
  const db = await getDatabase()
  const rows = await db.getAllAsync<{ stop: string }>(
    'SELECT DISTINCT stop FROM schedule ORDER BY stop'
  )
  return rows.map((row) => row.stop)
}

async function getSchedule(stop: string): Promise<ScheduleEntry[]> {
  const db = await getDatabase()
  return await db.getAllAsync<ScheduleEntry>(
    'SELECT * FROM schedule WHERE stop = ? ORDER BY time',
    stop
  )
}

function StopsList({ onSelect }: { onSelect: (stop: string) => void }) {
  const [stops, setStops] = useState<string[]>([])

  useEffect(() => {
    getStops().then(setStops)
  }, [])

  return (
    <FlatList
      data={stops}
      keyExtractor={(stop) => stop}
      renderItem={({ item }) => (
        <Pressable style={styles.row} onPress={() => onSelect(item)}>
          <Text style={styles.rowTitle}>{item}</Text>
          <Text style={styles.link}>Смотреть</Text>
        </Pressable>
      )}
    />
  )
}

function ScheduleScreen({ stop }: { stop: string }) {
  const [entries, setEntries] = useState<ScheduleEntry[]>([])

  useEffect(() => {
    getSchedule(stop).then(setEntries)
  }, [])

  return (
    <FlatList
      data={entries}
      keyExtractor={(item) => String(item.id)}
      renderItem={({ item }) => (
        <View style={styles.row}>
          <Text style={styles.time}>{item.time}</Text>
          <Text>{item.stop}</Text>
        </View>
      )}
    />
  )
}

export default function App() {
  const [ready, setReady] = useState(false)
  const [selectedStop, setSelectedStop] = useState<string | null>(null)

  useEffect(() => {
    getDatabase().then(() => setReady(true))
  }, [])

  if (!ready) return <View style={styles.center}><Text>Загрузка расписания…</Text></View>

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Расписание автобусов</Text>

      {selectedStop !== null ? (
        <>
          <Button title="Все остановки" onPress={() => setSelectedStop(null)} />
          <Text style={styles.subtitle}>{selectedStop}</Text>
          <ScheduleScreen stop={selectedStop} />
        </>
      ) : (
        <StopsList onSelect={setSelectedStop} />
      )}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16, paddingTop: 60 },
  center: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  subtitle: { fontSize: 18, marginVertical: 8 },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 16, borderBottomWidth: 1, borderBottomColor: '#EEEEEE' },
  rowTitle: { fontSize: 16 },
  link: { color: '#0057B8' },
  time: { fontWeight: 'bold', marginRight: 16 },
})
```

Разберём ключевые моменты:

- Экран определяется состоянием `selectedStop`: `null` — список остановок, строка — расписание выбранной остановки.
- `getDatabase` при первом запуске создаёт таблицу и переносит в неё данные из JSON.
- При следующих запусках таблица уже заполнена, поэтому повторной загрузки не происходит.
- `getStops` получает уникальные остановки, `getSchedule` — время одной остановки; ключом списка служит само название остановки.

## Проверьте работу

1. Запустите приложение — появится список уникальных остановок.
2. Нажмите на остановку — откроется её расписание, отсортированное по времени.
3. Нажмите «Все остановки» — вернитесь к списку.
4. Перезапустите приложение — расписание не задублировалось: данные загружаются только один раз.
5. Измените `schedule.json` и перезапустите приложение — база уже заполнена, поэтому изменения не применятся.

## Резюме

- JSON-данные загружаются в SQLite один раз, при первом запуске.
- `SELECT DISTINCT` получает уникальные остановки, `WHERE stop = ?` — расписание одной остановки.
- `ORDER BY time` сортирует отправления по времени.
- Два экрана переключаются одним состоянием `selectedStop` без дополнительных библиотек.
- База данных на устройстве хранит данные между запусками приложения.
