### Что вы создадите

Приложение «Инвентарь» с редактированием и удалением предметов.

## Шаг 1. Операции обновления и удаления

Продолжите проект из практической работы 31 и добавьте в слой данных две функции:

```tsx
async function updateItem(item: Item): Promise<void> {
  const db = await getDatabase()
  await db.runAsync(
    'UPDATE items SET name = ?, quantity = ?, price = ? WHERE id = ?',
    item.name,
    item.quantity,
    item.price,
    item.id
  )
}

async function deleteItem(id: number): Promise<void> {
  const db = await getDatabase()
  await db.runAsync('DELETE FROM items WHERE id = ?', id)
}
```

- `UPDATE` переписывает поля строки, `WHERE id = ?` выбирает ровно одну запись.
- `DELETE` удаляет строку по её `id`.
- Без условия `WHERE` запрос изменил или удалил бы всю таблицу — идентификатор обязателен.

## Шаг 2. Форма редактирования

Добавьте компонент **`EditItemForm`** — форму правки одного предмета. Она получает предмет в свойстве `item`, хранит название, количество и цену в собственных состояниях и показывает их в трёх полях `TextInput`.

- Значения из базы приходят числами, поэтому для полей они приводятся к строке: `String(item.quantity)`.
- При сохранении текст превращается обратно в числа: `parseInt(quantity) || 0` и `parseFloat(price) || 0`.
- Кнопка «Сохранить» вызывает `updateItem`, кнопка «Отмена» просто закрывает форму.
- Полный код компонента — в следующем шаге.

## Шаг 3. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { Button, FlatList, StyleSheet, Text, TextInput, View } from 'react-native'
import * as SQLite from 'expo-sqlite'

type Item = { id: number; name: string; quantity: number; price: number }

let database: SQLite.SQLiteDatabase | null = null

async function getDatabase(): Promise<SQLite.SQLiteDatabase> {
  if (database) return database

  database = await SQLite.openDatabaseAsync('inventory.db')
  await database.execAsync(`
    CREATE TABLE IF NOT EXISTS items (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      quantity INTEGER NOT NULL,
      price REAL NOT NULL
    )
  `)
  return database
}

async function insertItem(name: string, quantity: number, price: number): Promise<void> {
  const db = await getDatabase()
  await db.runAsync(
    'INSERT INTO items (name, quantity, price) VALUES (?, ?, ?)',
    name,
    quantity,
    price
  )
}

async function updateItem(item: Item): Promise<void> {
  const db = await getDatabase()
  await db.runAsync(
    'UPDATE items SET name = ?, quantity = ?, price = ? WHERE id = ?',
    item.name,
    item.quantity,
    item.price,
    item.id
  )
}

async function deleteItem(id: number): Promise<void> {
  const db = await getDatabase()
  await db.runAsync('DELETE FROM items WHERE id = ?', id)
}

async function getAllItems(): Promise<Item[]> {
  const db = await getDatabase()
  return await db.getAllAsync<Item>('SELECT * FROM items')
}

function AddItemForm({ onItemAdded }: { onItemAdded: () => void }) {
  const [name, setName] = useState('')
  const [quantity, setQuantity] = useState('')
  const [price, setPrice] = useState('')

  async function handleAdd() {
    if (name === '') return

    await insertItem(name, parseInt(quantity) || 0, parseFloat(price) || 0)
    setName('')
    setQuantity('')
    setPrice('')
    onItemAdded()
  }

  return (
    <View style={styles.form}>
      <TextInput style={styles.input} placeholder="Название" value={name} onChangeText={setName} />
      <TextInput style={styles.input} placeholder="Количество" value={quantity} onChangeText={setQuantity} keyboardType="numeric" />
      <TextInput style={styles.input} placeholder="Цена" value={price} onChangeText={setPrice} keyboardType="numeric" />
      <Button title="Добавить" onPress={handleAdd} />
    </View>
  )
}

function EditItemForm({ item, onSaved, onCancel }: { item: Item; onSaved: () => void; onCancel: () => void }) {
  const [name, setName] = useState(item.name)
  const [quantity, setQuantity] = useState(String(item.quantity))
  const [price, setPrice] = useState(String(item.price))

  async function save() {
    await updateItem({
      id: item.id,
      name,
      quantity: parseInt(quantity) || 0,
      price: parseFloat(price) || 0,
    })
    onSaved()
  }

  return (
    <View style={styles.editBox}>
      <Text style={styles.subtitle}>Редактирование</Text>
      <TextInput style={styles.input} placeholder="Название" value={name} onChangeText={setName} />
      <TextInput style={styles.input} placeholder="Количество" value={quantity} onChangeText={setQuantity} keyboardType="numeric" />
      <TextInput style={styles.input} placeholder="Цена" value={price} onChangeText={setPrice} keyboardType="numeric" />
      <Button title="Сохранить" onPress={save} />
      <View style={styles.cancel}>
        <Button title="Отмена" color="gray" onPress={onCancel} />
      </View>
    </View>
  )
}

export default function App() {
  const [items, setItems] = useState<Item[]>([])
  const [editing, setEditing] = useState<Item | null>(null)

  async function loadItems() {
    setItems(await getAllItems())
  }

  useEffect(() => {
    loadItems()
  }, [])

  async function removeItem(id: number) {
    await deleteItem(id)
    await loadItems()
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Инвентарь</Text>

      <AddItemForm onItemAdded={loadItems} />

      {editing !== null && (
        <EditItemForm
          key={editing.id}
          item={editing}
          onSaved={async () => {
            setEditing(null)
            await loadItems()
          }}
          onCancel={() => setEditing(null)}
        />
      )}

      <FlatList
        data={items}
        keyExtractor={(item) => String(item.id)}
        renderItem={({ item }) => (
          <View style={styles.row}>
            <Text style={styles.itemName}>
              {item.name} ×{item.quantity} — {item.price} ₽
            </Text>
            <View style={styles.actions}>
              <Button title="Изменить" onPress={() => setEditing(item)} />
              <Button title="Удалить" color="red" onPress={() => removeItem(item.id)} />
            </View>
          </View>
        )}
      />

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, paddingTop: 60 },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  subtitle: { fontSize: 18, fontWeight: 'bold', marginBottom: 8 },
  form: { marginBottom: 16 },
  editBox: { backgroundColor: '#FFF3E0', padding: 16, borderRadius: 8, marginBottom: 16 },
  input: { borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, padding: 12, marginBottom: 12 },
  cancel: { marginTop: 8 },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 12, borderBottomWidth: 1, borderBottomColor: '#EEEEEE' },
  itemName: { flex: 1, marginRight: 8 },
  actions: { gap: 8 },
})
```

Разберём ключевые моменты:

- `editing` хранит предмет, который сейчас редактируется, или `null`, если форма закрыта.
- `key={editing.id}` пересоздаёт форму при выборе другого предмета — поля заполняются его значениями.
- После сохранения форма закрывается, а список перечитывается из базы.
- Удаление тоже заканчивается вызовом `loadItems()` — экран всегда показывает актуальные данные.

## Резюме

- `SELECT * FROM items` читает все записи и отображает их в `FlatList`.
- `UPDATE ... WHERE id = ?` обновляет одну строку, `DELETE ... WHERE id = ?` удаляет её.
- Форма редактирования получает данные предмета и возвращает изменённые значения через `updateItem`.
- После каждой операции список перечитывается из базы — интерфейс не расходится с данными.
