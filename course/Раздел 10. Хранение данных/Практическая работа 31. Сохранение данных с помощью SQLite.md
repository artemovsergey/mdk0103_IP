# Практическая работа 31. Сохранение данных с помощью SQLite

В большинстве приложений есть данные, которые нужно сохранять: списки покупок, записи расходов, коллекции. В этой работе вы создадите приложение **Инвентарь** (Inventory), которое добавляет предметы в базу данных SQLite и хранит их между запусками.

### Пререквизиты

- Лекция 24 «SQL и базы данных».
- Умение работать с `useState`, `useEffect` и `TextInput`.

### Что вы узнаете

- Как открыть базу данных и создать таблицу.
- Как вынести операции с базой в отдельный слой данных (DAO).
- Как сохранять данные и обновлять список после сохранения.

### Что вы создадите

Приложение «Инвентарь»: форму добавления предмета (название, количество, цена) и список уже добавленных предметов.

## Шаг 2. Открытие базы и создание таблицы

```tsx
import * as SQLite from 'expo-sqlite'

let database: SQLite.SQLiteDatabase | null = null

async function getDatabase(): Promise<SQLite.SQLiteDatabase> {
  if (database) return database

  database = await SQLite.openDatabaseAsync('inventory.db')
  await database.execAsync(`
    CREATE TABLE IF NOT EXISTS items (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      quantity INTEGER NOT NULL,
      price REAL NOT NULL
    )
  `)
  return database
}
```

- Переменная `database` хранит открытое соединение, чтобы не открывать базу заново при каждом действии.
- `CREATE TABLE IF NOT EXISTS` создаёт таблицу один раз — повторные запуски безопасны.
- `AUTOINCREMENT` поручает базе самой присваивать `id` новым строкам.

## Шаг 3. Слой данных (DAO)

Вынесем операции с базой в отдельные функции — так экран не будет знать деталей SQL:

```tsx
type Item = { id: number; name: string; quantity: number; price: number }

async function insertItem(name: string, quantity: number, price: number): Promise<void> {
  const db = await getDatabase()
  await db.runAsync(
    'INSERT INTO items (name, quantity, price) VALUES (?, ?, ?)',
    name,
    quantity,
    price
  )
}

async function getAllItems(): Promise<Item[]> {
  const db = await getDatabase()
  return await db.getAllAsync<Item>('SELECT * FROM items')
}
```

- `Item` описывает строку таблицы: тип совпадает с колонками.
- `insertItem` добавляет запись, `getAllItems` читает все записи.
- Параметры `?` защищают запрос от SQL-инъекций.

## Шаг 4. Форма добавления

```tsx
function AddItemForm({ onItemAdded }: { onItemAdded: () => void }) {
  const [name, setName] = useState('')
  const [quantity, setQuantity] = useState('')
  const [price, setPrice] = useState('')

  async function handleAdd() {
    if (name === '') return

    await insertItem(name, parseInt(quantity) || 0, parseFloat(price) || 0)
    setName('')
    setQuantity('')
    setPrice('')
    onItemAdded()
  }

  return (
    <View style={styles.form}>
      <TextInput style={styles.input} placeholder="Название" value={name} onChangeText={setName} />
      <TextInput style={styles.input} placeholder="Количество" value={quantity} onChangeText={setQuantity} keyboardType="numeric" />
      <TextInput style={styles.input} placeholder="Цена" value={price} onChangeText={setPrice} keyboardType="numeric" />
      <Button title="Добавить" onPress={handleAdd} />
    </View>
  )
}
```

- Три состояния хранят текст из полей формы.
- `parseInt` и `parseFloat` превращают текст в числа; при пустом поле получается `0`.
- После сохранения поля очищаются, а родитель получает сигнал `onItemAdded` — он перечитает список.

## Шаг 5. Главный экран — полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { Button, FlatList, StyleSheet, Text, TextInput, View } from 'react-native'
import * as SQLite from 'expo-sqlite'

type Item = { id: number; name: string; quantity: number; price: number }

let database: SQLite.SQLiteDatabase | null = null

async function getDatabase(): Promise<SQLite.SQLiteDatabase> {
  if (database) return database

  database = await SQLite.openDatabaseAsync('inventory.db')
  await database.execAsync(`
    CREATE TABLE IF NOT EXISTS items (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      quantity INTEGER NOT NULL,
      price REAL NOT NULL
    )
  `)
  return database
}

async function insertItem(name: string, quantity: number, price: number): Promise<void> {
  const db = await getDatabase()
  await db.runAsync(
    'INSERT INTO items (name, quantity, price) VALUES (?, ?, ?)',
    name,
    quantity,
    price
  )
}

async function getAllItems(): Promise<Item[]> {
  const db = await getDatabase()
  return await db.getAllAsync<Item>('SELECT * FROM items')
}

function AddItemForm({ onItemAdded }: { onItemAdded: () => void }) {
  const [name, setName] = useState('')
  const [quantity, setQuantity] = useState('')
  const [price, setPrice] = useState('')

  async function handleAdd() {
    if (name === '') return

    await insertItem(name, parseInt(quantity) || 0, parseFloat(price) || 0)
    setName('')
    setQuantity('')
    setPrice('')
    onItemAdded()
  }

  return (
    <View style={styles.form}>
      <TextInput style={styles.input} placeholder="Название" value={name} onChangeText={setName} />
      <TextInput style={styles.input} placeholder="Количество" value={quantity} onChangeText={setQuantity} keyboardType="numeric" />
      <TextInput style={styles.input} placeholder="Цена" value={price} onChangeText={setPrice} keyboardType="numeric" />
      <Button title="Добавить" onPress={handleAdd} />
    </View>
  )
}

export default function App() {
  const [items, setItems] = useState<Item[]>([])

  async function loadItems() {
    setItems(await getAllItems())
  }

  useEffect(() => {
    loadItems()
  }, [])

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Инвентарь</Text>

      <AddItemForm onItemAdded={loadItems} />

      <FlatList
        data={items}
        keyExtractor={(item) => String(item.id)}
        renderItem={({ item }) => (
          <View style={styles.row}>
            <Text style={styles.itemName}>{item.name}</Text>
            <Text>×{item.quantity}</Text>
            <Text>{item.price} ₽</Text>
          </View>
        )}
      />

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, paddingTop: 60 },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  form: { marginBottom: 24 },
  input: { borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, padding: 12, marginBottom: 12 },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 12, borderBottomWidth: 1, borderBottomColor: '#EEEEEE' },
  itemName: { flex: 1 },
})
```

Разберём ключевые моменты:

- `loadItems` читает всю таблицу и кладёт результат в состояние — список перерисовывается автоматически.
- `useEffect` с пустым массивом зависимостей запускает загрузку один раз при открытии экрана.
- Форма не работает с базой напрямую: она вызывает `insertItem`, а затем `onItemAdded()`.
- `keyExtractor` превращает числовой `id` в строку — ключи списка должны быть строками.

## Резюме

- SQLite хранит структурированные данные на устройстве и переживает перезапуск приложения.
- Модуль `getDatabase` открывает базу один раз и создаёт таблицу при первом запуске.
- DAO-функции скрывают SQL-запросы от интерфейса.
- Параметризованные запросы `?` защищают от SQL-инъекций.
- После записи данные перечитываются, и состояние обновляет список.
