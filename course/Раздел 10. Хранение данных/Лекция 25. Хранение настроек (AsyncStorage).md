# Лекция 25. Хранение настроек (AsyncStorage)

SQL и SQLite — мощный инструмент для структурированных данных. Но когда нужно сохранить пару простых настроек (тема, язык, порядок сортировки), реляционная база данных избыточна. Для таких случаев существует **хранилище «ключ — значение»**: данные сохраняются парами «ключ — значение» и восстанавливаются при следующем запуске. В React Native для этого используется пакет **AsyncStorage**.

## Хранилище «ключ — значение»

Хранилище «ключ — значение» (key-value store) — простейшая база данных из двух колонок: **ключ** (строка-идентификатор) и **значение**. По ключу значение получают мгновенно, без описания таблиц и SQL-запросов.

Такое хранилище подходит для:

- пользовательских настроек: тема, язык, единицы измерения;
- простых флагов: показывать ли обучение при первом запуске;
- небольших данных: последняя выбранная категория, черновик формы.

Для больших списков и сложных связей между данными используйте SQLite (лекция 24).

## Установка

```bash
npx expo install @react-native-async-storage/async-storage
```

## Основные методы

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage'

// Сохранить
await AsyncStorage.setItem('theme', 'dark')

// Прочитать
const theme = await AsyncStorage.getItem('theme') // 'dark' | null

// Удалить
await AsyncStorage.removeItem('theme')

// Очистить всё
await AsyncStorage.clear()
```

- `setItem` и `removeItem` ничего не возвращают, но их тоже ждут через `await`.
- `getItem` возвращает строку или `null`, если ключа ещё нет.
- `clear` удаляет разом все ключи — используйте осторожно.

## Сохранение объектов

`AsyncStorage` хранит только строки. Объекты и массивы сериализуют через `JSON.stringify`, а при чтении разбирают через `JSON.parse`:

```tsx
await AsyncStorage.setItem('user', JSON.stringify({ name: 'Иван', age: 30 }))

const json = await AsyncStorage.getItem('user')
const user = json ? JSON.parse(json) : null
```

При первом запуске ключа ещё нет — `getItem` вернёт `null`, и этот случай нужно обработать.

## Приложение Dessert Release

Приложение показывает список релизов. Кнопка переключает макет между списком и сеткой, а выбор сохраняется в `AsyncStorage`:

```tsx
import { useEffect, useState } from 'react'
import { FlatList, StyleSheet, Text, TouchableOpacity, View } from 'react-native'
import AsyncStorage from '@react-native-async-storage/async-storage'

const releases = [
  { id: '1', name: 'Android 14', year: 2023 },
  { id: '2', name: 'Android 13', year: 2022 },
  { id: '3', name: 'Android 12', year: 2021 },
]

type Layout = 'list' | 'grid'

const STORAGE_KEY = 'layout_preference'

export default function App() {
  const [layout, setLayout] = useState<Layout>('list')
  const [ready, setReady] = useState(false)

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then((value) => {
      if (value === 'list' || value === 'grid') {
        setLayout(value)
      }
      setReady(true)
    })
  }, [])

  async function toggleLayout() {
    const next: Layout = layout === 'list' ? 'grid' : 'list'
    setLayout(next)
    await AsyncStorage.setItem(STORAGE_KEY, next)
  }

  if (!ready) return null

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.title}>Dessert Release</Text>
        <TouchableOpacity onPress={toggleLayout}>
          <Text style={styles.toggle}>{layout === 'list' ? 'Сетка' : 'Список'}</Text>
        </TouchableOpacity>
      </View>

      <FlatList
        data={releases}
        keyExtractor={(item) => item.id}
        numColumns={layout === 'grid' ? 2 : 1}
        key={layout}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <View style={[styles.card, layout === 'grid' && styles.gridCard]}>
            <Text style={styles.cardTitle}>{item.name}</Text>
            <Text>Год: {item.year}</Text>
          </View>
        )}
      />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, paddingTop: 60 },
  header: {
    flexDirection: 'row',
    justifyContent: 'space-between',
    alignItems: 'center',
    padding: 16,
  },
  title: { fontSize: 22, fontWeight: 'bold' },
  toggle: { fontSize: 16, color: '#0057B8' },
  list: { padding: 16 },
  card: {
    borderWidth: 1,
    borderColor: '#DDDDDD',
    borderRadius: 8,
    padding: 16,
    marginBottom: 12,
  },
  gridCard: { flex: 1, margin: 6 },
  cardTitle: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
})
```

Разберём ключевые моменты:

- `useState('list')` задаёт макет по умолчанию, а `useEffect` заменяет его сохранённым значением, если оно есть.
- Флаг `ready` не даёт показать экран до окончания чтения — иначе макет «прыгал» бы с одного на другой.
- `toggleLayout` сначала обновляет состояние (интерфейс реагирует сразу), а затем сохраняет выбор.
- Свойство `key={layout}` заставляет `FlatList` перестроиться при смене числа колонок.
- `numColumns` переключает список на сетку из двух колонок.

## Как это работает

1. При запуске `useEffect` читает сохранённое значение из `AsyncStorage`.
2. Пока значение не прочитано, `ready` равен `false` — экран пуст.
3. Если значение есть, оно устанавливается в состояние.
4. При нажатии кнопки `toggleLayout` состояние меняется и новое значение сохраняется.
5. При следующем запуске приложение «помнит» выбор пользователя.

## Когда использовать AsyncStorage, а когда SQLite

| Критерий | AsyncStorage | SQLite |
|---|---|---|
| Тип данных | Простые настройки, строки | Структурированные таблицы |
| Запросы | Чтение и запись по ключу | SQL-запросы с фильтрацией |
| Объём | Небольшой | Большой |
| Сложность | Простая | Высокая |

## Частые ошибки

- **Забыли `await` при чтении.** Без `await` в переменной окажется промис, а не значение.
- **Читаете значение в теле компонента.** Так чтение запускается при каждом рендере; читайте один раз в `useEffect`.
- **Не обрабатываете `null`.** При первом запуске ключа ещё нет — задайте значение по умолчанию.
- **Храните большой список.** Для структурированных данных используйте SQLite.

## Резюме

- `AsyncStorage` — простое хранилище «ключ — значение» для данных приложения.
- `setItem`, `getItem`, `removeItem` и `clear` — основные методы пакета.
- Данные сохраняются между перезапусками приложения.
- Объекты сериализуются через `JSON.stringify` и `JSON.parse`.
- Для настроек достаточно `AsyncStorage`, для реляционных данных — SQLite.
