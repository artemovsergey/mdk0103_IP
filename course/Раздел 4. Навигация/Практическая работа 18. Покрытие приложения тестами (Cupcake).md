# Практическая работа 18. Покрытие приложения тестами (Cupcake)

В этой работе вы напишете автоматизированные тесты для навигации приложения **Cupcake** — заказа кексов. Тесты будут проверять, что приложение открывается на стартовом экране, что кнопки переводят на нужные экраны и что данные, выбранные пользователем, доходят до итогового экрана.

### Пререквизиты

- Практическая работа 15 — настройка Jest и `@testing-library/react-native`.
- Практическая работа 16 — навигация по стеку экранов.
- Умение создавать состояние через `useState`.

### Что вы узнаете

- Как тестировать приложение, в котором есть `NavigationContainer`.
- Как имитировать нажатия кнопок и проверять появление нового экрана.
- Как проверить, что заблокированная кнопка не выполняет действие.
- Как настроить Jest для библиотек React Navigation.

### Что вы создадите

Приложение **Cupcake** с тремя экранами и файл `__tests__/App.test.tsx` с четырьмя тестами навигации.

## Шаг 1. Создание проекта

```bash
npx create-expo-app@latest cupcake --template blank-typescript
cd cupcake
npx expo install @react-navigation/native @react-navigation/native-stack react-native-screens react-native-safe-area-context
```

## Шаг 2. Приложение Cupcake

Замените содержимое `App.tsx` на готовое приложение с тремя экранами: старт, выбор вкуса и итог заказа.

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { Button, StyleSheet, Text, View } from 'react-native'
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

const FLAVORS = ['Ваниль', 'Шоколад', 'Клубника']

function StartScreen({ navigation }: { navigation: any }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Заказать кекс</Text>
      <Button title="Начать" onPress={() => navigation.navigate('Flavor')} />
    </View>
  )
}

function FlavorScreen({ navigation }: { navigation: any }) {
  const [flavor, setFlavor] = useState<string | null>(null)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Выберите вкус</Text>
      {FLAVORS.map((name) => (
        <Button key={name} title={flavor === name ? `Выбрано: ${name}` : name} onPress={() => setFlavor(name)} />
      ))}
      <Button title="Далее" disabled={flavor === null} onPress={() => navigation.navigate('Summary', { flavor })} />
    </View>
  )
}

function SummaryScreen({ route }: { route: any }) {
  const { flavor } = route.params
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Ваш заказ</Text>
      <Text style={styles.row}>{`Вкус: ${flavor}`}</Text>
    </View>
  )
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Start">
        <Stack.Screen name="Start" component={StartScreen} options={{ title: 'Cupcake' }} />
        <Stack.Screen name="Flavor" component={FlavorScreen} options={{ title: 'Вкус' }} />
        <Stack.Screen name="Summary" component={SummaryScreen} options={{ title: 'Итог' }} />
      </Stack.Navigator>
      <StatusBar style="auto" />
    </NavigationContainer>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 24, gap: 12 },
  title: { fontSize: 24, fontWeight: 'bold', textAlign: 'center', marginBottom: 8 },
  row: { fontSize: 18 },
})
```

## Шаг 3. Установка Jest

Установите те же библиотеки, что и в практической работе 15:

```bash
npm install --save-dev jest-expo jest @types/jest @testing-library/react-native
```

- `jest` — среда запуска тестов.
- `jest-expo` — пресет Jest для проектов Expo.
- `@types/jest` — типы TypeScript для `describe`, `test` и `expect`.
- `@testing-library/react-native` — отрисовка компонентов и имитация действий пользователя.

## Шаг 4. Настройка package.json

Добавьте команду запуска тестов и пресет с настройкой `transformIgnorePatterns`:

```json
{
  "scripts": {
    "test": "jest"
  },
  "jest": {
    "preset": "jest-expo",
    "transformIgnorePatterns": [
      "node_modules/(?!((jest-)?react-native|@react-native(-community)?)|expo(nent)?|@expo(nent)?/.*|@expo-google-fonts/.*|react-navigation|@react-navigation/.*|@sentry/react-native|native-base|react-native-svg)"
    ]
  }
}
```

По умолчанию Jest не преобразует код из `node_modules` — он считает, что пакеты уже готовы к запуску. Библиотеки React Navigation поставляются с современным синтаксисом модулей, поэтому их нужно добавить в исключения `transformIgnorePatterns`. Шаблон выше — официальный пример из документации Expo.

## Шаг 5. Тесты навигации

Каждый тест отрисовывает приложение целиком через `render(<App />)` — вместе с `NavigationContainer`. Это позволяет имитировать реальные действия пользователя и проверять, какой экран появился на месте предыдущего.

```tsx
import { fireEvent, render, screen } from '@testing-library/react-native'

import App from '../App'

describe('Cupcake', () => {
  test('открывается на стартовом экране', () => {
    render(<App />)

    expect(screen.getByText('Заказать кекс')).toBeTruthy()
    expect(screen.queryByText('Выберите вкус')).toBeNull()
  })

  test('кнопка «Начать» открывает экран выбора вкуса', () => {
    render(<App />)

    fireEvent.press(screen.getByText('Начать'))

    expect(screen.getByText('Выберите вкус')).toBeTruthy()
    expect(screen.queryByText('Заказать кекс')).toBeNull()
  })

  test('кнопка «Далее» не работает, пока вкус не выбран', () => {
    render(<App />)
    fireEvent.press(screen.getByText('Начать'))

    fireEvent.press(screen.getByText('Далее'))

    expect(screen.getByText('Выберите вкус')).toBeTruthy()
    expect(screen.queryByText('Ваш заказ')).toBeNull()
  })

  test('после выбора вкуса показывается итог заказа', () => {
    render(<App />)
    fireEvent.press(screen.getByText('Начать'))

    fireEvent.press(screen.getByText('Ваниль'))
    fireEvent.press(screen.getByText('Далее'))

    expect(screen.getByText('Ваш заказ')).toBeTruthy()
    expect(screen.getByText('Вкус: Ваниль')).toBeTruthy()
  })
})
```

Разберём тесты:

- Первый тест проверяет начальный маршрут: на экране есть текст стартового экрана и нет текста экрана выбора вкуса.
- Второй тест нажимает «Начать» и убеждается, что появился заголовок нового экрана, а текст старого исчез.
- Третий тест нажимает заблокированную кнопку «Далее»: `fireEvent` не выполняет события на заблокированных элементах, поэтому экран остаётся прежним.
- Четвёртый тест проходит весь путь: выбор вкуса, затем «Далее». Проверяется не только появление итогового экрана, но и то, что выбранный вкус доехал до него через параметры маршрута.

## Резюме

- Тесты навигации отрисовывают приложение вместе с `NavigationContainer` — никаких дополнительных настроек не требуется.
- `fireEvent.press` имитирует нажатие, а `screen.getByText` проверяет, какой экран появился.
- `queryByText` возвращает `null`, если элемента нет, — так проверяют, что старый экран исчез.
- `fireEvent` не срабатывает на заблокированных кнопках — это тоже полезное поведение для теста.
- `transformIgnorePatterns` подключает к преобразованию пакеты React Navigation.
