# Практическая работа 16. Практика навигации (Lunch Tray)

В этой работе вы закрепите навыки навигации, создав приложение **Lunch Tray** — пошаговый заказ обеда. Пользователь проходит цепочку экранов, на каждом выбирает один вариант, а в конце видит итоговый чек из всех своих выборов.

### Пререквизиты

- Лекция 16 «Навигация».
- Умение создавать состояние через `useState`.
- Умение настраивать `NavigationContainer` и `Stack.Navigator`.

### Что вы узнаете

- Как организовать пошаговый поток из нескольких экранов.
- Как накапливать выбранные данные в параметрах маршрута.
- Как работает кнопка «Назад» в заголовке экрана.
- Как вернуться к началу заказа и как отправить готовый заказ.

### Что вы создадите

Приложение **Lunch Tray** с пятью экранами: старт, основное блюдо, гарнир, напиток и итоговый чек.

## Обзор потока экранов

```
Start → Entree → SideDish → Accompaniment → Checkout
```

- **Start** — приветствие и кнопка «Начать заказ»; **Entree**, **SideDish**, **Accompaniment** — три экрана выбора.
- **Checkout** — чек, отправка заказа и кнопка «Новый заказ».

Из любого шага можно вернуться на шаг назад кнопкой «Назад» в заголовке — это отмена текущего шага.

## Шаг 1. Создание проекта

Создайте приложение Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest lunch-tray --template blank-typescript
cd lunch-tray
npx expo start
```

Все изменения этой работы вносятся в файл `App.tsx` — мы создадим его целиком на шаге 7.

## Шаг 2. Установка React Navigation

Выполните команды в папке проекта:

```
npx expo install @react-navigation/native @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context
```

- `@react-navigation/native` — ядро навигации.
- `@react-navigation/native-stack` — навигатор стека: каждый новый экран кладётся поверх предыдущего.
- `react-native-screens` и `react-native-safe-area-context` — вспомогательные библиотеки, которые используют экраны навигации.

## Шаг 3. Передача данных между экранами

Выбранные блюда накапливаются в параметрах маршрута. На первом экране выбора:

```tsx
navigation.navigate('SideDish', { entree })
```

На следующих экранах старые параметры объединяются с новой выборкой:

```tsx
navigation.navigate('Checkout', { ...route.params, accompaniment })
```

Приём `{ ...route.params, новое_поле }` означает: «возьми всё, что уже выбрано, и добавь новый пункт». К экрану `Checkout` в `route.params` собран весь заказ.

## Шаг 4. Общий экран выбора

Все четыре экрана выбора устроены одинаково, поэтому создадим один переиспользуемый компонент `SelectionScreen`:

```tsx
function SelectionScreen({ title, options, onNext }: { title: string; options: string[]; onNext: (option: string) => void }) {
  const [selected, setSelected] = useState<string | null>(null)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>{title}</Text>
      <View style={styles.options}>
        {options.map((option) => (
          <Button
            key={option}
            title={selected === option ? `Выбрано: ${option}` : option}
            onPress={() => setSelected(option)}
          />
        ))}
      </View>
      <Button title="Далее" disabled={selected === null} onPress={() => onNext(selected!)} />
    </View>
  )
}
```

- Компонент сам хранит состояние `selected` — выбранный вариант.
- Кнопка «Далее» заблокирована, пока пользователь ничего не выбрал.
- Выбранный вариант выделяется текстом «Выбрано: …».

## Шаг 5. Экран чека

Чек показывает все выбранные блюда и умеет отправлять заказ через системный диалог `Share`:

```tsx
function CheckoutScreen({ navigation, route }: { navigation: any; route: any }) {
  const { entree, sideDish, accompaniment } = route.params

  const shareOrder = async () => {
    await Share.share({ message: `Заказ: ${entree}, ${sideDish}, ${accompaniment}` })
  }
  // далее — разметка экрана
}
```

Кнопка «Новый заказ» вызывает `navigation.popToTop()` и возвращает пользователя к стартовому экрану.

## Шаг 6. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { Button, Share, StyleSheet, Text, View } from 'react-native'
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

function SelectionScreen({ title, options, onNext }: { title: string; options: string[]; onNext: (option: string) => void }) {
  const [selected, setSelected] = useState<string | null>(null)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>{title}</Text>
      <View style={styles.options}>
        {options.map((option) => (
          <Button
            key={option}
            title={selected === option ? `Выбрано: ${option}` : option}
            onPress={() => setSelected(option)}
          />
        ))}
      </View>
      <Button title="Далее" disabled={selected === null} onPress={() => onNext(selected!)} />
    </View>
  )
}

function StartScreen({ navigation }: { navigation: any }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Добро пожаловать в Lunch Tray</Text>
      <Text style={styles.subtitle}>Соберите свой обед за четыре шага</Text>
      <Button title="Начать заказ" onPress={() => navigation.navigate('Entree')} />
    </View>
  )
}

function EntreeScreen({ navigation }: { navigation: any }) {
  return (
    <SelectionScreen
      title="Выберите основное блюдо"
      options={['Сэндвич с индейкой', 'Овощная лазанья', 'Салат с тунцом']}
      onNext={(entree) => navigation.navigate('SideDish', { entree })}
    />
  )
}

function SideDishScreen({ navigation, route }: { navigation: any; route: any }) {
  return (
    <SelectionScreen
      title="Выберите гарнир"
      options={['Картофель фри', 'Салат', 'Суп']}
      onNext={(sideDish) => navigation.navigate('Accompaniment', { ...route.params, sideDish })}
    />
  )
}

function AccompanimentScreen({ navigation, route }: { navigation: any; route: any }) {
  return (
    <SelectionScreen
      title="Выберите напиток"
      options={['Чай', 'Кофе', 'Лимонад']}
      onNext={(accompaniment) =>
        navigation.navigate('Checkout', { ...route.params, accompaniment })
      }
    />
  )
}

function CheckoutScreen({ navigation, route }: { navigation: any; route: any }) {
  const { entree, sideDish, accompaniment } = route.params

  const shareOrder = async () => {
    await Share.share({ message: `Заказ: ${entree}, ${sideDish}, ${accompaniment}` })
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Ваш заказ</Text>
      <Text style={styles.row}>{`Основное: ${entree}`}</Text>
      <Text style={styles.row}>{`Гарнир: ${sideDish}`}</Text>
      <Text style={styles.row}>{`Напиток: ${accompaniment}`}</Text>
      <View style={styles.buttons}>
        <Button title="Отправить заказ" onPress={shareOrder} />
        <Button title="Новый заказ" onPress={() => navigation.popToTop()} />
      </View>
    </View>
  )
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Start">
        <Stack.Screen
          name="Start"
          component={StartScreen}
          options={{ title: 'Lunch Tray', headerBackVisible: false }}
        />
        <Stack.Screen name="Entree" component={EntreeScreen} options={{ title: 'Основное блюдо' }} />
        <Stack.Screen name="SideDish" component={SideDishScreen} options={{ title: 'Гарнир' }} />
        <Stack.Screen
          name="Accompaniment"
          component={AccompanimentScreen}
          options={{ title: 'Напиток' }}
        />
        <Stack.Screen name="Checkout" component={CheckoutScreen} options={{ title: 'Чек' }} />
      </Stack.Navigator>
      <StatusBar style="auto" />
    </NavigationContainer>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 24, gap: 12 },
  title: { fontSize: 24, fontWeight: 'bold', textAlign: 'center', marginBottom: 8 },
  subtitle: { fontSize: 16, textAlign: 'center', color: '#555555' },
  options: { gap: 8 },
  row: { fontSize: 18 },
  buttons: { gap: 12, marginTop: 16 },
})
```

## Проверьте работу

1. Запустите приложение и нажмите «Начать заказ» — откроется экран «Основное блюдо».
2. Выберите блюдо: кнопка «Далее» станет активной, а на выбранной кнопке появится пометка «Выбрано: …».
3. Нажмите «Далее» и пройдите гарнир и напиток — в конце появится чек со всеми тремя пунктами, а «Назад» на экране напитка вернёт на шаг назад.
4. Нажмите «Новый заказ» в чеке — приложение вернётся на стартовый экран, история экранов очистится.
5. Нажмите «Отправить заказ» — откроется системный диалог с текстом заказа.

## Резюме

- Пошаговый поток — это стек экранов: каждый следующий экран кладётся поверх предыдущего.
- Данные накапливаются в параметрах маршрута приёмом `{ ...route.params, новое_поле }`.
- Один переиспользуемый компонент `SelectionScreen` заменяет четыре похожих экрана.
- Кнопка «Назад» в заголовке работает как отмена шага, а `popToTop()` возвращает к началу заказа и очищает историю.
