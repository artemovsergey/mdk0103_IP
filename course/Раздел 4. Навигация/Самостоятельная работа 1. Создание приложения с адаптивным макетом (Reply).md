# Самостоятельная работа 1. Создание приложения с адаптивным макетом (Reply)

В практической работе 17 вы начали делать почтовый клиент **Reply** адаптивным: на телефоне письмо открывается на отдельном экране, а на широком экране список и письмо показываются рядом. В этой самостоятельной работе вы доведёте макет до канонического вида **«список + подробности»** (list-detail) и сделаете его поведение аккуратным на всех размерах окна.

### Пререквизиты

- Лекция 16 «Навигация (Capcake)» и практическая работа 17.
- Умение получать ширину окна через `useWindowDimensions`.
- Умение хранить состояние (`useState`) и строить списки (`FlatList`).

### Что вы узнаете

- Как выбрать макет по классу размера окна.
- Как построить макет «список + подробности» для широких экранов.
- Как сохранить выбранное письмо при изменении ширины окна.

### Что вы создадите

Приложение **Reply**, которое перестраивает макет при изменении ширины окна:

- **compact** (меньше 600) — только список писем, письмо открывается на отдельном экране;
- **medium** (от 600 до 840) — список и письмо рядом, панель списка шириной 280;
- **expanded** (больше 840) — список и письмо рядом, панель списка шириной 360.

## Задание

Создайте приложение Reply, которое:

- на узком экране показывает только список и открывает письмо на отдельном экране стека;
- на широком экране показывает список и текст письма одновременно;
- подсвечивает выбранное письмо и сохраняет выбор при изменении ширины окна.

## Классы размера окна

Ширину окна возвращает хук `useWindowDimensions`. Он обновляется автоматически при повороте устройства и при изменении размера окна браузера:

```tsx
type SizeClass = 'compact' | 'medium' | 'expanded'

function useSizeClass(): SizeClass {
  const { width } = useWindowDimensions()
  if (width < 600) return 'compact'
  if (width < 840) return 'medium'
  return 'expanded'
}
```

На компактном экране работает навигация по стеку, на остальных — макет «список + подробности».

## Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { FlatList, Pressable, StyleSheet, Text, useWindowDimensions, View } from 'react-native'
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

type Email = { id: string; subject: string; sender: string; body: string }
type SizeClass = 'compact' | 'medium' | 'expanded'

const EMAILS: Email[] = [
  { id: '1', subject: 'Расписание на неделю', sender: 'Учебная часть', body: 'Занятия начинаются в 8:30, во вторник вместо лекции практическая работа.' },
  { id: '2', subject: 'Макет приложения', sender: 'Анна Петрова', body: 'Прикрепила макет экрана входа, посмотрите до пятницы.' },
  { id: '3', subject: 'Встреча команды', sender: 'Иван Смирнов', body: 'Обсуждаем навигацию и адаптивный макет сегодня в 16:00.' },
]

function useSizeClass(): SizeClass {
  const { width } = useWindowDimensions()
  if (width < 600) return 'compact'
  if (width < 840) return 'medium'
  return 'expanded'
}

function EmailList({ selectedId, onSelect }: { selectedId?: string; onSelect: (email: Email) => void }) {
  return (
    <FlatList
      data={EMAILS}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable style={[styles.card, selectedId === item.id && styles.cardSelected]} onPress={() => onSelect(item)}>
          <Text style={styles.cardTitle}>{item.subject}</Text>
          <Text style={styles.cardSender}>{item.sender}</Text>
        </Pressable>
      )}
    />
  )
}

function EmailDetails({ email }: { email: Email }) {
  return (
    <View>
      <Text style={styles.cardTitle}>{email.subject}</Text>
      <Text style={styles.cardSender}>{email.sender}</Text>
      <Text style={styles.body}>{email.body}</Text>
    </View>
  )
}

function InboxScreen({ navigation }: { navigation: any }) {
  return <EmailList onSelect={(email) => navigation.navigate('Email', { email })} />
}

function EmailScreen({ route }: { route: any }) {
  const { email } = route.params
  return <EmailDetails email={email} />
}

function MasterDetailLayout({ listWidth, selected, onSelect }: { listWidth: number; selected: Email | null; onSelect: (email: Email) => void }) {
  return (
    <View style={styles.row}>
      <View style={[styles.listPane, { width: listWidth }]}>
        <EmailList selectedId={selected?.id} onSelect={onSelect} />
      </View>
      <View style={styles.detailPane}>
        {selected === null ? <Text style={styles.placeholder}>Выберите письмо слева</Text> : <EmailDetails email={selected} />}
      </View>
    </View>
  )
}

export default function App() {
  const sizeClass = useSizeClass()
  const [selected, setSelected] = useState<Email | null>(null)

  if (sizeClass === 'compact') {
    return (
      <>
        <NavigationContainer>
          <Stack.Navigator>
            <Stack.Screen name="Inbox" component={InboxScreen} options={{ title: 'Входящие' }} />
            <Stack.Screen name="Email" component={EmailScreen} options={{ title: 'Письмо' }} />
          </Stack.Navigator>
        </NavigationContainer>
        <StatusBar style="auto" />
      </>
    )
  }

  return (
    <>
      <MasterDetailLayout listWidth={sizeClass === 'expanded' ? 360 : 280} selected={selected} onSelect={setSelected} />
      <StatusBar style="auto" />
    </>
  )
}

const styles = StyleSheet.create({
  row: { flex: 1, flexDirection: 'row', backgroundColor: '#F5F5F5' },
  listPane: { borderRightWidth: 1, borderRightColor: '#DDDDDD' },
  detailPane: { flex: 1, padding: 24 },
  placeholder: { color: '#777777', textAlign: 'center', marginTop: 24 },
  card: { padding: 16, borderBottomWidth: 1, borderBottomColor: '#EEEEEE', backgroundColor: '#FFFFFF' },
  cardSelected: { backgroundColor: '#E3F0FF' },
  cardTitle: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
  cardSender: { color: '#555555' },
  body: { marginTop: 16, fontSize: 16, lineHeight: 24 },
})
```

Разберём ключевые моменты:

- `useSizeClass` возвращает три класса размера — оформление перестраивается плавно.
- Ширина панели списка вычисляется один раз в `App`: `sizeClass === 'expanded' ? 360 : 280`.
- Выбранное письмо хранится в `App`, поэтому переключение макетов не сбрасывает выбор.
- Список и панель подробностей — независимые компоненты, которые знают только о своих свойствах.

## Проверка работы

1. Запустите приложение командой `npx expo start` и откройте его в браузере (клавиша `w`).
2. Сузьте окно до ширины меньше 600 — виден только список писем.
3. Нажмите письмо — откроется экран «Письмо» с текстом, кнопка «Назад» вернёт к списку.
4. Расширьте окно больше 600 — справа появится панель с подсказкой «Выберите письмо слева».
5. Нажмите письмо в списке — текст откроется справа, а строка подсветится.
6. Расширьте окно больше 840 — панель списка станет шире, а затем сузьте и снова расширьте окно: выбранное письмо останется подсвеченным.

## Требования к работе

- Проект создан на Expo с шаблоном TypeScript; библиотеки установлены через `npx expo install`.
- Адаптивность реализована через `useWindowDimensions`, без фиксированных размеров всего макета.
- Определены три класса размера окна и два макета: «только список» и «список + подробности».
- На широком экране список и письмо видны одновременно, выбранное письмо подсвечивается.
- Состояние выбранного письма хранится в главном компоненте и не теряется при изменении размера окна.
- Код разделён на компоненты, интерфейс аккуратен на всех размерах.

## Резюме

- `useWindowDimensions` даёт ширину окна и обновляется при изменении размера и повороте устройства.
- Класс размера окна (`compact`, `medium`, `expanded`) определяет, какой макет показать.
- Канонический макет «список + подробности» удобен для больших экранов: список и письмо видны одновременно.
- Состояние, поднятое в главный компонент, не сбрасывается при переключении макетов.
- Адаптивность проверяют, изменяя ширину окна браузера и поворачивая телефон или планшет.
