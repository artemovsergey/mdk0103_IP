# Практическая работа 20. Асинхронность в React Native

В этой работе вы научитесь загружать данные из интернета и показывать их в приложении. Вы создадите приложение **Пользователи**, которое при запуске запрашивает список с сервера, показывает индикатор загрузки, умеет обрабатывать ошибки и обновлять данные по кнопке.

### Пререквизиты

- Лекция 10 «Асинхронность» и практическая работа 6.
- Умение создавать состояние через `useState`.
- Умение выводить списки через `FlatList`.

### Что вы узнаете

- Как выполнять запрос к серверу через `fetch` внутри `async`-функции.
- Как запускать загрузку данных при открытии экрана через `useEffect`.
- Как показывать состояния загрузки и ошибки.
- Как повторно запросить данные по кнопке.

### Что вы создадите

Приложение **Пользователи**: список имён и адресов электронной почты, загруженный с учебного сервера `jsonplaceholder.typicode.com`.

## Шаг 1. Создание проекта

```bash
npx create-expo-app@latest async-users --template blank-typescript
cd async-users
npx expo start
```

Все изменения вносятся в файл `App.tsx`.

## Шаг 2. Данные и адрес API

Опишем, что приходит от сервера, и запомним адрес запроса в константе:

```tsx
type User = {
  id: number
  name: string
  email: string
}

const API_URL = 'https://jsonplaceholder.typicode.com/users'
```

- Сервер вернёт JSON-массив объектов с полями `id`, `name`, `email` и другими, но нам нужны только эти три.
- `API_URL` — адрес учебного API, который отдаёт тестовые данные.

## Шаг 3. Состояния экрана

Для загрузки из сети нужны три состояния: данные, признак загрузки и текст ошибки.

```tsx
const [users, setUsers] = useState<User[]>([])
const [loading, setLoading] = useState(true)
const [error, setError] = useState('')
```

- `users` — то, что показываем в списке; изначально пусто.
- `loading` — `true`, пока запрос выполняется; тогда на экране индикатор.
- `error` — пустая строка, если ошибки нет; иначе — понятное сообщение.

## Шаг 4. Функция загрузки

Запрос выполняет асинхронная функция. Она не блокирует интерфейс: пока `await fetch(...)` ждёт ответ, приложение продолжает отрисовываться.

```tsx
const loadUsers = async () => {
  setLoading(true)
  setError('')

  try {
    const response = await fetch(API_URL)

    if (!response.ok) {
      throw new Error(`Сервер вернул код ${response.status}`)
    }

    const data: User[] = await response.json()
    setUsers(data)
  } catch (e) {
    setError(e instanceof Error ? e.message : 'Не удалось загрузить данные')
  } finally {
    setLoading(false)
  }
}
```

- Перед запросом сбрасываем прошлую ошибку и включаем индикатор.
- `await fetch(API_URL)` возвращает ответ сервера — промис.
- `response.ok` равен `false` при ошибке сервера (например, 404), тогда мы выбрасываем исключение.
- `await response.json()` превращает тело ответа в массив объектов.
- `catch` показывает сообщение об ошибке, `finally` выключает индикатор в любом случае.

## Шаг 5. Загрузка при старте и кнопка обновления

Чтобы список загрузился сразу при открытии приложения, вызовем функцию в `useEffect`:

```tsx
useEffect(() => {
  loadUsers()
}, [])
```

Пустой массив зависимостей означает: «выполнить один раз после первого показа экрана». Кнопка «Обновить данные» повторяет тот же запрос в любой момент — она привязана к `onPress={loadUsers}`.

## Шаг 6. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { ActivityIndicator, Button, FlatList, StyleSheet, Text, View } from 'react-native'

type User = {
  id: number
  name: string
  email: string
}

const API_URL = 'https://jsonplaceholder.typicode.com/users'

export default function App() {
  const [users, setUsers] = useState<User[]>([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState('')

  const loadUsers = async () => {
    setLoading(true)
    setError('')

    try {
      const response = await fetch(API_URL)

      if (!response.ok) {
        throw new Error(`Сервер вернул код ${response.status}`)
      }

      const data: User[] = await response.json()
      setUsers(data)
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Не удалось загрузить данные')
    } finally {
      setLoading(false)
    }
  }

  useEffect(() => {
    loadUsers()
  }, [])

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Пользователи</Text>

      {loading && <ActivityIndicator size="large" color="#0057B8" />}

      {!loading && error !== '' && (
        <View style={styles.center}>
          <Text style={styles.error}>{error}</Text>
          <Button title="Повторить" onPress={loadUsers} />
        </View>
      )}

      {!loading && error === '' && (
        <FlatList
          data={users}
          keyExtractor={(item) => String(item.id)}
          renderItem={({ item }) => (
            <View style={styles.card}>
              <Text style={styles.name}>{item.name}</Text>
              <Text style={styles.email}>{item.email}</Text>
            </View>
          )}
        />
      )}

      <View style={styles.footer}>
        <Button title="Обновить данные" onPress={loadUsers} disabled={loading} />
      </View>

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', padding: 16, paddingTop: 48 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 12 },
  center: { alignItems: 'center', gap: 12, marginTop: 24 },
  error: { color: '#C62828', textAlign: 'center' },
  card: { backgroundColor: '#FFFFFF', borderRadius: 8, padding: 16, marginBottom: 8 },
  name: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
  email: { color: '#555555' },
  footer: { marginTop: 8 },
})
```

Разберём ключевые моменты:

- Экран показывает ровно одно из трёх состояний: индикатор, сообщение об ошибке или список.
- `ActivityIndicator` — встроенный компонент-крутилка; показывается, пока `loading` равен `true`.
- При ошибке появляется кнопка «Повторить» — она вызывает ту же функцию загрузки.
- Кнопка «Обновить данные» заблокирована во время загрузки, чтобы не запускать два запроса одновременно.
- `keyExtractor` превращает числовой `id` в строку — ключи списка должны быть строками.

## Проверьте работу

1. Запустите приложение — сначала появится индикатор загрузки, затем список из десяти пользователей.
2. Нажмите «Обновить данные» — индикатор появится снова, а список обновится.
3. Временно замените `API_URL` на `https://jsonplaceholder.typicode.com/unknown` — появится сообщение «Сервер вернул код 404» и кнопка «Повторить».
4. Верните правильный адрес и нажмите «Повторить» — загрузка пройдёт успешно.
5. Обратите внимание: пока идёт запрос, приложение не «зависает» — кнопки и прокрутка работают.

## Резюме

- `fetch` возвращает промис, поэтому запрос выполняют в `async`-функции через `await`.
- `try` / `catch` / `finally` разделяют успех, ошибку и завершение загрузки.
- На экране одновременно живут три состояния: индикатор загрузки, ошибка и данные.
- `useEffect` с пустым массивом зависимостей запускает загрузку один раз при открытии экрана.
- Повторная загрузка — это просто повторный вызов той же асинхронной функции по кнопке.
