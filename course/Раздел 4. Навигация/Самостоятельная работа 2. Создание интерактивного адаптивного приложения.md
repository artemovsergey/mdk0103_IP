# Самостоятельная работа 2. Создание интерактивного адаптивного приложения

В этой самостоятельной работе вы создадите спортивное приложение **Sports** — список видов спорта с подробным описанием. На телефоне пользователь видит список и открывает подробности нажатием, а на широком экране список и описание располагаются рядом. Приложение интерактивное: выбранный вид спорта подсвечивается, а кнопка «Назад» появляется только там, где она действительно нужна.

### Пререквизиты

- Самостоятельная работа 1 «Создание приложения с адаптивным макетом».
- Умение получать ширину окна через `useWindowDimensions`.
- Умение создавать состояние (`useState`) и списки (`FlatList`).

### Что вы узнаете

- Как определить подходящий макет для большого экрана.
- Как показать список и подробности рядом и подсветить выбор.
- Как управлять поведением кнопки «Назад» на разных макетах.

### Что вы создадите

Приложение **Sports** из трёх частей: список видов спорта, панель подробностей и панель приложения с заголовком. На узком экране части показываются по очереди, на широком — список и подробности одновременно.

## Задание

Создайте приложение Sports, которое:

- на узком экране (меньше 600) показывает список, а по нажатию — подробности выбранного вида спорта;
- на широком экране (600 и больше) показывает список и подробности рядом, без смены экрана;
- подсвечивает выбранную строку и сохраняет выбор при изменении размера окна;
- показывает кнопку «Назад» только на узком экране в режиме подробностей.

## Тип содержимого

Тип содержимого определяем по ширине окна:

```tsx
type ContentType = 'ListOnly' | 'ListAndDetail'

function useContentType(): ContentType {
  const { width } = useWindowDimensions()
  return width < 600 ? 'ListOnly' : 'ListAndDetail'
}
```

- **ListOnly** — на экране что-то одно: список или подробности.
- **ListAndDetail** — список и подробности рядом.

## Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { FlatList, Pressable, StyleSheet, Text, useWindowDimensions, View } from 'react-native'

type Sport = { id: string; name: string; description: string }
type ContentType = 'ListOnly' | 'ListAndDetail'

const SPORTS: Sport[] = [
  { id: '1', name: 'Футбол', description: 'Командная игра с мячом: две команды стараются забить гол в ворота соперника.' },
  { id: '2', name: 'Теннис', description: 'Игра с ракеткой и мячом на корте: соперники перебрасывают мяч через сетку.' },
  { id: '3', name: 'Плавание', description: 'Водный вид спорта: спортсмен преодолевает дистанцию разными стилями.' },
]

function useContentType(): ContentType {
  const { width } = useWindowDimensions()
  return width < 600 ? 'ListOnly' : 'ListAndDetail'
}

function SportsDetail({ sport }: { sport: Sport | null }) {
  if (!sport) {
    return <Text style={styles.hint}>Выберите вид спорта</Text>
  }
  return (
    <>
      <Text style={styles.title}>{sport.name}</Text>
      <Text style={styles.body}>{sport.description}</Text>
    </>
  )
}

function SportsList({ selected, onSportPressed }: { selected: Sport | null; onSportPressed: (sport: Sport) => void }) {
  return (
    <FlatList
      data={SPORTS}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable
          style={[styles.item, selected?.id === item.id && styles.itemSelected]}
          onPress={() => onSportPressed(item)}
        >
          <Text style={styles.itemText}>{item.name}</Text>
        </Pressable>
      )}
    />
  )
}

function SportsListAndDetails({ selected, onSelect }: { selected: Sport | null; onSelect: (sport: Sport) => void }) {
  return (
    <View style={styles.row}>
      <View style={styles.listPane}>
        <SportsList selected={selected} onSportPressed={onSelect} />
      </View>
      <View style={styles.detailPane}>
        <SportsDetail sport={selected} />
      </View>
    </View>
  )
}

function SportsAppBar({ isDetail, onBack }: { isDetail: boolean; onBack: () => void }) {
  return (
    <View style={styles.appBar}>
      {isDetail && (
        <Pressable onPress={onBack}>
          <Text style={styles.back}>Назад</Text>
        </Pressable>
      )}
      <Text style={styles.appBarTitle}>Sports</Text>
    </View>
  )
}

export default function App() {
  const contentType = useContentType()
  const [selected, setSelected] = useState<Sport | null>(null)

  const isDetail = contentType === 'ListOnly' && selected !== null

  return (
    <View style={styles.container}>
      <SportsAppBar isDetail={isDetail} onBack={() => setSelected(null)} />

      {contentType === 'ListAndDetail' ? (
        <SportsListAndDetails selected={selected} onSelect={setSelected} />
      ) : isDetail ? (
        <View style={styles.detailPane}>
          <SportsDetail sport={selected} />
        </View>
      ) : (
        <SportsList selected={selected} onSportPressed={setSelected} />
      )}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#F5F5F5' },
  appBar: { flexDirection: 'row', alignItems: 'center', gap: 16, padding: 16, backgroundColor: '#3F51B5' },
  appBarTitle: { color: '#FFFFFF', fontSize: 20, fontWeight: 'bold' },
  back: { color: '#FFFFFF', fontSize: 16 },
  row: { flex: 1, flexDirection: 'row' },
  listPane: { width: 320, borderRightWidth: 1, borderRightColor: '#DDDDDD' },
  detailPane: { flex: 1, padding: 24 },
  item: { padding: 16, borderBottomWidth: 1, borderBottomColor: '#EEEEEE', backgroundColor: '#FFFFFF' },
  itemSelected: { backgroundColor: '#E8EAF6' },
  itemText: { fontSize: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 16 },
  body: { fontSize: 16, lineHeight: 24 },
  hint: { fontSize: 16, color: '#888888' },
})
```

Разберём ключевые моменты:

- `useContentType` возвращает тип содержимого по ширине окна: `ListOnly` или `ListAndDetail`.
- Состояние `selected` хранится в `App`, поэтому выбор сохраняется при переключении макетов и изменении размера окна.
- `isDetail` управляет кнопкой «Назад»: на широком макете она не показывается.
- `selected?.id === item.id` подсвечивает выбранную строку списка, а `SportsDetail` показывает подсказку, пока ничего не выбрано.

## Проверка работы

1. Запустите приложение командой `npx expo start` и откройте его в браузере (клавиша `w`).
2. Сузьте окно меньше 600 — виден только список видов спорта.
3. Нажмите «Футбол» — откроются подробности, сверху появится кнопка «Назад».
4. Нажмите «Назад» — снова откроется список, выбор сбросится.
5. Расширьте окно больше 600 — список и подробности окажутся рядом, кнопка «Назад» исчезнет.
6. Нажмите «Теннис» — строка подсветится, а описание появится справа без смены экрана.

## Требования к работе

- Проект создан на Expo с шаблоном TypeScript и запускается командой `npx expo start`.
- Адаптивность реализована через `useWindowDimensions`; жёстко задана только ширина панели списка.
- Есть два макета: `ListOnly` для узкого экрана и `ListAndDetail` для широкого.
- На широком экране список и подробности видны одновременно, выбранный элемент подсвечивается.
- На узком экране кнопка «Назад» возвращает к списку; на широком кнопки «Назад» нет.
- Код разделён на компоненты `SportsList`, `SportsDetail`, `SportsListAndDetails`, `SportsAppBar`.

## Резюме

- Канонический макет «список + подробности» подходит для больших экранов.
- `useWindowDimensions` определяет тип содержимого и обновляется при изменении размера окна.
- Подсветка выбранного элемента делает интерактивность понятной пользователю.
- Поведение кнопки «Назад» зависит от текущего макета: на широком экране она не нужна.
- Состояние, поднятое в главный компонент, сохраняется при переходе между макетами.
