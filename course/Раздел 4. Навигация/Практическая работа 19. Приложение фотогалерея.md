# Практическая работа 19. Приложение фотогалерея

В этой работе вы создадите приложение **Фотогалерея**: сетку фотографий, которые можно открыть крупно на весь экран. Вы потренируетесь выводить списки в несколько колонок, загружать изображения по ссылке и показывать модальное окно поверх основного экрана.

### Пререквизиты

- Лекция 12 «Добавление изображений».
- Умение создавать состояние через `useState`.
- Умение выводить списки через `FlatList`.

### Что вы узнаете

- Как вывести сетку изображений с помощью `FlatList` и `numColumns`.
- Как загрузить изображение по ссылке и как подписать его.
- Как открыть фотографию крупно в модальном окне.
- Как передать данные из элемента списка в модальное окно.

### Что вы создадите

Приложение **Фотогалерея** — сетка из шести фотографий с подписями и полноэкранным просмотром.

## Шаг 1. Создание проекта

```bash

cd photo-gallery

```

## Шаг 2. Данные фотографий

Опишем фотографию типом и соберём массив данных:

```tsx
type Photo = {
  id: string
  title: string
  uri: string
}

const PHOTOS: Photo[] = [
  { id: '1', title: 'Горное озеро', uri: 'https://picsum.photos/id/1018/600/400' },
  { id: '2', title: 'Северное сияние', uri: 'https://picsum.photos/id/1015/600/400' },
  { id: '3', title: 'Туманная долина', uri: 'https://picsum.photos/id/1016/600/400' },
  { id: '4', title: 'Вечерний город', uri: 'https://picsum.photos/id/1011/600/400' },
  { id: '5', title: 'Лесная тропа', uri: 'https://picsum.photos/id/1019/600/400' },
  { id: '6', title: 'Морской берег', uri: 'https://picsum.photos/id/1013/600/400' },

```

Поле `uri` — адрес изображения в интернете, `title` — подпись. Вместо ссылок можно использовать и локальные файлы из папки `assets` — тогда источник задаётся через `require('./assets/photo.png')`.

## Шаг 3. Сетка фотографий

`FlatList` умеет рисовать несколько колонок. Добавьте свойство `numColumns={2}` — и список превратится в сетку:

```tsx
<FlatList
  data={PHOTOS}
  keyExtractor={(item) => item.id}
  numColumns={2}
  columnWrapperStyle={styles.column}
  contentContainerStyle={styles.list}
  renderItem={({ item }) => (
    <Pressable style={styles.card} onPress={() => setSelected(item)}>
      <Image source={{ uri: item.uri }} style={styles.thumbnail} />
      <Text style={styles.caption}>{item.title}</Text>
    </Pressable>
  )}
/>
```

- `numColumns={2}` — две карточки в строке.
- `columnWrapperStyle` — промежуток между колонками.
- Каждая карточка — `Pressable`: нажатие сохраняет фотографию в состояние `selected`.

## Шаг 4. Полноэкранный просмотр

Выбранная фотография показывается в модальном окне `Modal`, которое накрывает весь экран:

```tsx
<Modal
  visible={selected !== null}
  transparent
  animationType="fade"
  onRequestClose={() => setSelected(null)}
>
  <View style={styles.modalBackground}>
    <Text style={styles.modalTitle}>{selected?.title}</Text>
    {selected !== null && (
      <Image source={{ uri: selected.uri }} style={styles.fullImage} resizeMode="contain" />
    )}
    <Pressable style={styles.closeButton} onPress={() => setSelected(null)}>
      <Text style={styles.closeText}>Закрыть</Text>
    </Pressable>
  </View>
</Modal>
```

- `visible={selected !== null}` — окно открыто, пока что-то выбрано.
- `transparent` — фон вокруг фотографии полупрозрачный, основной экран виден.
- `onRequestClose` срабатывает по системной кнопке «Назад» и закрывает окно.
- `selected?.title` — безопасное обращение: если ничего не выбрано, подпись не выводится.
- `resizeMode="contain"` вписывает фотографию целиком, не обрезая.

## Шаг 5. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { FlatList, Image, Modal, Pressable, StyleSheet, Text, View } from 'react-native'

type Photo = {
  id: string
  title: string
  uri: string
}

const PHOTOS: Photo[] = [
  { id: '1', title: 'Горное озеро', uri: 'https://picsum.photos/id/1018/600/400' },
  { id: '2', title: 'Северное сияние', uri: 'https://picsum.photos/id/1015/600/400' },
  { id: '3', title: 'Туманная долина', uri: 'https://picsum.photos/id/1016/600/400' },
  { id: '4', title: 'Вечерний город', uri: 'https://picsum.photos/id/1011/600/400' },
  { id: '5', title: 'Лесная тропа', uri: 'https://picsum.photos/id/1019/600/400' },
  { id: '6', title: 'Морской берег', uri: 'https://picsum.photos/id/1013/600/400' },
]

export default function App() {
  const [selected, setSelected] = useState<Photo | null>(null)

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Фотогалерея</Text>

      <FlatList
        data={PHOTOS}
        keyExtractor={(item) => item.id}
        numColumns={2}
        columnWrapperStyle={styles.column}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <Pressable style={styles.card} onPress={() => setSelected(item)}>
            <Image source={{ uri: item.uri }} style={styles.thumbnail} />
            <Text style={styles.caption}>{item.title}</Text>
          </Pressable>
        )}
      />

      <Modal
        visible={selected !== null}
        transparent
        animationType="fade"
        onRequestClose={() => setSelected(null)}
      >
        <View style={styles.modalBackground}>
          <Text style={styles.modalTitle}>{selected?.title}</Text>
          {selected !== null && (
            <Image source={{ uri: selected.uri }} style={styles.fullImage} resizeMode="contain" />
          )}
          <Pressable style={styles.closeButton} onPress={() => setSelected(null)}>
            <Text style={styles.closeText}>Закрыть</Text>
          </Pressable>
        </View>
      </Modal>

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#111111', paddingTop: 48, paddingHorizontal: 12 },
  title: { fontSize: 24, fontWeight: 'bold', color: '#FFFFFF', marginBottom: 12 },
  list: { paddingBottom: 24 },
  column: { gap: 12 },
  card: { flex: 1, marginBottom: 12, borderRadius: 12, overflow: 'hidden', backgroundColor: '#222222' },
  thumbnail: { width: '100%', height: 120 },
  caption: { color: '#FFFFFF', padding: 8, fontSize: 14 },
  modalBackground: { flex: 1, backgroundColor: 'rgba(0, 0, 0, 0.9)', justifyContent: 'center', padding: 16, gap: 16 },
  modalTitle: { color: '#FFFFFF', fontSize: 20, fontWeight: 'bold', textAlign: 'center' },
  fullImage: { width: '100%', height: '60%' },
  closeButton: { alignSelf: 'center', backgroundColor: '#0057B8', paddingHorizontal: 24, paddingVertical: 12, borderRadius: 8 },
  closeText: { color: '#FFFFFF', fontSize: 16 },
})
```

## Проверьте работу

1. Запустите приложение — появится сетка из шести фотографий в две колонки с подписями.
2. Нажмите на любую карточку — фотография откроется крупно на затемнённом фоне.
3. Нажмите «Закрыть» или системную кнопку «Назад» — модальное окно закроется, галерея останется на месте.
4. Откройте другую фотографию — в модальном окне появятся её изображение и подпись.
5. Проверьте галерею на телефоне и на широком окне браузера — карточки не должны выходить за границы экрана.

## Резюме

- `FlatList` с `numColumns={2}` рисует сетку из карточек.
- Изображение по ссылке выводится через `<Image source={{ uri }} />`, локальное — через `require(...)`.
- Модальное окно `Modal` показывается поверх основного экрана, а его видимостью управляет состояние.
- Данные из списка в модальное окно передаются через выбранный элемент состояния.
- `onRequestClose` закрывает окно по системной кнопке «Назад» — это важно для телефонов.
