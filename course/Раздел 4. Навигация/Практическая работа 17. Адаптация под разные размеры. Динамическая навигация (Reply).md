# Практическая работа 17. Адаптация под разные размеры. Динамическая навигация (Reply)

В этой работе вы сделаете приложение **Reply** — почтовый клиент с письмами — адаптивным. На телефоне пользователь видит список писем и открывает письмо на отдельном экране, а на широком экране список и текст письма располагаются рядом. Такой макет называется **master-detail**, а навигация, которая подстраивается под ширину окна, — динамической.

### Пререквизиты

- Лекция 16 «Навигация» и практическая работа 16.
- Умение создавать состояние (`useState`) и списки (`FlatList`).
- Умение подключать `Pressable` для обработки нажатий.

### Что вы узнаете

- Как получить ширину окна через `useWindowDimensions`.
- Как выбрать макет по классу размера окна.
- Как совместить стек экранов для телефона и макет «список + подробности» для широкого экрана.
- Как выбирать письмо на широком экране без перехода между экранами.

### Что вы создадите

Приложение **Reply** с адаптивным макетом: на узком экране работает навигация по стеку, на широком — список и письмо видны одновременно.

## Шаг 2. Классы размера окна

Ширину окна возвращает хук `useWindowDimensions` — он обновляется при повороте устройства и при изменении размера окна браузера. Определим три класса размера:

```tsx
type SizeClass = 'compact' | 'medium' | 'expanded'

function useSizeClass(): SizeClass {
  const { width } = useWindowDimensions()
  if (width < 600) return 'compact'
  if (width < 840) return 'medium'
  return 'expanded'
}
```

- **compact** (меньше 600) — телефон: показываем только список.
- **medium** (от 600 до 840) — небольшой планшет: список и письмо рядом.
- **expanded** (больше 840) — большой экран: список и письмо рядом.

В нашем приложении два макета: «только список» для compact и «список + подробности» для остальных классов.

## Шаг 3. Список писем и содержимое письма

Данные — массив писем. Список и текст письма оформим отдельными компонентами, чтобы переиспользовать их в обоих макетах:

```tsx
type Email = {
  id: string
  subject: string
  sender: string
  body: string
}

function EmailList({ selectedId, onSelect }: { selectedId?: string; onSelect: (email: Email) => void }) {
  return (
    <FlatList
      data={EMAILS}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable style={[styles.card, selectedId === item.id && styles.cardSelected]} onPress={() => onSelect(item)}>
          <Text style={styles.cardTitle}>{item.subject}</Text>
          <Text style={styles.cardSender}>{item.sender}</Text>
        </Pressable>
      )}
    />
  )
}

function EmailDetails({ email }: { email: Email }) {
  return (
    <View>
      <Text style={styles.cardTitle}>{email.subject}</Text>
      <Text style={styles.cardSender}>{email.sender}</Text>
      <Text style={styles.body}>{email.body}</Text>
    </View>
  )
}
```

Обратите внимание: `EmailList` не решает сам, что делать при нажатии, — он сообщает о выборе через `onSelect`. Благодаря этому один компонент подходит и для перехода на новый экран, и для выбора письма в соседней панели.

## Шаг 4. Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { FlatList, Pressable, StyleSheet, Text, useWindowDimensions, View } from 'react-native'
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

type Email = {
  id: string
  subject: string
  sender: string
  body: string
}

const EMAILS: Email[] = [
  { id: '1', subject: 'Расписание на неделю', sender: 'Учебная часть', body: 'Занятия начинаются в 8:30, во вторник вместо лекции практическая работа.' },
  { id: '2', subject: 'Макет приложения', sender: 'Анна Петрова', body: 'Прикрепила макет экрана входа, посмотрите до пятницы.' },
  { id: '3', subject: 'Встреча команды', sender: 'Иван Смирнов', body: 'Обсуждаем навигацию и адаптивный макет сегодня в 16:00.' },
]

function useSizeClass() {
  const { width } = useWindowDimensions()
  if (width < 600) return 'compact'
  if (width < 840) return 'medium'
  return 'expanded'
}

function EmailList({ selectedId, onSelect }: { selectedId?: string; onSelect: (email: Email) => void }) {
  return (
    <FlatList
      data={EMAILS}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable style={[styles.card, selectedId === item.id && styles.cardSelected]} onPress={() => onSelect(item)}>
          <Text style={styles.cardTitle}>{item.subject}</Text>
          <Text style={styles.cardSender}>{item.sender}</Text>
        </Pressable>
      )}
    />
  )
}

function EmailDetails({ email }: { email: Email }) {
  return (
    <View>
      <Text style={styles.cardTitle}>{email.subject}</Text>
      <Text style={styles.cardSender}>{email.sender}</Text>
      <Text style={styles.body}>{email.body}</Text>
    </View>
  )
}

function InboxScreen({ navigation }: { navigation: any }) {
  return <EmailList onSelect={(email) => navigation.navigate('Email', { email })} />
}

function EmailScreen({ route }: { route: any }) {
  const { email } = route.params
  return <EmailDetails email={email} />
}

function MasterDetailLayout() {
  const [selected, setSelected] = useState<Email | null>(null)

  return (
    <View style={styles.row}>
      <View style={styles.listPane}>
        <EmailList selectedId={selected?.id} onSelect={setSelected} />
      </View>
      <View style={styles.detailPane}>
        {selected === null ? (
          <Text style={styles.placeholder}>Выберите письмо слева</Text>
        ) : (
          <EmailDetails email={selected} />
        )}
      </View>
    </View>
  )
}

export default function App() {
  const sizeClass = useSizeClass()

  const content =
    sizeClass === 'compact' ? (
      <NavigationContainer>
        <Stack.Navigator>
          <Stack.Screen name="Inbox" component={InboxScreen} options={{ title: 'Входящие' }} />
          <Stack.Screen name="Email" component={EmailScreen} options={{ title: 'Письмо' }} />
        </Stack.Navigator>
      </NavigationContainer>
    ) : (
      <MasterDetailLayout />
    )

  return (
    <>
      {content}
      <StatusBar style="auto" />
    </>
  )
}

const styles = StyleSheet.create({
  row: { flex: 1, flexDirection: 'row', backgroundColor: '#F5F5F5' },
  listPane: { width: 320, borderRightWidth: 1, borderRightColor: '#DDDDDD' },
  detailPane: { flex: 1, padding: 24 },
  placeholder: { color: '#777777', textAlign: 'center', marginTop: 24 },
  card: { padding: 16, borderBottomWidth: 1, borderBottomColor: '#EEEEEE', backgroundColor: '#FFFFFF' },
  cardSelected: { backgroundColor: '#E3F0FF' },
  cardTitle: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
  cardSender: { color: '#555555' },
  body: { marginTop: 16, fontSize: 16, lineHeight: 24 },
})
```

Разберём ключевые моменты:

- На узком экране `InboxScreen` открывает `EmailScreen` через `navigation.navigate('Email', { email })` — работает обычный стек с кнопкой «Назад».
- На широком экране навигатор не нужен: `MasterDetailLayout` хранит выбранное письмо в состоянии и показывает его справа.
- В списке подсвечивается выбранное письмо — за это отвечает `selectedId`.
- При изменении ширины окна макет пересобирается: если открыть письмо и расширить окно, приложение покажет широкий макет со сброшенным выбором.

## Проверьте работу

1. Запустите приложение в узком окне — виден только список писем.
2. Нажмите письмо — откроется экран «Письмо» с текстом, кнопка «Назад» вернёт к списку.
3. Расширьте окно браузера (или поверните планшет) до ширины больше 600 — справа появится панель «Выберите письмо слева».
4. Нажмите письмо в списке — текст откроется справа, а список останется на месте, и письмо в нём подсветится.
5. Сузьте окно обратно — снова работает навигация по стеку.

## Резюме

- `useWindowDimensions` даёт ширину окна и обновляется при повороте устройства или изменении размера окна.
- Класс размера окна (`compact`, `medium`, `expanded`) выбирает подходящий макет.
- На узком экране используется стек экранов, на широком — макет «список + подробности».
- Динамическая навигация — это переход между экранами только там, где он нужен: на широком экране выбор письма не меняет экран, а лишь обновляет соседнюю панель.
