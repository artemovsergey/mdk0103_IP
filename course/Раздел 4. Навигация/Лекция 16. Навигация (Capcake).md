# Лекция 16. Навигация (Capcake)

До этого момента ваши приложения состояли из одного экрана. Но большинство приложений, которыми вы пользуетесь, устроены иначе: список, карточка товара, настройки — это отдельные экраны, между которыми перемещается пользователь. Например, в приложении «Настройки» десятки страниц, и каждая открывается на своём экране.

На этом занятии вы научитесь создавать многоэкранные приложения и соберёте приложение **Capcake** — заказ кексов, в котором пользователь проходит путь от выбора вкуса до отправки заказа.

### Пререквизиты

- Лекция 15 «Работа с состоянием (Tip Time)».
- Умение создавать состояние через `useState` и управляемые поля `TextInput`.
- Базовые представления о компонентах `View`, `Text`, `Pressable` и `FlatList`.

### Что вы узнаете

- Как установить и настроить библиотеку **React Navigation**.
- Как описать стек экранов (`Stack Navigator`).
- Как переходить между экранами и возвращаться назад.
- Как передавать данные между экранами через параметры маршрута.
- Как отправить готовый заказ с помощью системного диалога.

### Что вы создадите

Приложение **Capcake** из четырёх экранов: **Start** (кнопка «Начать»), **Flavor** (выбор вкуса), **Pickup** (выбор даты) и **Summary** (итог и отправка).

## Установка React Navigation

Откройте проект Expo и установите библиотеки навигации:

```bash
npx expo install @react-navigation/native @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context
```

- `@react-navigation/native` — ядро навигации.
- `@react-navigation/native-stack` — навигатор стека: экраны кладутся друг на друга, как карточки.
- `react-native-screens` и `react-native-safe-area-context` — вспомогательные библиотеки навигатора. Команда `npx expo install` подбирает версии, совместимые с вашей версией Expo.

## Навигатор стека

Навигатор стека хранит историю экранов. Каждый новый экран кладётся сверху, а кнопка «Назад» возвращает к предыдущему. Минимальная конфигурация выглядит так:

```tsx
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Start">
        <Stack.Screen name="Start" component={StartScreen} />
        <Stack.Screen name="Flavor" component={FlavorScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  )
}
```

- `NavigationContainer` — корневой контейнер, управляющий всем деревом навигации; он должен быть один на всё приложение.
- `Stack.Navigator` — сам стек экранов. Параметр `initialRouteName` задаёт первый экран.
- `Stack.Screen` — один экран. Свойство `name` — имя маршрута, `component` — компонент экрана.

Имена маршрутов уникальны: по ним приложение находит нужный экран при переходе.

## Экран Start

Экраны опишем в одном файле `App.tsx`. Напишем стартовый экран:

```tsx
function StartScreen({ navigation }: { navigation: any }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Заказать кекс</Text>
      <Button title="Начать" onPress={() => navigation.navigate('Flavor')} />
    </View>
  )
}
```

Каждый экран получает объект `navigation` через свойства. Вызов `navigation.navigate('Flavor')` открывает экран с именем `Flavor` и кладёт его поверх текущего. Для строгой типизации используют `NativeStackScreenProps`, но в учебном примере мы указываем `any`, чтобы не загромождать код.

## Экран Flavor

На экране выбора вкуса храним выбранный вариант в состоянии. Кнопка «Далее» заблокирована, пока пользователь ничего не выбрал:

```tsx
function FlavorScreen({ navigation }: { navigation: any }) {
  const [flavor, setFlavor] = useState<string | null>(null)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Выберите вкус</Text>
      {FLAVORS.map((name) => (
        <Pressable
          key={name}
          onPress={() => setFlavor(name)}
          style={[styles.option, flavor === name && styles.optionSelected]}
        >
          <Text style={flavor === name ? styles.optionTextSelected : styles.optionText}>
            {name}
          </Text>
        </Pressable>
      ))}
      <Button
        title="Далее"
        disabled={flavor === null}
        onPress={() => navigation.navigate('Pickup', { flavor })}
      />
    </View>
  )
}
```

- `useState<string | null>(null)` — выбранного вкуса ещё нет.
- `flavor === name` — выбранный вариант подсвечивается другим стилем.
- `disabled={flavor === null}` — пока вкус не выбран, переход дальше запрещён.

## Передача данных между экранами

Второй аргумент `navigate` — объект параметров. Так данные попадают с одного экрана на другой, а на экране-получателе доступны через `route.params`:

```tsx
navigation.navigate('Pickup', { flavor })

function PickupScreen({ navigation, route }: { navigation: any; route: any }) {
  const { flavor } = route.params
  ...
}
```

Экран Pickup устроен так же, как Flavor: список дат и кнопка «Далее» с переходом `navigation.navigate('Summary', { flavor, date })`. На Summary передаются оба параметра — заказ «собирается» по мере прохождения экранов.

## Итоговый экран и отправка заказа

На экране Summary показываем выбранные данные и отправляем заказ через системный диалог `Share`:

```tsx
import { Share } from 'react-native'

const shareOrder = async (flavor: string, date: string) => {
  await Share.share({
    message: `Заказ: кекс «${flavor}», дата получения: ${date}`,
  })
}
```

`Share.share` открывает системное окно, в котором пользователь выбирает, куда отправить заказ: приложение не знает заранее, какое приложение он выберет. Кнопка «Отменить заказ» на этом экране вызывает `navigation.popToTop()` и возвращает на самый первый экран.

## Возврат назад и заголовки

- Кнопка «Назад» в заголовке появляется автоматически на всех экранах, кроме первого, и возвращает на предыдущий экран.
- Программно вернуться на шаг назад позволяет `navigation.goBack()`.
- Вернуться к первому экрану стека помогает `navigation.popToTop()` — он удаляет все экраны, кроме начального.
- Заголовок настраивается свойством `options`: `options={{ title: 'Вкус' }}`. Если заголовок не указан, навигатор покажет имя маршрута, а заголовок первого экрана обычно делают названием приложения — «Capcake».

## Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { Button, Pressable, Share, StyleSheet, Text, View } from 'react-native'
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

const FLAVORS = ['Ваниль', 'Шоколад', 'Клубника']
const PICKUP_OPTIONS = ['Сегодня', 'Завтра', 'Через два дня']

function StartScreen({ navigation }: { navigation: any }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Заказать кекс</Text>
      <Button title="Начать" onPress={() => navigation.navigate('Flavor')} />
    </View>
  )
}

function FlavorScreen({ navigation }: { navigation: any }) {
  const [flavor, setFlavor] = useState<string | null>(null)
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Выберите вкус</Text>
      {FLAVORS.map((name) => (
        <Pressable
          key={name}
          onPress={() => setFlavor(name)}
          style={[styles.option, flavor === name && styles.optionSelected]}
        >
          <Text style={flavor === name ? styles.optionTextSelected : styles.optionText}>
            {name}
          </Text>
        </Pressable>
      ))}
      <Button
        title="Далее"
        disabled={flavor === null}
        onPress={() => navigation.navigate('Pickup', { flavor })}
      />
    </View>
  )
}

function PickupScreen({ navigation, route }: { navigation: any; route: any }) {
  const { flavor } = route.params
  const [date, setDate] = useState<string | null>(null)
  return (
    <View style={styles.container}>
      <Text style={styles.subtitle}>Вкус: {flavor}</Text>
      <Text style={styles.title}>Выберите дату получения</Text>
      {PICKUP_OPTIONS.map((option) => (
        <Pressable
          key={option}
          onPress={() => setDate(option)}
          style={[styles.option, date === option && styles.optionSelected]}
        >
          <Text style={date === option ? styles.optionTextSelected : styles.optionText}>
            {option}
          </Text>
        </Pressable>
      ))}
      <Button
        title="Далее"
        disabled={date === null}
        onPress={() => navigation.navigate('Summary', { flavor, date })}
      />
    </View>
  )
}

function SummaryScreen({ navigation, route }: { navigation: any; route: any }) {
  const { flavor, date } = route.params
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Ваш заказ</Text>
      <Text style={styles.subtitle}>Вкус: {flavor}</Text>
      <Text style={styles.subtitle}>Дата: {date}</Text>
      <Button title="Отправить заказ" onPress={() => shareOrder(flavor, date)} />
      <Button title="Отменить заказ" onPress={() => navigation.popToTop()} />
    </View>
  )
}

const shareOrder = async (flavor: string, date: string) => {
  await Share.share({
    message: `Заказ: кекс «${flavor}», дата получения: ${date}`,
  })
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Start">
        <Stack.Screen name="Start" component={StartScreen} options={{ title: 'Capcake' }} />
        <Stack.Screen name="Flavor" component={FlavorScreen} options={{ title: 'Вкус' }} />
        <Stack.Screen name="Pickup" component={PickupScreen} options={{ title: 'Дата' }} />
        <Stack.Screen name="Summary" component={SummaryScreen} options={{ title: 'Итог' }} />
      </Stack.Navigator>
      <StatusBar style="auto" />
    </NavigationContainer>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 24, gap: 12 },
  title: { fontSize: 24, fontWeight: 'bold' },
  subtitle: { fontSize: 16, color: '#555555' },
  option: { width: '100%', padding: 16, borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, backgroundColor: '#FFFFFF' },
  optionSelected: { backgroundColor: '#0057B8', borderColor: '#0057B8' },
  optionText: { fontSize: 16, color: '#333333' },
  optionTextSelected: { fontSize: 16, color: '#FFFFFF' },
})
```

Разберём ключевые моменты:

- `Stack.Screen name="..."` и строка в `navigate('...')` должны совпадать — по имени навигатор находит экран.
- Данные между экранами передаются вторым аргументом `navigate` и читаются через `route.params`.
- `disabled` не даёт перейти дальше, пока пользователь не сделал выбор.
- `Share.share` отправляет текст заказа в приложение на выбор пользователя.
- `popToTop()` очищает стек — так кнопка «Отменить заказ» возвращает на стартовый экран.

## Проверьте работу

1. Запустите проект командой `npx expo start` и откройте приложение в браузере (клавиша `w`) или на телефоне через Expo Go.
2. На стартовом экране нажмите «Начать» — откроется выбор вкуса.
3. Выберите вкус: вариант подсветится, кнопка «Далее» станет активной, а на следующем экране будет виден выбранный вкус.
4. На итоговом экране проверьте, что показаны вкус и дата, и нажмите «Отправить заказ» — откроется системное окно отправки.
5. Вернитесь назад кнопкой в заголовке, а затем проверьте кнопку «Отменить заказ» — она возвращает на самый первый экран.

## Резюме

- `NavigationContainer` — корень навигации, внутри него размещается `Stack.Navigator`.
- `Stack.Screen` описывает экран: имя маршрута, компонент и заголовок.
- `navigation.navigate('Имя')` открывает экран и кладёт его в стек.
- Данные передаются через параметры: `navigate('Имя', { ... })` и `route.params`.
- Кнопка «Назад» возвращает на предыдущий экран, `goBack()` делает то же программно, а `popToTop()` очищает стек до первого экрана.
- `Share.share` позволяет отправить данные заказа в другое приложение.
