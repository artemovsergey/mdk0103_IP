# Приложение Мой город

В этой работе вы создадите приложение **Мой город** — справочник о городе: список достопримечательностей с фотографиями и отдельный экран с подробным описанием. Вы закрепите навигацию между экранами и передачу данных через параметры маршрута.

### Пререквизиты

- Лекция 16 «Навигация» и практическая работа 16 «Практика навигации (Lunch Tray)».
- Умение выводить списки через `FlatList` и отображать изображения через `Image`.
- Умение настраивать `NavigationContainer` и `Stack.Navigator`.

### Что вы узнаете

- Как разделить приложение на экран списка и экран подробностей.
- Как передать объект выбранного места через `route.params`.
- Как собрать карточку достопримечательности с изображением и описанием.
- Как использовать заголовок экрана для кнопки «Назад».

### Что вы создадите

Приложение **Мой город**: список из пяти достопримечательностей и экран с подробным описанием выбранного места.

## Шаг 3. Полный код App.tsx

Два экрана объединяет навигатор стека: из списка пользователь переходит на подробности, а кнопка «Назад» возвращает его обратно.

```tsx
import { StatusBar } from 'expo-status-bar'
import { FlatList, Image, Pressable, ScrollView, StyleSheet, Text, View } from 'react-native'
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'
import { Place, places } from './data/places'

const Stack = createNativeStackNavigator()

function PlaceCard({ place, onPress }: { place: Place; onPress: () => void }) {
  return (
    <Pressable
      style={styles.card}
      onPress={onPress}
      accessibilityRole="button"
      accessibilityLabel={place.name}
      accessibilityHint="Открывает подробное описание места"
    >
      <Image source={place.image} style={styles.image} />
      <View style={styles.body}>
        <Text style={styles.cardTitle}>{place.name}</Text>
        <Text style={styles.cardShort}>{place.short}</Text>
      </View>
    </Pressable>
  )
}

function CityScreen({ navigation }: { navigation: any }) {
  return (
    <FlatList
      data={places}
      keyExtractor={(item) => item.id}
      contentContainerStyle={styles.list}
      ListHeaderComponent={<Text style={styles.title}>Чем заняться в Казани</Text>}
      renderItem={({ item }) => (
        <PlaceCard place={item} onPress={() => navigation.navigate('Place', { place: item })} />
      )}
    />
  )
}

function PlaceScreen({ route }: { route: any }) {
  const { place } = route.params as { place: Place }

  return (
    <ScrollView contentContainerStyle={styles.details}>
      <Image
        source={place.image}
        style={styles.detailsImage}
        accessibilityLabel={`Фотография: ${place.name}`}
      />
      <Text style={styles.detailsTitle}>{place.name}</Text>
      <Text style={styles.address}>{place.address}</Text>
      <Text style={styles.description}>{place.description}</Text>
    </ScrollView>
  )
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="City" component={CityScreen} options={{ title: 'Мой город' }} />
        <Stack.Screen name="Place" component={PlaceScreen} options={{ title: 'О месте' }} />
      </Stack.Navigator>
      <StatusBar style="auto" />
    </NavigationContainer>
  )
}

const styles = StyleSheet.create({
  list: { padding: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 12 },
  card: { backgroundColor: '#FFFFFF', borderRadius: 12, marginBottom: 12, overflow: 'hidden' },
  image: { width: '100%', height: 160 },
  body: { padding: 12, gap: 4 },
  cardTitle: { fontSize: 18, fontWeight: 'bold' },
  cardShort: { color: '#555555' },
  details: { padding: 16, gap: 8 },
  detailsImage: { width: '100%', height: 220, borderRadius: 12 },
  detailsTitle: { fontSize: 22, fontWeight: 'bold' },
  address: { color: '#0057B8' },
  description: { fontSize: 16, lineHeight: 24 },
})
```

Разберём ключевые моменты:

- `Stack.Navigator` объявляет два экрана; первый в списке становится стартовым.
- `navigation.navigate('Place', { place: item })` передаёт выбранный объект на экран подробностей, а `route.params` его принимает.
- Кнопка «Назад» в заголовке экрана «О месте» появляется автоматически и возвращает к списку.
- `ListHeaderComponent` выводит заголовок над списком и прокручивается вместе с ним.
- У карточки задана `accessibilityLabel` — программа чтения с экрана произнесёт название места.

## Резюме

- Справочное приложение удобно делить на экран списка и экран подробностей.
- `Stack.Navigator` связывает экраны, а кнопка «Назад» появляется автоматически.
- Данные передаются через параметры маршрута: `navigation.navigate('Place', { place })` и `route.params`.
- Модель и данные хранятся отдельно от экранов — в файле `data/places.ts`.
- Карточки с изображениями и заголовками собираются из знакомых `Pressable`, `Image` и `Text`.
