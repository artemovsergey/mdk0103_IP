# Практическая работа 27. Уведомления в приложении

В этой работе вы создадите приложение **«Напоминание»** с двумя кнопками. Первая планирует локальное уведомление через 5 секунд, вторая отменяет все запланированные уведомления. Проверять работу будем на телефоне в Expo Go: локальные уведомления там полностью поддерживаются и приходят, даже когда приложение свёрнуто или закрыто.

- Умение работать с `useState` и `useEffect` (лекция 15).
- Телефон с установленным Expo Go.

### Что вы узнаете

- Как запросить разрешение на уведомления и обработать отказ.
- Как создать канал уведомлений на Android.
- Как запланировать уведомление с триггером по времени.
- Как отменить все запланированные уведомления.

### Что вы создадите

Приложение «Напоминание» с кнопками «Напомнить через 5 секунд» и «Отменить все». Уведомление появляется плашкой поверх экрана и остаётся в центре уведомлений.

## Шаг 2. Настройка уведомлений

Первым делом создадим канал на Android и запросим разрешение. Обработчик `setNotificationHandler` вызывается один раз вне компонента и определяет, как ведёт себя уведомление, когда приложение открыто:

```tsx
import * as Notifications from 'expo-notifications'
import { Platform } from 'react-native'

const CHANNEL_ID = 'reminders'

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowBanner: true,
    shouldShowList: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
})

async function prepareNotifications(): Promise<boolean> {
  if (Platform.OS === 'android') {
    await Notifications.setNotificationChannelAsync(CHANNEL_ID, {
      name: 'Напоминания',
      importance: Notifications.AndroidImportance.MAX,
    })
  }

  const settings = await Notifications.getPermissionsAsync()
  if (settings.granted) {
    return true
  }

  const request = await Notifications.requestPermissionsAsync()
  return request.granted
}
```

Разберём ключевые моменты:

- Канал создаётся только на Android; на iOS каналов нет, поэтому код защищён проверкой `Platform.OS`.
- `getPermissionsAsync` проверяет, выдано ли разрешение раньше; если да — диалог повторно не показывается.
- `requestPermissionsAsync` открывает системный диалог, а `granted` сообщает ответ пользователя.

## Шаг 3. Планирование и отмена уведомления

Добавим функцию планирования. Триггер `TIME_INTERVAL` сработает через 5 секунд, а `channelId` направляет уведомление в созданный канал:

```tsx
function scheduleReminder(): Promise<string> {
  return Notifications.scheduleNotificationAsync({
    content: {
      title: 'Напоминание',
      body: 'Это уведомление пришло через 5 секунд после нажатия.',
    },
    trigger: {
      type: Notifications.SchedulableTriggerInputTypes.TIME_INTERVAL,
      seconds: 5,
      channelId: CHANNEL_ID,
    },
  })
}
```

Отмена выполняется одним методом: `cancelAllScheduledNotificationsAsync` удаляет все уведомления, которые ещё не успели прийти.

## Шаг 4. Полный код App.tsx

Соберите приложение целиком: состояние, обработчики кнопок, разметку и стили.

```tsx
import * as Notifications from 'expo-notifications'
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { Alert, Platform, Pressable, StyleSheet, Text, View } from 'react-native'

const CHANNEL_ID = 'reminders'

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowBanner: true,
    shouldShowList: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
})

async function prepareNotifications(): Promise<boolean> {
  if (Platform.OS === 'android') {
    await Notifications.setNotificationChannelAsync(CHANNEL_ID, {
      name: 'Напоминания',
      importance: Notifications.AndroidImportance.MAX,
    })
  }

  const settings = await Notifications.getPermissionsAsync()
  if (settings.granted) {
    return true
  }

  const request = await Notifications.requestPermissionsAsync()
  return request.granted
}

function scheduleReminder(): Promise<string> {
  return Notifications.scheduleNotificationAsync({
    content: {
      title: 'Напоминание',
      body: 'Это уведомление пришло через 5 секунд после нажатия.',
    },
    trigger: {
      type: Notifications.SchedulableTriggerInputTypes.TIME_INTERVAL,
      seconds: 5,
      channelId: CHANNEL_ID,
    },
  })
}

export default function App() {
  const [allowed, setAllowed] = useState(false)
  const [planned, setPlanned] = useState(false)

  useEffect(() => {
    prepareNotifications().then((granted) => {
      setAllowed(granted)
      if (!granted) {
        Alert.alert('Нет разрешения', 'Разрешите уведомления в настройках телефона.')
      }
    })
  }, [])

  async function handleRemind() {
    await scheduleReminder()
    setPlanned(true)
  }

  async function handleCancelAll() {
    await Notifications.cancelAllScheduledNotificationsAsync()
    setPlanned(false)
  }

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Напоминание</Text>
      <Text style={styles.hint}>
        Нажмите кнопку, сверните приложение и подождите пять секунд.
      </Text>

      <Pressable
        style={[styles.button, !allowed && styles.buttonDisabled]}
        onPress={handleRemind}
        disabled={!allowed}
      >
        <Text style={styles.buttonText}>Напомнить через 5 секунд</Text>
      </Pressable>

      <Pressable style={[styles.button, styles.cancelButton]} onPress={handleCancelAll}>
        <Text style={styles.buttonText}>Отменить все</Text>
      </Pressable>

      {planned && <Text style={styles.status}>Уведомление запланировано</Text>}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 96, paddingHorizontal: 24, gap: 16 },
  title: { fontSize: 24, fontWeight: 'bold' },
  hint: { color: '#555555', marginBottom: 8 },
  button: {
    backgroundColor: '#0057B8',
    borderRadius: 8,
    minHeight: 44,
    alignItems: 'center',
    justifyContent: 'center',
    paddingHorizontal: 16,
  },
  buttonDisabled: { backgroundColor: '#AAAAAA' },
  cancelButton: { backgroundColor: '#C62828' },
  buttonText: { color: '#FFFFFF', fontSize: 16, fontWeight: 'bold' },
  status: { color: '#0057B8', marginTop: 8 },
})
```

Разберём ключевые моменты:

- `prepareNotifications` вызывается один раз в `useEffect`; результат сохраняется в состояние `allowed`.
- Если разрешение не выдано, кнопка планирования блокируется, а пользователь видит подсказку.
- `handleRemind` сначала планирует уведомление, затем включает подпись «Уведомление запланировано».
- `handleCancelAll` отменяет все запланированные уведомления и возвращает подпись в исходное состояние.

## Проверьте работу

1. Откройте приложение в Expo Go. При первом запуске появится системный запрос — разрешите уведомления.
2. Нажмите «Напомнить через 5 секунд» и **сверните** приложение (жест «домой»), не закрывая его полностью.
3. Через пять секунд появится уведомление; разверните шторку уведомлений — запись останется в списке.
4. Вернитесь в приложение и нажмите «Напомнить через 5 секунд» два раза подряд, затем сразу «Отменить все» — ни одно уведомление не появится.
5. Заблокируйте телефон сразу после нажатия — уведомление всё равно придёт: его показывает система, а не само приложение.

> Если уведомление не появляется, проверьте, что приложение не было полностью закрыто (смахнуто из списка запущенных), а разрешение не отозвано в настройках телефона.

## Резюме

- Разрешение проверяют через `getPermissionsAsync`, запрашивают через `requestPermissionsAsync`; на Android перед этим создают канал.
- `scheduleNotificationAsync` с триггером `TIME_INTERVAL` планирует уведомление через заданное число секунд.
- Метод планирования возвращает идентификатор — по нему уведомление можно отменить точечно.
- `cancelAllScheduledNotificationsAsync` отменяет все запланированные уведомления разом.
- Локальные уведомления работают в Expo Go и приходят, даже когда приложение свёрнуто или телефон заблокирован.
