# Практическая работа 28. Разработка приложения с фоновыми задачами (Water Me)

В этой работе вы создадите приложение **Water Me** — трекер полива растений: пользователь добавляет растения и включает для каждого ежедневное напоминание, а список сохраняется между запусками. Напоминания работают через локальные уведомления, поэтому приложение полностью работает в Expo Go. Полноценные фоновые задачи выполняются только в собранном приложении — сборку сделаем в практической работе 30.

## Шаг 2. Хранение списка и напоминания

Опишем растение типом `Plant` — поле `reminderId` хранит идентификатор запланированного уведомления, а пока напоминание выключено, там `null`. Список сериализуется в `AsyncStorage` через `JSON.stringify` и читается через `JSON.parse`; сохранять идентификатор важно, потому что после перезапуска приложения напоминание можно будет выключить. Ежедневное уведомление создаётся триггером `DAILY`: один раз запланировали — дальше система повторяет его сама.

```tsx
function scheduleDailyReminder(plantName: string): Promise<string> {
  return Notifications.scheduleNotificationAsync({
    content: { title: 'Пора полить растение', body: `Не забудьте полить «${plantName}»` },
    trigger: {
      type: Notifications.SchedulableTriggerInputTypes.DAILY,
      hour: REMINDER_HOUR,
      minute: 0,
      channelId: CHANNEL_ID,
    },
  })
}
```

- `hour` и `minute` задают время; `REMINDER_HOUR` и `CHANNEL_ID` — константы из полного кода ниже.
- Метод возвращает идентификатор уведомления — его сохраняют в поле `reminderId`.
- Отмена выполняется по идентификатору (`cancelScheduledNotificationAsync`); для быстрой проверки добавим одноразовое уведомление через 10 секунд — триггер `TIME_INTERVAL`.

## Шаг 3. Полный код App.tsx

Соберите приложение целиком: загрузка списка, добавление растений, переключатели напоминаний и тестовая кнопка.

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage'
import * as Notifications from 'expo-notifications'
import { StatusBar } from 'expo-status-bar'
import { useEffect, useState } from 'react'
import { Alert, FlatList, Platform, Pressable, StyleSheet, Switch, Text, TextInput, View } from 'react-native'

const STORAGE_KEY = 'water-me-plants'
const CHANNEL_ID = 'watering-reminders'
const REMINDER_HOUR = 9
const TEST_DELAY_SECONDS = 10

type Plant = { id: string; name: string; reminderId: string | null }

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowBanner: true,
    shouldShowList: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
})

async function prepareNotifications(): Promise<boolean> {
  if (Platform.OS === 'android') {
    await Notifications.setNotificationChannelAsync(CHANNEL_ID, {
      name: 'Полив растений',
      importance: Notifications.AndroidImportance.MAX,
    })
  }

  const settings = await Notifications.getPermissionsAsync()
  if (settings.granted) return true

  const request = await Notifications.requestPermissionsAsync()
  return request.granted
}

function scheduleDailyReminder(plantName: string): Promise<string> {
  return Notifications.scheduleNotificationAsync({
    content: { title: 'Пора полить растение', body: `Не забудьте полить «${plantName}»` },
    trigger: {
      type: Notifications.SchedulableTriggerInputTypes.DAILY,
      hour: REMINDER_HOUR,
      minute: 0,
      channelId: CHANNEL_ID,
    },
  })
}

function scheduleTestReminder(plantName: string): Promise<string> {
  return Notifications.scheduleNotificationAsync({
    content: { title: 'Проверка напоминания', body: `Так выглядит напоминание для «${plantName}»` },
    trigger: {
      type: Notifications.SchedulableTriggerInputTypes.TIME_INTERVAL,
      seconds: TEST_DELAY_SECONDS,
      channelId: CHANNEL_ID,
    },
  })
}

export default function App() {
  const [plants, setPlants] = useState<Plant[]>([])
  const [nameInput, setNameInput] = useState('')
  const [ready, setReady] = useState(false)

  useEffect(() => {
    async function load() {
      await prepareNotifications()
      const json = await AsyncStorage.getItem(STORAGE_KEY)
      setPlants(json !== null ? (JSON.parse(json) as Plant[]) : [])
      setReady(true)
    }

    load()
  }, [])

  async function savePlants(next: Plant[]) {
    setPlants(next)
    await AsyncStorage.setItem(STORAGE_KEY, JSON.stringify(next))
  }

  function withChange(plant: Plant, changes: Partial<Plant>) {
    return plants.map((item) => (item.id === plant.id ? { ...item, ...changes } : item))
  }

  async function handleAddPlant() {
    const name = nameInput.trim()
    if (name === '') {
      Alert.alert('Введите название растения')
      return
    }

    await savePlants([...plants, { id: Date.now().toString(), name, reminderId: null }])
    setNameInput('')
  }

  async function handleToggleReminder(plant: Plant, enabled: boolean) {
    if (enabled) {
      const reminderId = await scheduleDailyReminder(plant.name)
      await savePlants(withChange(plant, { reminderId }))
    } else {
      if (plant.reminderId !== null) {
        await Notifications.cancelScheduledNotificationAsync(plant.reminderId)
      }
      await savePlants(withChange(plant, { reminderId: null }))
    }
  }

  async function handleTestReminder(plant: Plant) {
    await scheduleTestReminder(plant.name)
    Alert.alert('Проверка', `Уведомление придёт через ${TEST_DELAY_SECONDS} секунд. Сверните приложение.`)
  }

  if (!ready) {
    return null
  }

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Water Me</Text>

      <View style={styles.addRow}>
        <TextInput
          style={styles.input}
          value={nameInput}
          onChangeText={setNameInput}
          placeholder="Например, фикус"
        />
        <Pressable style={styles.addButton} onPress={handleAddPlant}>
          <Text style={styles.addButtonText}>Добавить</Text>
        </Pressable>
      </View>

      <FlatList
        data={plants}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <View style={styles.card}>
            <View style={styles.cardInfo}>
              <Text style={styles.plantName}>{item.name}</Text>
              <Text style={styles.plantStatus}>
                {item.reminderId !== null ? 'Напоминание включено' : 'Без напоминания'}
              </Text>
            </View>
            <Pressable onPress={() => handleTestReminder(item)}>
              <Text style={styles.testText}>Проверить</Text>
            </Pressable>
            <Switch
              value={item.reminderId !== null}
              onValueChange={(enabled) => handleToggleReminder(item, enabled)}
            />
          </View>
        )}
        ListEmptyComponent={<Text style={styles.empty}>Список пуст. Добавьте первое растение.</Text>}
      />

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 48, paddingHorizontal: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 16 },
  addRow: { flexDirection: 'row', gap: 8, marginBottom: 16 },
  input: { flex: 1, backgroundColor: '#FFFFFF', borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, paddingHorizontal: 12, paddingVertical: 10, fontSize: 16 },
  addButton: { backgroundColor: '#0057B8', borderRadius: 8, paddingHorizontal: 20, justifyContent: 'center', minHeight: 44 },
  addButtonText: { color: '#FFFFFF', fontSize: 16, fontWeight: 'bold' },
  card: { backgroundColor: '#FFFFFF', borderRadius: 12, padding: 16, marginBottom: 12, flexDirection: 'row', alignItems: 'center', justifyContent: 'space-between', gap: 12 },
  cardInfo: { flex: 1, gap: 4 },
  plantName: { fontSize: 16, fontWeight: 'bold' },
  plantStatus: { color: '#777777', fontSize: 13 },
  testText: { color: '#0057B8', fontSize: 14 },
  empty: { color: '#555555', textAlign: 'center', marginTop: 24 },
})
```

Разберём ключевые моменты:

- `load` внутри `useEffect` настраивает уведомления, читает сохранённый список и только потом включает экран (`ready`); `savePlants` обновляет состояние и сразу сохраняет список, а `withChange` заменяет одно растение в массиве.
- `handleToggleReminder` при включении планирует уведомление и записывает его идентификатор, при выключении — отменяет напоминание и очищает поле.
- Кнопка «Проверить» планирует одноразовое уведомление через 10 секунд, чтобы результат был виден сразу.

## Проверьте работу

1. Добавьте растение, например «Фикус», — появится карточка со статусом «Без напоминания».
2. Включите переключатель — статус сменится на «Напоминание включено», и каждый день в 9:00 будет приходить уведомление.
3. Нажмите «Проверить» и сверните приложение — через 10 секунд придёт тестовое уведомление.
4. Выключите переключатель — ежедневное напоминание отменится, а затем закройте и снова откройте приложение — растения и переключатели сохранятся.

## Резюме

- Список растений хранится в `AsyncStorage`: `JSON.stringify` при сохранении и `JSON.parse` при чтении.
- Идентификатор уведомления хранится в объекте растения — по нему напоминание отменяют.
- Триггер `DAILY` повторяет уведомление каждый день, `TIME_INTERVAL` пригодился для проверки, а локальные уведомления работают в Expo Go и срабатывают при закрытом приложении.
