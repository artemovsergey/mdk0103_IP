# Настройка окружения для разработки на React Native (Expo)

В этом курсе мобильные приложения разрабатываются на языке **TypeScript** с использованием фреймворка **React Native** и инструмента **Expo**. Для работы не нужен Android Studio и тяжёлый Android SDK - приложение запускается на телефоне через приложение **Expo Go** или в браузере.

После настройки окружения вы сможете создавать и запускать мобильные приложения за несколько минут.

## Что понадобится

- Компьютер под управлением Windows, macOS или Linux.
- Подключение к Интернету.
- Смартфон на Android или iOS (необязательно - можно обойтись браузером).
- Установленный **Node.js** (версия LTS) и менеджер пакетов **npm** (устанавливается вместе с Node.js).
- Редактор кода **Visual Studio Code**.

## Шаг 1. Установка Node.js

1. Откройте сайт <https://nodejs.org> и скачайте версию **LTS** для своей операционной системы.
2. Установите её, оставив все параметры по умолчанию.
3. Проверьте установку. Откройте терминал (Windows PowerShell, «Терминал» или командную строку) и выполните:

```bash
node -v
npm -v
```

Вы должны увидеть номера версий, например:

```
v24.11.1
11.7.0
```

> Если команда `node` не найдена, перезапустите терминал, а при необходимости - компьютер. Значит, переменная `PATH` ещё не обновилась.

## Шаг 2. Установка Visual Studio Code

1. Скачайте VS Code с сайта <https://code.visualstudio.com> и установите.
2. Установите полезные расширения (вкладка Extensions, `Ctrl+Shift+X`):
   - **ES7+ React/Redux/React-Native snippets** - шаблоны кода React.
   - **Prettier - Code formatter** - автоформатирование.
   - **React Native Tools** - запуск и отладка приложений.

## Шаг 3. Установка приложения Expo Go на телефон (необязательно)

1. Установите **Expo Go** из Google Play (Android) или App Store (iOS).
2. Телефон и компьютер должны быть подключены к **одной сети Wi-Fi**.
3. Expo Go понадобится, чтобы запускать приложение на реальном устройстве, читая QR-код.

> Если Wi-Fi недоступен или сеть мешает соединению, используйте запуск в браузере (шаг 6).

## Шаг 4. Создание первого проекта

1. Откройте терминал и перейдите в папку, где будете хранить проекты:

```bash
cd C:\Projects
```

2. Создайте проект с шаблоном TypeScript:

```bash
npx create-expo-app@latest my-app --template blank-typescript
```

> `npx` - это команда запуска пакетов Node.js без их глобальной установки. При первом запуске npx скачает `create-expo-app`.

3. Перейдите в папку проекта и установите зависимости:

```bash
cd my-app
npm install
```

4. Откройте проект в VS Code:

```bash
code .
```

## Шаг 5. Структура проекта

После создания проекта вы увидите следующие файлы и папки:

```
my-app/
├── assets/           # изображения, иконки, шрифты
│   ├── icon.png
│   └── ...
├── App.tsx           # главный (и обычно единственный) экран приложения
├── app.json          # настройки приложения: имя, иконка, ориентация
├── index.ts          # точка входа, регистрирует App
├── package.json      # список зависимостей и команды запуска
└── tsconfig.json     # настройки TypeScript
```

- **App.tsx** - это React-компонент, который описывает пользовательский интерфейс. Здесь вы будете писать основную часть кода.
- **app.json** - конфигурация Expo: название приложения, иконка, цвет экрана загрузки.
- **package.json** - в разделе `dependencies` перечислены библиотеки, а в `scripts` - команды (`start`, `android`, `web`).

Начальное содержимое `App.tsx` выглядит так:

```tsx
import { StatusBar } from 'expo-status-bar';
import { StyleSheet, Text, View } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text>Open up App.tsx to start working on your app!</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

## Шаг 6. Запуск приложения

В папке проекта выполните:

```bash
npx expo start
```

В терминале появится QR-код и список клавиш:

- **Сканировать QR-код** приложением Expo Go (Android) или камерой (iOS) - приложение откроется на телефоне.
- Нажмите `a` - запуск на Android-эмуляторе.
- Нажмите `i` - запуск на iOS-симуляторе (только macOS).
- Нажмите `w` - запуск в **браузере** (самый быстрый способ проверить приложение).

> Если телефона нет, можно использовать эмулятор Android. В репозитории курса есть скрипт `start_emulator.bat` - он создаёт и запускает эмулятор (Pixel 7, API 35). Приложение **Expo Go** на эмуляторе устанавливается из Google Play.

Для запуска сразу в браузере можно использовать команду:

```bash
npx expo start --web
```

Чтобы остановить сервер разработки, нажмите `Ctrl+C` в терминале.

> При изменении файлов приложение обновляется автоматически - это называется **hot reload**. Перезапускать сервер не нужно.

## Шаг 7. Проверка работоспособности

Замените текст в `App.tsx`:

```tsx
<Text>Привет, React Native!</Text>
```

Сохраните файл (`Ctrl+S`) и посмотрите на телефон или браузер - текст на экране изменится. Это значит, что окружение настроено правильно.

## Проверка типов

TypeScript позволяет находить ошибки до запуска приложения. Чтобы проверить весь проект, выполните:

```bash
npx tsc --noEmit
```

Команда ничего не выводит, если ошибок нет. Любое сообщение означает ошибку, которую нужно исправить.

## Полезные команды

| Команда | Назначение |
|:--|:--|
| `npx expo start` | Запустить сервер разработки |
| `npx expo start --web` | Запустить приложение в браузере |
| `npx tsc --noEmit` | Проверить типы TypeScript |
| `npm install <пакет>` | Установить библиотеку |
| `npx expo install <пакет>` | Установить библиотеку, совместимую с версией Expo |

## Возможные проблемы

- **Телефон не видит QR-код.** Убедитесь, что компьютер и телефон в одной сети Wi-Fi. Проверьте, что брандмауэр не блокирует порт `8081`. Как запасной вариант используйте режим браузера (`npx expo start --web`).
- **Ошибки при `npm install` из-за прокси.** Если в сети колледжа используется прокси-сервер, настройте npm:

```bash
npm config set proxy http://gate-espd.scc:3128
npm config set https-proxy http://gate-espd.scc:3128
```

- **Порт 8081 занят.** Expo предложит запуститься на другом порту - согласитесь, нажав `Y`.
- **Старая версия Node.js.** Для актуальных версий Expo нужен Node.js LTS. Проверьте `node -v` и при необходимости обновите.
