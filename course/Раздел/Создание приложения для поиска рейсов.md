# Создание приложения для поиска рейсов

В этой работе вы создадите приложение **Поиск рейсов**: пользователь указывает, откуда и куда летит и на какую дату, а приложение показывает подходящие рейсы. Справочник рейсов хранится прямо в приложении, а поиск — это фильтрация массива.

### Пререквизиты

- Умение работать с `TextInput`, состоянием `useState` и кнопкой `Pressable`.
- Умение выводить списки через `FlatList` и показывать загрузку через `ActivityIndicator`.
- Понимание метода `.filter()` и методов строк `toLowerCase()` и `includes()`.

### Что вы узнаете

- Как собрать поисковый запрос из нескольких полей формы.
- Как фильтровать массив по городу, коду аэропорта и дате.
- Как различать состояния экрана: форма не заполнена, идёт поиск, есть результат, ничего не найдено.
- Как форматировать цену через `toLocaleString`.

### Что вы создадите

Приложение **Поиск рейсов** с формой «Откуда», «Куда», «Дата» и списком карточек найденных рейсов.

## Шаг 2. Полный код App.tsx

Данные шести рейсов лежат в массиве `flights`, а функция `searchFlights` фильтрует его по трём условиям. Небольшая задержка имитирует ответ сервера — она нужна, чтобы было видно состояние загрузки.

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { ActivityIndicator, FlatList, Pressable, StyleSheet, Text, TextInput, View } from 'react-native'

type Flight = {
  id: string; flightNumber: string; fromCity: string; fromCode: string
  toCity: string; toCode: string; date: string; departure: string; arrival: string; price: number
}

const flights: Flight[] = [
  { id: '1', flightNumber: 'N4-201', fromCity: 'Москва', fromCode: 'SVO', toCity: 'Казань', toCode: 'KZN', date: '12.06.2026', departure: '08:20', arrival: '09:55', price: 5400 },
  { id: '2', flightNumber: 'N4-205', fromCity: 'Москва', fromCode: 'SVO', toCity: 'Казань', toCode: 'KZN', date: '12.06.2026', departure: '17:40', arrival: '19:15', price: 4900 },
  { id: '3', flightNumber: 'N4-210', fromCity: 'Москва', fromCode: 'SVO', toCity: 'Казань', toCode: 'KZN', date: '13.06.2026', departure: '12:10', arrival: '13:45', price: 6200 },
  { id: '4', flightNumber: 'N4-330', fromCity: 'Москва', fromCode: 'SVO', toCity: 'Сочи', toCode: 'AER', date: '12.06.2026', departure: '10:05', arrival: '13:20', price: 7800 },
  { id: '5', flightNumber: 'N4-118', fromCity: 'Казань', fromCode: 'KZN', toCity: 'Москва', toCode: 'SVO', date: '12.06.2026', departure: '07:15', arrival: '08:50', price: 5300 },
  { id: '6', flightNumber: 'N4-402', fromCity: 'Сочи', fromCode: 'AER', toCity: 'Москва', toCode: 'SVO', date: '13.06.2026', departure: '19:20', arrival: '22:35', price: 7600 },
]

const SEARCH_DELAY = 600

async function searchFlights(from: string, to: string, date: string): Promise<Flight[]> {
  await new Promise((resolve) => setTimeout(resolve, SEARCH_DELAY))

  const fromQuery = from.trim().toLowerCase()
  const toQuery = to.trim().toLowerCase()

  return flights.filter((flight) => {
    const matchesFrom = flight.fromCity.toLowerCase().includes(fromQuery) || flight.fromCode.toLowerCase() === fromQuery
    const matchesTo = flight.toCity.toLowerCase().includes(toQuery) || flight.toCode.toLowerCase() === toQuery

    return matchesFrom && matchesTo && flight.date === date
  })
}

function FlightCard({ flight }: { flight: Flight }) {
  return (
    <View style={styles.card}>
      <View style={styles.cardHeader}>
        <Text style={styles.flightNumber}>{flight.flightNumber}</Text>
        <Text style={styles.price}>{`${flight.price.toLocaleString('ru-RU')} ₽`}</Text>
      </View>
      <Text style={styles.route}>{`${flight.fromCity} (${flight.fromCode}) → ${flight.toCity} (${flight.toCode})`}</Text>
      <Text style={styles.time}>{`${flight.date}, ${flight.departure}–${flight.arrival}`}</Text>
    </View>
  )
}

export default function App() {
  const [from, setFrom] = useState('')
  const [to, setTo] = useState('')
  const [date, setDate] = useState('')
  const [results, setResults] = useState<Flight[] | null>(null)
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState('')

  const datePattern = /^\d{2}\.\d{2}\.\d{4}$/

  async function handleSearch() {
    if (from.trim() === '' || to.trim() === '') {
      setResults(null)
      setError('Заполните поля «Откуда» и «Куда»')
      return
    }

    if (!datePattern.test(date.trim())) {
      setResults(null)
      setError('Введите дату в формате ДД.ММ.ГГГГ, например 12.06.2026')
      return
    }

    setLoading(true)
    setError('')
    try {
      setResults(await searchFlights(from, to, date.trim()))
    } catch {
      setResults(null)
      setError('Не удалось выполнить поиск. Попробуйте ещё раз')
    } finally {
      setLoading(false)
    }
  }

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Поиск рейсов</Text>

      <TextInput style={styles.input} value={from} onChangeText={setFrom} placeholder="Откуда: город или код" />
      <TextInput style={styles.input} value={to} onChangeText={setTo} placeholder="Куда: город или код" />
      <TextInput style={styles.input} value={date} onChangeText={setDate} placeholder="Дата, например 12.06.2026" />

      <Pressable style={styles.button} onPress={handleSearch} disabled={loading}>
        <Text style={styles.buttonText}>Найти рейсы</Text>
      </Pressable>

      {error !== '' && <Text style={styles.error}>{error}</Text>}

      {loading && <ActivityIndicator size="large" color="#0057B8" style={styles.loader} />}

      {!loading && error === '' && results !== null && (
        <FlatList
          data={results}
          keyExtractor={(item) => item.id}
          contentContainerStyle={styles.list}
          renderItem={({ item }) => <FlightCard flight={item} />}
          ListEmptyComponent={<Text style={styles.message}>Рейсы не найдены. Измените запрос или дату.</Text>}
        />
      )}

      {!loading && error === '' && results === null && (
        <Text style={styles.message}>Заполните форму и нажмите «Найти рейсы».</Text>
      )}

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 48, paddingHorizontal: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 12 },
  input: { backgroundColor: '#FFFFFF', borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, padding: 12, fontSize: 16, marginBottom: 12 },
  button: { backgroundColor: '#0057B8', borderRadius: 8, alignItems: 'center', justifyContent: 'center', minHeight: 44, marginBottom: 16 },
  buttonText: { color: '#FFFFFF', fontSize: 16, fontWeight: 'bold' },
  error: { color: '#C62828', marginBottom: 16 },
  loader: { marginTop: 32 },
  message: { color: '#555555', textAlign: 'center', marginTop: 24 },
  list: { paddingBottom: 24 },
  card: { backgroundColor: '#FFFFFF', borderRadius: 12, padding: 16, marginBottom: 12, gap: 4 },
  cardHeader: { flexDirection: 'row', justifyContent: 'space-between' },
  flightNumber: { fontWeight: 'bold' },
  price: { fontWeight: 'bold', color: '#0057B8' },
  route: { fontSize: 16 },
  time: { color: '#555555' },
})
```

Разберём ключевые моменты:

- Форма хранит три строки состояния, а запрос собирается из значений всех полей сразу.
- `toLowerCase()` и `trim()` делают поиск нечувствительным к регистру и пробелам, а код аэропорта сравнивается строгим равенством — `SVO` не совпадёт с `SVX`.
- `results === null` означает «поиск ещё не выполнялся» (показана подсказка), пустой массив — «ничего не найдено» (`ListEmptyComponent`).
- Пока идёт поиск, кнопка заблокирована, а вместо списка виден `ActivityIndicator`.
- Задержка `SEARCH_DELAY` имитирует ответ сервера: массив `flights` легко заменить на `fetch`, как в практической работе 26.

## Проверьте работу

1. Заполните форму: Москва, Казань, дата `12.06.2026` — появятся два рейса с номерами, временем и ценой.
2. Введите вместо городов коды `SVO` и `KZN` — результат будет тем же.
3. Поставьте дату `13.06.2026` — останется один рейс, а с датой `14.06.2026` появится сообщение «Рейсы не найдены».
4. Очистите поле «Куда» или введите дату без точек — появится сообщение об ошибке.

## Резюме

- Форма поиска собирает запрос из нескольких полей, а сам поиск — это фильтрация массива по всем условиям сразу.
- `toLowerCase()` и `trim()` снимают различия в регистре и лишних пробелах.
- Состояние `null` отличает «ещё не искали» от «ничего не найдено» (пустой массив).
- Из четырёх состояний экрана показывается ровно одно: подсказка, индикатор загрузки, список или сообщение об ошибке.
- Мок-данные удобны для отладки, но легко заменяются на запрос к серверу.
