- Лекция 17 «Управление состоянием (Unscramble)»: `useReducer` и собственные хуки.

### Что вы создадите

Новую версию приложения `Dessert Clicker` с тремя десертами и хуком `useDessertClicker`.

## Что делает приложение

Игрок нажимает на текущий десерт — «продаётся» одна порция: количество проданных растёт, а выручка увеличивается на цену десерта. Каждые пять проданных десертов открывается следующий вид из списка.

Приложение хранит три связанных значения:

- индекс текущего десерта;
- количество проданных десертов;
- выручку.

Раз они меняются вместе, логично описать их одним состоянием и одним редьюсером.

## Шаг 1. Данные о десертах

```ts
type Dessert = { id: string; name: string; price: number }

const desserts: Dessert[] = [
  { id: '1', name: 'Пончик', price: 20 },
  { id: '2', name: 'Кекс', price: 35 },
  { id: '3', name: 'Мороженое', price: 50 },
]

const DESSERTS_SOLD_TO_CHANGE = 5
```

## Шаг 2. Состояние и редьюсер

Опишите состояние и действия. Вся логика продажи — в чистой функции `dessertReducer`:

```ts
type DessertState = {
  dessertIndex: number
  amountSold: number
  revenue: number
}

type DessertAction = { type: 'SELL_DESSERT' } | { type: 'RESET' }

const initialState: DessertState = {
  dessertIndex: 0,
  amountSold: 0,
  revenue: 0,
}

function dessertReducer(state: DessertState, action: DessertAction): DessertState {
  switch (action.type) {
    case 'SELL_DESSERT': {
      const amountSold = state.amountSold + 1
      const revenue = state.revenue + desserts[state.dessertIndex].price
      const dessertIndex = Math.min(
        Math.floor(amountSold / DESSERTS_SOLD_TO_CHANGE),
        desserts.length - 1,
      )
      return { dessertIndex, amountSold, revenue }
    }
    case 'RESET':
      return initialState
    default:
      return state
  }
}
```

Как меняется индекс десерта:

- после 5 продаж `Math.floor(5 / 5)` равно `1` — открывается второй десерт;
- после 10 продаж — третий;
- `Math.min` не даёт выйти за пределы списка: на последнем десерте выбор остаётся.

## Шаг 3. Собственный хук

Оберните редьюсер в хук `useDessertClicker` — компоненту он вернёт готовые данные и функции:

```tsx
import { useReducer } from 'react'

function useDessertClicker() {
  const [state, dispatch] = useReducer(dessertReducer, initialState)
  const currentDessert = desserts[state.dessertIndex]

  return {
    currentDessert,
    amountSold: state.amountSold,
    revenue: state.revenue,
    sellDessert: () => dispatch({ type: 'SELL_DESSERT' }),
    reset: () => dispatch({ type: 'RESET' }),
  }
}
```

## Шаг 4. Компонент использует хук

Компонент больше не хранит логику — он только отображает данные и вызывает функции хука:

```tsx
function DessertClickerApp() {
  const { currentDessert, amountSold, revenue, sellDessert, reset } = useDessertClicker()
  // разметка: кнопка с текущим десертом, счётчики и кнопка сброса
}
```

## Шаг 5. Проверка

## Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar'
import { useReducer } from 'react'
import { Button, Pressable, StyleSheet, Text, View } from 'react-native'

type Dessert = { id: string; name: string; price: number }

const desserts: Dessert[] = [
  { id: '1', name: 'Пончик', price: 20 },
  { id: '2', name: 'Кекс', price: 35 },
  { id: '3', name: 'Мороженое', price: 50 },
]

const DESSERTS_SOLD_TO_CHANGE = 5

type DessertState = {
  dessertIndex: number
  amountSold: number
  revenue: number
}

type DessertAction = { type: 'SELL_DESSERT' } | { type: 'RESET' }

const initialState: DessertState = {
  dessertIndex: 0,
  amountSold: 0,
  revenue: 0,
}

function dessertReducer(state: DessertState, action: DessertAction): DessertState {
  switch (action.type) {
    case 'SELL_DESSERT': {
      const amountSold = state.amountSold + 1
      const revenue = state.revenue + desserts[state.dessertIndex].price
      const dessertIndex = Math.min(
        Math.floor(amountSold / DESSERTS_SOLD_TO_CHANGE),
        desserts.length - 1,
      )
      return { dessertIndex, amountSold, revenue }
    }
    case 'RESET':
      return initialState
    default:
      return state
  }
}

function useDessertClicker() {
  const [state, dispatch] = useReducer(dessertReducer, initialState)
  const currentDessert = desserts[state.dessertIndex]

  return {
    currentDessert,
    amountSold: state.amountSold,
    revenue: state.revenue,
    sellDessert: () => dispatch({ type: 'SELL_DESSERT' }),
    reset: () => dispatch({ type: 'RESET' }),
  }
}

function DessertClickerApp() {
  const { currentDessert, amountSold, revenue, sellDessert, reset } = useDessertClicker()

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Dessert Clicker</Text>

      <Pressable style={styles.button} onPress={sellDessert}>
        <Text style={styles.dessert}>{currentDessert.name}</Text>
        <Text style={styles.price}>{`Цена: ${currentDessert.price} ₽`}</Text>
      </Pressable>

      <Text style={styles.stats}>{`Продано: ${amountSold}`}</Text>
      <Text style={styles.stats}>{`Выручка: ${revenue} ₽`}</Text>

      <Button title="Сбросить" onPress={reset} />
    </View>
  )
}

export default function App() {
  return (
    <>
      <DessertClickerApp />
      <StatusBar style="auto" />
    </>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#FFF4E6', alignItems: 'center', justifyContent: 'center', gap: 12 },
  title: { fontSize: 24, fontWeight: 'bold' },
  button: { backgroundColor: '#D2691E', paddingHorizontal: 32, paddingVertical: 20, borderRadius: 12 },
  dessert: { color: '#FFFFFF', fontSize: 22, fontWeight: 'bold', textAlign: 'center' },
  price: { color: '#FFFFFF', fontSize: 16, textAlign: 'center', marginTop: 4 },
  stats: { fontSize: 16 },
})
```

## Резюме

- Состояние и логика вынесены из компонента в собственный хук.
- `useReducer` хранит связанные значения одним объектом, а изменения описывает действиями.
- Правило продажи — чистая функция-редьюсер: его легко проверить отдельно от интерфейса.
- Компонент отвечает только за отображение и вызов функций хука.
