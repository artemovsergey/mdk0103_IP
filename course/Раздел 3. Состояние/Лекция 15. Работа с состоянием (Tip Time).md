# Лекция 15. Работа с состоянием (Tip Time)

**Состояние** (state) — это данные, которые изменяются во время работы приложения и влияют на то, что видит пользователь. Текст в поле ввода, выбранный процент чаевых, положение переключателя — всё это состояние. React Native следит за состоянием компонентов и автоматически обновляет интерфейс, когда оно меняется.

Все приложения отображают состояние пользователю. Примеры состояния:

- Сообщение об ошибке при отсутствии сети.
- Текст, введённый в форму регистрации.
- Нажата или не нажата кнопка.
- Выбранный процент чаевых.

На этом занятии вы научитесь работать с состоянием и создадите интерактивный калькулятор чаевых **Tip Time**.

### Что вы узнаете

- Что такое состояние компонента.
- Как хранить состояние с помощью хука `useState`.
- Как создать управляемое текстовое поле `TextInput`.
- Как использовать компоненты `Switch`, `Pressable` и `Button`.
- Как поднимать состояние вверх (lifting state up).

### Что вы создадите

Приложение **Tip Time**, которое рассчитывает сумму чаевых и итог на основе введённой суммы счёта, выбранного процента чаевых и переключателя округления.

## Что такое состояние

Состояние — это данные, которые меняются со временем. Когда состояние меняется, React Native автоматически перерисовывает компонент, чтобы интерфейс отобразил новое значение.

Для состояния не подходят обычные переменные:

```tsx
let amountInput = ''
```

Если изменить такую переменную, React Native не узнает об этом и экран не обновится. Поэтому для значений, влияющих на интерфейс, используют хук `useState`.

## Хук useState

В функциональном компоненте состояние создаётся хуком **`useState`**:

```tsx
import { useState } from 'react'

const [amountInput, setAmountInput] = useState('')
```

- `amountInput` — текущее значение состояния.
- `setAmountInput` — функция для его изменения.
- `useState('')` — начальное значение (пустая строка).

Когда вызывается `setAmountInput('1000')`, компонент перерисовывается, и интерфейс показывает новое значение.

Полезные правила:

- Имена состояний принято давать по шаблону `[значение, setЗначение]`.
- Значение состояния нельзя изменять напрямую — только через функцию-сеттер.
- Каждый вызов `useState` создаёт независимую «ячейку» состояния.

## Управляемое текстовое поле

Текстовое поле создаётся компонентом **`TextInput`**. Чтобы поле стало **управляемым** (controlled), ему передают текущее значение (`value`) и обработчик изменения (`onChangeText`):

```tsx
<TextInput
  value={amountInput}
  onChangeText={setAmountInput}
  placeholder="Например, 1000"
/>
```

Связь работает так:

1. Пользователь вводит текст.
2. Вызывается `onChangeText` с новым текстом.
3. `setAmountInput` обновляет состояние.
4. Компонент перерисовывается, и `value` показывает новый текст.

### Настройка клавиатуры

Свойство `keyboardType` подсказывает мобильной клавиатуре, какие символы показать:

```tsx
<TextInput keyboardType="decimal-pad" ... />
<TextInput keyboardType="numeric" ... />
```

- `decimal-pad` — цифры и десятичный разделитель (для суммы счёта).
- `numeric` — только цифры (например, для процента).

## Переключатель Switch

Компонент **`Switch`** хранит булево состояние — включено или выключено:

```tsx
const [roundUp, setRoundUp] = useState(false)

<Switch value={roundUp} onValueChange={setRoundUp} />
```

- `value` — текущее значение (`true` или `false`).
- `onValueChange` — вызывается, когда пользователь переключает.

## Обработка событий

На нажатие реагируют компоненты **`Pressable`** и **`Button`**. Обработчик передаётся в свойство `onPress`:

```tsx
<Pressable onPress={() => setTipPercent(20)}>
  <Text>20%</Text>
</Pressable>

<Button title="Рассчитать сумму" onPress={() => setTipPercent(15)} />
```

`Pressable` — гибкий контейнер, которому можно задать любые стили, а `Button` — готовая системная кнопка с заголовком.

Обратите внимание: в `onPress` передаётся функция, а не результат её вызова. Запись `onPress={setTipPercent(20)}` вызовет сеттер сразу при рендере и приведёт к ошибке — правильно `onPress={() => setTipPercent(20)}`.

## Приложение Tip Time

Соберём калькулятор чаевых: поле для суммы счёта, выбор процента, переключатель округления и результат. Создайте проект Expo и замените содержимое `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import { Pressable, StyleSheet, Switch, Text, TextInput, View } from 'react-native'

const TIP_OPTIONS = [10, 15, 20]

function calculateTip(amount: number, tipPercent: number): number {
  return (tipPercent / 100) * amount
}

export default function App() {
  const [amountInput, setAmountInput] = useState('')
  const [tipPercent, setTipPercent] = useState(15)
  const [roundUp, setRoundUp] = useState(false)

  const amount = parseFloat(amountInput) || 0
  const rawTip = calculateTip(amount, tipPercent)
  const tip = roundUp ? Math.ceil(rawTip) : rawTip
  const total = amount + tip

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Рассчитать чаевые</Text>

      <Text style={styles.label}>Сумма счёта</Text>
      <TextInput
        style={styles.input}
        value={amountInput}
        onChangeText={setAmountInput}
        placeholder="Например, 1000"
        keyboardType="decimal-pad"
      />

      <Text style={styles.label}>Процент чаевых</Text>
      <View style={styles.options}>
        {TIP_OPTIONS.map((percent) => (
          <Pressable
            key={percent}
            onPress={() => setTipPercent(percent)}
            style={[styles.option, tipPercent === percent && styles.optionSelected]}
          >
            <Text
              style={tipPercent === percent ? styles.optionTextSelected : styles.optionText}
            >
              {percent}%
            </Text>
          </Pressable>
        ))}
      </View>

      <View style={styles.switchRow}>
        <Text style={styles.switchLabel}>Округлить сумму чаевых</Text>
        <Switch value={roundUp} onValueChange={setRoundUp} />
      </View>

      <Text style={styles.result}>{`Сумма чаевых: ${tip.toFixed(2)} ₽`}</Text>
      <Text style={styles.total}>{`Итог: ${total.toFixed(2)} ₽`}</Text>

      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#F5F5F5', alignItems: 'center', justifyContent: 'center', padding: 40 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 24 },
  label: { fontSize: 16, marginBottom: 8, alignSelf: 'flex-start' },
  input: {
    width: '100%',
    borderWidth: 1,
    borderColor: '#CCCCCC',
    borderRadius: 8,
    padding: 12,
    fontSize: 16,
    marginBottom: 24,
    backgroundColor: '#FFFFFF',
  },
  options: { flexDirection: 'row', gap: 12, marginBottom: 24 },
  option: {
    paddingHorizontal: 24,
    paddingVertical: 12,
    borderWidth: 1,
    borderColor: '#CCCCCC',
    borderRadius: 8,
    backgroundColor: '#FFFFFF',
  },
  optionSelected: { backgroundColor: '#0057B8', borderColor: '#0057B8' },
  optionText: { fontSize: 16, color: '#333333' },
  optionTextSelected: { fontSize: 16, color: '#FFFFFF' },
  switchRow: { width: '100%', flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', marginBottom: 24 },
  switchLabel: { fontSize: 16 },
  result: { fontSize: 24, fontWeight: 'bold' },
  total: { fontSize: 18, marginTop: 8 },
})
```

Разберём ключевые моменты:

- `parseFloat(amountInput) || 0` — преобразует строку в число. Если поле пустое или содержит не число, `parseFloat` вернёт `NaN`, и `|| 0` даст `0`.
- `TIP_OPTIONS.map(...)` — создаёт кнопку для каждого процента из массива.
- `tipPercent === percent` — выбранная кнопка подсвечивается другим стилем.
- `roundUp ? Math.ceil(rawTip) : rawTip` — округление включает переключатель `Switch`.
- `tip` и `total` — **производные значения**: они вычисляются при каждом рендере и не хранятся в состоянии.

Введите сумму — числа обновятся автоматически.

## Как обновляется интерфейс

Всё, что зависит от состояния, пересчитывается автоматически:

1. Пользователь вводит текст в поле.
2. Вызывается `setAmountInput` — React Native планирует перерисовку.
3. Функция `App` выполняется заново.
4. Производные значения (`amount`, `tip`, `total`) пересчитываются.
5. На экране появляются новые числа.

Не нужно вручную менять текст на экране — достаточно обновить состояние.

## Поднятие состояния

Когда нескольким компонентам нужны одни и те же данные, состояние поднимают в их общего родителя. Это называется **поднятием состояния** (lifting state up).

Например, вынесем поле ввода в отдельный компонент `EditNumberField`, а состояние оставим в родителе:

```tsx
function EditNumberField({
  value,
  onValueChanged,
}: {
  value: string
  onValueChanged: (text: string) => void
}) {
  return (
    <TextInput
      style={styles.input}
      value={value}
      onChangeText={onValueChanged}
      placeholder="Например, 1000"
      keyboardType="decimal-pad"
    />
  )
}
```

Родитель передаёт состояние и функцию его изменения как свойства (props):

```tsx
export default function App() {
  const [amountInput, setAmountInput] = useState('')

  return (
    <View style={styles.container}>
      <EditNumberField value={amountInput} onValueChanged={setAmountInput} />
      <Text>{`Сумма чаевых: ${calculateTip(parseFloat(amountInput) || 0, 15).toFixed(2)} ₽`}</Text>
    </View>
  )
}
```

Компонент `EditNumberField` не хранит собственное состояние — он получает его от родителя. Такой компонент называется **компонентом без состояния** (stateless). Поднятие состояния делает компоненты переиспользуемыми: одно и то же поле подходит и для суммы счёта, и для процента чаевых.

## Резюме

- Состояние — это данные, которые изменяются со временем и влияют на интерфейс.
- `useState` возвращает значение состояния и функцию его изменения.
- `TextInput` становится управляемым через `value` и `onChangeText`.
- `Switch` — булево состояние с обработчиком `onValueChange`.
- `Pressable` и `Button` вызывают обработчик `onPress`.
- Производные значения вычисляются при рендере, а не хранятся в состоянии.
- Поднятие состояния делает компоненты переиспользуемыми.
