# Практическая работа 14. Приложение калькулятор чаевых (Tip Time)

В этой работе вы создадите полноценное приложение **Tip Time** — калькулятор чаевых. Пользователь вводит сумму счёта, выбирает процент чаевых и нажимает кнопку «Рассчитать», после чего видит сумму чаевых и итог.

### Пререквизиты

- Лекция 15 «Работа с состоянием».
- Умение создавать состояние через `useState` и поднимать его вверх.
- Знание управляемых компонентов `TextInput`.

### Что вы узнаете

- Как использовать `Pressable` для выбора одного варианта из нескольких.
- Как использовать `Button` для запуска вычислений.
- Как обрабатывать пустой и нечисловой ввод.
- Как `KeyboardAvoidingView` защищает поля от клавиатуры.

### Что вы создадите

Приложение `Tip Time`, которое по сумме счёта и проценту чаевых рассчитывает сумму чаевых и итог.

## Шаг 1. Создание проекта

Создайте приложение Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest tip-time --template blank-typescript
cd tip-time
npx expo start
```

Откройте проект в редакторе. Все изменения этой работы вносятся в файл `App.tsx`.

## Шаг 2. Константы и функция расчёта

Добавьте в начало файла список процентов и чистую функцию расчёта (необходимые импорты — в полном коде на шаге 5):

```tsx
const TIP_OPTIONS = [10, 15, 20]

type TipResult = {
  tip: number
  total: number
}

function calculateTip(amount: number, tipPercent: number): TipResult {
  const tip = (tipPercent / 100) * amount
  return { tip, total: amount + tip }
}
```

- `TIP_OPTIONS` — доступные проценты чаевых.
- `calculateTip` — чистая функция: получает числа и возвращает результат. Такие функции легко тестировать, и вы займётесь этим в практической работе 15.

## Шаг 3. Состояние приложения

Объявите состояния внутри компонента `App`:

```tsx
export default function App() {
  const [amountInput, setAmountInput] = useState('')
  const [tipPercent, setTipPercent] = useState(15)
  const [result, setResult] = useState<TipResult | null>(null)
  const [error, setError] = useState('')
```

- `amountInput` — текст из поля ввода, всегда строка.
- `tipPercent` — выбранный процент; по умолчанию 15.
- `result` — результат расчёта или `null`, пока расчёта не было.
- `error` — сообщение об ошибке ввода.

## Шаг 4. Расчёт по кнопке и проверка ввода

Добавьте функцию-обработчик нажатия на кнопку:

```tsx
  function handleCalculate() {
    const amount = Number.parseFloat(amountInput.replace(',', '.'))

    if (amountInput.trim() === '') {
      setError('Введите сумму счёта')
      setResult(null)
      return
    }

    if (Number.isNaN(amount) || amount <= 0) {
      setError('Сумма должна быть положительным числом')
      setResult(null)
      return
    }

    setError('')
    setResult(calculateTip(amount, tipPercent))
  }
```

- `replace(',', '.')` — пользователь может ввести дробное число и через запятую, и через точку.
- Пустой и нечисловой ввод обрабатываются отдельно: результат сбрасывается, а пользователь видит понятную подсказку.
- `return` прерывает выполнение, чтобы расчёт не выполнялся по некорректным данным.

## Шаг 5. Разметка, стили и результат

Ниже — полный код `App.tsx` вместе со `StyleSheet`. Соберите его из шагов 2–4 и добавьте разметку экрана:

```tsx
import { StatusBar } from 'expo-status-bar'
import { useState } from 'react'
import {
  Button,
  KeyboardAvoidingView,
  Platform,
  Pressable,
  StyleSheet,
  Text,
  TextInput,
  View,
} from 'react-native'

const TIP_OPTIONS = [10, 15, 20]

type TipResult = {
  tip: number
  total: number
}

function calculateTip(amount: number, tipPercent: number): TipResult {
  const tip = (tipPercent / 100) * amount
  return { tip, total: amount + tip }
}

export default function App() {
  const [amountInput, setAmountInput] = useState('')
  const [tipPercent, setTipPercent] = useState(15)
  const [result, setResult] = useState<TipResult | null>(null)
  const [error, setError] = useState('')

  function handleCalculate() {
    const amount = Number.parseFloat(amountInput.replace(',', '.'))

    if (amountInput.trim() === '') {
      setError('Введите сумму счёта')
      setResult(null)
      return
    }

    if (Number.isNaN(amount) || amount <= 0) {
      setError('Сумма должна быть положительным числом')
      setResult(null)
      return
    }

    setError('')
    setResult(calculateTip(amount, tipPercent))
  }

  return (
    <KeyboardAvoidingView
      style={styles.screen}
      behavior={Platform.OS === 'ios' ? 'padding' : undefined}
    >
      <View style={styles.container}>
        <Text style={styles.title}>Калькулятор чаевых</Text>

        <Text style={styles.label}>Счёт</Text>
        <TextInput
          style={styles.input}
          value={amountInput}
          onChangeText={setAmountInput}
          placeholder="Например, 1000"
          keyboardType="decimal-pad"
        />
        {error !== '' && <Text style={styles.error}>{error}</Text>}

        <Text style={styles.label}>Процент чаевых</Text>
        <View style={styles.options}>
          {TIP_OPTIONS.map((percent) => (
            <Pressable
              key={percent}
              onPress={() => setTipPercent(percent)}
              style={[styles.option, tipPercent === percent && styles.optionSelected]}
            >
              <Text
                style={tipPercent === percent ? styles.optionTextSelected : styles.optionText}
              >
                {percent}%
              </Text>
            </Pressable>
          ))}
        </View>

        <Button title="Рассчитать" onPress={handleCalculate} />

        {result !== null && (
          <View style={styles.result}>
            <Text style={styles.resultText}>{`Сумма чаевых: ${result.tip.toFixed(2)} ₽`}</Text>
            <Text style={styles.totalText}>{`Итог: ${result.total.toFixed(2)} ₽`}</Text>
          </View>
        )}

        <StatusBar style="auto" />
      </View>
    </KeyboardAvoidingView>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5' },
  container: { flex: 1, justifyContent: 'center', paddingHorizontal: 24, paddingVertical: 40 },
  title: { fontSize: 24, fontWeight: 'bold', textAlign: 'center', marginBottom: 24 },
  label: { fontSize: 16, marginBottom: 8 },
  input: {
    borderWidth: 1,
    borderColor: '#CCCCCC',
    borderRadius: 8,
    padding: 12,
    fontSize: 16,
    backgroundColor: '#FFFFFF',
  },
  error: { color: '#C62828', marginTop: 8 },
  options: { flexDirection: 'row', gap: 12, marginTop: 8, marginBottom: 24 },
  option: {
    flex: 1,
    alignItems: 'center',
    paddingVertical: 12,
    borderWidth: 1,
    borderColor: '#CCCCCC',
    borderRadius: 8,
    backgroundColor: '#FFFFFF',
  },
  optionSelected: { backgroundColor: '#0057B8', borderColor: '#0057B8' },
  optionText: { fontSize: 16, color: '#333333' },
  optionTextSelected: { fontSize: 16, color: '#FFFFFF' },
  result: { marginTop: 24, alignItems: 'center' },
  resultText: { fontSize: 24, fontWeight: 'bold' },
  totalText: { fontSize: 18, marginTop: 8 },
})
```

Разберём ключевые моменты:

- `KeyboardAvoidingView` поднимает содержимое экрана, когда открывается клавиатура; `behavior="padding"` нужен на iOS.
- Поле «Счёт» — управляемый `TextInput` с `keyboardType="decimal-pad"`; сообщение об ошибке выводится под полем, только если `error` не пустая.
- `TIP_OPTIONS.map(...)` создаёт кнопки процентов; условный стиль `tipPercent === percent && styles.optionSelected` подсвечивает выбранную.
- `Button` вызывает `handleCalculate`.
- Блок результата появляется, только когда `result` не равен `null`; `toFixed(2)` оставляет два знака после запятой.

## Проверьте работу

1. Запустите проект командой `npx expo start` и откройте приложение.
2. Введите `1000`, оставьте процент `15 %` и нажмите «Рассчитать» — появятся «Сумма чаевых: 150.00 ₽» и «Итог: 1150.00 ₽».
3. Очистите поле и нажмите «Рассчитать» — появится сообщение «Введите сумму счёта», результат исчезнет.
4. Выберите `20 %` и нажмите «Рассчитать» — сумма чаевых станет `200.00 ₽`.
5. Введите буквы вместо числа — появится сообщение «Сумма должна быть положительным числом».

## Резюме

- Кнопка `Button` запускает расчёт по нажатию.
- `Pressable` с условным стилем удобно использовать для выбора одного варианта из нескольких.
- Перед расчётом важно проверить ввод: пустое поле и нечисловой текст должны давать понятное сообщение.
- `KeyboardAvoidingView` не даёт клавиатуре перекрывать поля ввода.
- Результат хранится в состоянии и появляется на экране только после расчёта.
