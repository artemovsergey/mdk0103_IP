# Практическая работа 29. Камера и файлы устройства

В этой работе вы создадите приложение **Juice Tracker** — дневник соков. Пользователь делает снимок стакана сока или выбирает изображение из галереи, добавляет подпись и оценку, а запись появляется в списке. Список сохраняется на устройстве и восстанавливается при следующем запуске.

### Пререквизиты

- Лекция 23 «Нативные возможности и сборка приложения».
- Умение работать со списком `FlatList` и состоянием `useState`.
- Проект Expo, запущенный в Expo Go на телефоне: камера работает только на реальном устройстве.

### Что вы узнаете

- Как запрашивать разрешения на камеру и галерею.
- Как показать снимок в компоненте `Image`.
- Как сохранять список записей в `AsyncStorage`.

### Что вы создадите

Приложение `Juice Tracker` со списком снимков, подписями и оценками, который не теряется при перезапуске.

## Шаг 1. Создание проекта и установка модулей

Создайте проект Expo с шаблоном TypeScript и установите два модуля:

```bash
npx create-expo-app@latest juice-tracker --template blank-typescript
cd juice-tracker
npx expo install expo-image-picker @react-native-async-storage/async-storage
npx expo start
```

Весь код этой работы находится в файле `App.tsx`.

## Шаг 2. Модель записи и состояние

Каждая запись дневника описывается типом `JuiceEntry`:

```tsx
type JuiceEntry = {
  id: string
  uri: string
  caption: string
  rating: number
}
```

Внутри компонента `App` объявите состояние:

```tsx
const [entries, setEntries] = useState<JuiceEntry[]>([])
const [caption, setCaption] = useState('')
const [rating, setRating] = useState(3)
const [photoUri, setPhotoUri] = useState<string | null>(null)
```

- `entries` — готовые записи списка.
- `caption` и `rating` — данные новой записи.
- `photoUri` — ссылка на снимок, который ждёт подписи и оценки.

## Шаг 3. Разрешения и выбор фото

Модуль `expo-image-picker` сначала запрашивает разрешение, а затем открывает камеру или галерею:

```tsx
const cameraPermission = await ImagePicker.requestCameraPermissionsAsync()
const libraryPermission = await ImagePicker.requestMediaLibraryPermissionsAsync()
```

Если поле `granted` у объекта разрешения равно `false`, покажите сообщение и прервите работу. После разрешения открывается одно из окон:

```tsx
const cameraResult = await ImagePicker.launchCameraAsync(PICKER_OPTIONS)
const galleryResult = await ImagePicker.launchImageLibraryAsync(PICKER_OPTIONS)
```

В `result.assets[0].uri` лежит ссылка на изображение, а `result.canceled` сообщает, что пользователь закрыл окно. Константа `PICKER_OPTIONS` задаёт настройки: только изображения, кадрирование и качество `0.7`.

## Шаг 4. Добавление и сохранение записей

Кнопка «Добавить запись» собирает объект `JuiceEntry` из состояния и ставит его в начало списка, а функция `saveEntries` обновляет и состояние, и хранилище:

```tsx
const entry: JuiceEntry = {
  id: Date.now().toString(),
  uri: photoUri,
  caption: caption.trim(),
  rating,
}
await saveEntries([entry, ...entries])
```

Список сохраняется в `AsyncStorage` при каждом изменении и читается обратно при запуске:

```tsx
const json = await AsyncStorage.getItem(STORAGE_KEY)
if (json !== null) {
  setEntries(JSON.parse(json) as JuiceEntry[])
}

await AsyncStorage.setItem(STORAGE_KEY, JSON.stringify(nextEntries))
```

`AsyncStorage` хранит только строки, поэтому список сериализуют через `JSON.stringify`, а при чтении разбирают через `JSON.parse`. Подробнее это хранилище мы разберём в разделе 10.

## Шаг 5. Полный код App.tsx

Соберите приложение целиком: разметка показывает кнопки, предпросмотр снимка, поле подписи, выбор оценки и список записей.

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage'
import * as ImagePicker from 'expo-image-picker'
import { useEffect, useState } from 'react'
import { Alert, Button, FlatList, Image, Pressable, StyleSheet, Text, TextInput, View } from 'react-native'

const STORAGE_KEY = 'juice-tracker/entries'
const RATING_OPTIONS = [1, 2, 3, 4, 5]

type JuiceEntry = {
  id: string
  uri: string
  caption: string
  rating: number
}

const PICKER_OPTIONS: ImagePicker.ImagePickerOptions = {
  mediaTypes: ['images'],
  allowsEditing: true,
  quality: 0.7,
}

export default function App() {
  const [entries, setEntries] = useState<JuiceEntry[]>([])
  const [caption, setCaption] = useState('')
  const [rating, setRating] = useState(3)
  const [photoUri, setPhotoUri] = useState<string | null>(null)

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then((json) => {
      if (json !== null) {
        setEntries(JSON.parse(json) as JuiceEntry[])
      }
    })
  }, [])

  async function saveEntries(nextEntries: JuiceEntry[]) {
    setEntries(nextEntries)
    await AsyncStorage.setItem(STORAGE_KEY, JSON.stringify(nextEntries))
  }

  async function pickPhoto(source: 'camera' | 'gallery') {
    const permission =
      source === 'camera' ? await ImagePicker.requestCameraPermissionsAsync() : await ImagePicker.requestMediaLibraryPermissionsAsync()
    if (!permission.granted) {
      Alert.alert('Нет доступа', 'Разрешите доступ в настройках устройства.')
      return
    }
    const result =
      source === 'camera' ? await ImagePicker.launchCameraAsync(PICKER_OPTIONS) : await ImagePicker.launchImageLibraryAsync(PICKER_OPTIONS)
    if (!result.canceled) {
      setPhotoUri(result.assets[0].uri)
    }
  }

  async function addEntry() {
    if (photoUri === null) {
      Alert.alert('Сначала выберите фото', 'Сделайте снимок или выберите изображение.')
      return
    }
    const entry: JuiceEntry = {
      id: Date.now().toString(),
      uri: photoUri,
      caption: caption.trim(),
      rating,
    }
    await saveEntries([entry, ...entries])
    setCaption('')
    setRating(3)
    setPhotoUri(null)
  }

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Juice Tracker</Text>
      <View style={styles.photoButtons}>
        <Button title="Сделать фото" onPress={() => pickPhoto('camera')} />
        <Button title="Из галереи" onPress={() => pickPhoto('gallery')} />
      </View>
      {photoUri !== null && <Image source={{ uri: photoUri }} style={styles.preview} />}
      <TextInput
        style={styles.input}
        value={caption}
        onChangeText={setCaption}
        placeholder="Подпись, например «Апельсиновый фреш»"
      />
      <View style={styles.ratingRow}>
        {RATING_OPTIONS.map((value) => (
          <Pressable key={value} onPress={() => setRating(value)} style={[styles.ratingOption, rating === value && styles.ratingOptionSelected]}>
            <Text style={[styles.ratingText, rating === value && styles.ratingTextSelected]}>{value}</Text>
          </Pressable>
        ))}
      </View>
      <Button title="Добавить запись" onPress={addEntry} />
      <FlatList
        style={styles.list}
        data={entries}
        keyExtractor={(entry) => entry.id}
        renderItem={({ item }) => (
          <View style={styles.card}>
            <Image source={{ uri: item.uri }} style={styles.cardImage} />
            <Text style={styles.cardTitle}>{item.caption === '' ? 'Без подписи' : item.caption}</Text>
            <Text style={styles.cardRating}>{`Оценка: ${item.rating} из 5`}</Text>
          </View>
        )}
      />
    </View>
  )
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#F5F5F5', paddingTop: 60, paddingHorizontal: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 16 },
  photoButtons: { gap: 8, marginBottom: 16 },
  preview: { height: 200, borderRadius: 12, marginBottom: 12 },
  input: { borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, padding: 12, fontSize: 16, backgroundColor: '#FFFFFF', marginBottom: 12 },
  ratingRow: { flexDirection: 'row', gap: 8, marginBottom: 16 },
  ratingOption: { width: 44, height: 44, alignItems: 'center', justifyContent: 'center', borderWidth: 1, borderColor: '#CCCCCC', borderRadius: 8, backgroundColor: '#FFFFFF' },
  ratingOptionSelected: { backgroundColor: '#0057B8', borderColor: '#0057B8' },
  ratingText: { fontSize: 16, color: '#333333' },
  ratingTextSelected: { color: '#FFFFFF' },
  list: { flex: 1, marginTop: 16 },
  card: { backgroundColor: '#FFFFFF', borderRadius: 12, padding: 12, marginBottom: 12 },
  cardImage: { width: '100%', height: 160, borderRadius: 8, marginBottom: 8 },
  cardTitle: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
  cardRating: { fontSize: 14, color: '#555555' },
})
```

Ключевые моменты:

- `PICKER_OPTIONS` типизирована как `ImagePicker.ImagePickerOptions` — одна константа для камеры и галереи.
- `useEffect` с пустым массивом зависимостей выполняется один раз — при запуске приложения.
- `saveEntries` обновляет и состояние, и хранилище, поэтому список всегда совпадает с сохранённой версией.

> Примечание: мы сохраняем только ссылку `uri`; для долговременного хранения снимков файлы копируют в постоянную папку через `expo-file-system` (лекция 23).

## Резюме

- Перед камерой и галереей приложение обязано запросить разрешение и проверить поле `granted`.
- `launchCameraAsync` и `launchImageLibraryAsync` возвращают объект с полями `canceled` и `assets`.
- Список записей хранится в состоянии и рендерится через `FlatList`.
- `AsyncStorage` сохраняет список между запусками приложения.
