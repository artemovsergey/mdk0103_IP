# Экзаменационные билеты по мобильной разработке на React Native (Expo)

## Инструкция для студента

- Выполните задание в отдельном проекте Expo на TypeScript:
  ```bash
  npx create-expo-app@latest exam-app --template blank-typescript
  cd exam-app
  npx expo start
  ```
- Весь код размещается в файле `App.tsx` (при желании допускается вынести отдельные компоненты в соседние файлы).
- Запустите приложение в браузере (клавиша `w`) или на телефоне через Expo Go.
- Вёрстка должна быть адаптивной и корректно отображаться на экранах разных размеров.
- Состояние должно управляться через хуки `useState` / `useEffect` или `useReducer` (по желанию).
- Дополнительные библиотеки устанавливаются командами `npm install <пакет>` или `npx expo install <пакет>`:
  - `react-native-paper` — `Checkbox`, `RadioButton`, `Menu`, `Snackbar`, `Slider`, `Card` (варианты 6, 7, 11, 13, 18, 19, 23, 25).
  - `@react-native-community/slider` — `Slider` (вариант 7, если не используется Paper).
- Время на выполнение: **40 минут**.
- Что можно: пользоваться конспектом лекций, документацией React Native (docs.expo.dev, reactnative.dev) и официальной документацией установленных библиотек.
- Что нельзя: пользоваться чатами и генеративными нейросетями, обсуждать задание с другими студентами.
- Результат: работающее приложение, продемонстрированное на телефоне через Expo Go или в браузере; либо ссылка на репозиторий / архив с проектом.
- Критерии оценивания: приложение запускается без ошибок (3 балла), требования варианта выполнены полностью (4 балла), состояние обновляет интерфейс динамически (2 балла), аккуратная вёрстка и коррекция граничных случаев (1 балл).

## Вариант 1. «Приветствие»

Создайте экран с текстовым полем (`TextInput`) и кнопкой. Пользователь вводит своё имя, нажимает кнопку — ниже появляется текст: «Привет, [имя]!». Если поле пустое — выводится сообщение «Введите имя».

- `TextInput` — управляемое поле: `value` и `onChangeText` связаны с `useState`.
- `Pressable` или `Button` с обработчиком `onPress`.
- Имя хранится в состоянии, при его изменении приветствие пропадает или обновляется.
- Пустая строка (или строка из пробелов) — отдельное сообщение об ошибке.
- Текст приветствия отображается под кнопкой.

## Вариант 2. «Счётчик»

Создайте экран с текстом-счётчиком (начальное значение 0) и двумя кнопками: «+» и «−». При нажатии на «+» значение увеличивается на 1, при нажатии на «−» — уменьшается на 1. Минимальное значение — 0 (нельзя уйти в минус).

- Состояние с числом через `useState(0)`.
- Две кнопки `Pressable` или `Button`: «+» и «−» (символ минуса — `−`, не дефис).
- Текущее значение выводится крупным текстом.
- Кнопка «−» не уменьшает счётчик ниже нуля.
- Кнопка «−» становится неактивной (`disabled`) при значении 0.

## Вариант 3. «Калькулятор суммы»

Два текстовых поля для ввода чисел и кнопка «Сложить». При нажатии на кнопку под ней отображается сумма двух чисел. Если одно из полей пустое или введено не число — выводится «Ошибка ввода».

- Два управляемых `TextInput` с `keyboardType="decimal-pad"`.
- Кнопка `Pressable` или `Button` с обработчиком `onPress`.
- Числа преобразуются через `parseFloat`, результат проверяется на `NaN`.
- Результат выводится с округлением до 2 знаков (`toFixed(2)`).
- Сообщение «Ошибка ввода» отображается красным цветом.

## Вариант 4. «Кнопка-невидимка»

Разместите на экране переключатель (`Switch`) с подписью «Показать кнопку». Если переключатель включён — под ним видна кнопка «Нажми меня». Если выключен — кнопка исчезает. При нажатии на кнопку показывается диалог `Alert` с текстом «Кнопка нажата».

- Булево состояние через `useState(false)` и `Switch` с `onValueChange`.
- Условный рендеринг: `{showButton && <Button ... />}`.
- Подпись переключателя в одном ряду с `Switch` (`flexDirection: 'row'`).
- Нажатие кнопки вызывает `Alert.alert('Кнопка нажата')`.
- Кнопка полностью исчезает из интерфейса при выключенном переключателе.

## Вариант 5. «Список покупок»

Текстовое поле и кнопка «Добавить». При нажатии на кнопку текст из поля добавляется в `FlatList` в виде списка. После добавления поле ввода очищается. Пустые строки добавлять нельзя — показывать `Snackbar` с предупреждением.

- Установите `react-native-paper` для `Snackbar` (`npx expo install react-native-paper`).
- Массив покупок хранится в состоянии, новые элементы добавляются через `[...items, newItem]`.
- `FlatList` с ключом `keyExtractor` по индексу или по сгенерированному `id`.
- Поле ввода очищается после успешного добавления.
- Пустая строка (или строка из пробелов) не добавляется — показывается `Snackbar` с предупреждением.

## Вариант 6. «Флажки»

Создайте список из 4 чекбоксов (`Checkbox`) с подписями: «Молоко», «Хлеб», «Масло», «Сыр». Внизу экрана — текст «Выбрано: X из 4», где X динамически обновляется при изменении состояния чекбоксов.

- Установите `react-native-paper` и используйте `Checkbox.Item`.
- Отмеченные пункты хранятся в состоянии (например, массив булевых значений или массив выбранных подписей).
- `Checkbox.Item` с `label` и `status` (`checked` / `unchecked`).
- Счётчик «Выбрано: X из 4» пересчитывается при каждом переключении.
- Строка с результатом расположена внизу экрана и не перекрывает список.

## Вариант 7. «Слайдер громкости»

Разместите `Slider` с диапазоном от 0 до 100. Рядом с ним — текст, отображающий текущее значение. При значении 0 цвет текста красный, от 1 до 50 — жёлтый, от 51 до 100 — зелёный. Добавьте иконку динамика, которая меняется в зависимости от уровня (без звука / тихо / громко) — можно использовать эмодзи или иконки из `@expo/vector-icons`.

- Установите `@react-native-community/slider` или используйте `Slider` из `react-native-paper`.
- Значение слайдера хранится в состоянии (`useState`).
- Свойства `minimumValue={0}`, `maximumValue={100}`, `step={1}`.
- Цвет текста вычисляется по значению через условный стиль.
- Иконка или символ динамика меняется при переходе через границы (0 / 1–50 / 51–100).

## Вариант 8. «Случайное число»

Кнопка «Сгенерировать» и текст, отображающий случайное число от 1 до 100. При каждом нажатии число меняется. Добавьте кнопку «Сброс», которая возвращает текст в состояние «Нажмите кнопку».

- Состояние `number: number | null` — `null` означает, что число ещё не сгенерировано.
- Случайное число: `Math.floor(Math.random() * 100) + 1`.
- При повторном нажатии «Сгенерировать» число обязательно меняется.
- Кнопка «Сброс» возвращает состояние в `null`.
- Текст «Нажмите кнопку» показывается, пока число не сгенерировано.

## Вариант 9. «Таймер обратного отсчёта»

Поле ввода для количества секунд и кнопка «Старт». После нажатия запускается обратный отсчёт, текущее значение отображается крупным текстом. При достижении 0 выводится «Время вышло!». Использовать `useEffect` с `setInterval`. Кнопка «Старт» во время отсчёта неактивна.

- Управляемый `TextInput` с `keyboardType="numeric"`.
- Отсчёт реализуется через `useEffect` + `setInterval` (интервал создаётся при старте и очищается через `clearInterval` в функции очистки).
- Текущее значение таймера в состоянии, уменьшается каждую секунду.
- При достижении 0 интервал останавливается и показывается «Время вышло!».
- Кнопка «Старт» неактивна, пока идёт отсчёт; пустой ввод не запускает таймер.

## Вариант 10. «Переключение темы»

Создайте экран с переключателем «Тёмная тема». При включении переключателя фон экрана становится тёмным, текст — светлым, и наоборот. Используйте собственную цветовую схему (не обязательно системную тему, достаточно кастомных цветов фона и текста через состояние).

- Булево состояние темы через `useState(false)` и `Switch`.
- Цвет фона и цвет текста вычисляются из состояния при рендере.
- Стили комбинируются через массив: `[styles.container, dark && styles.containerDark]`.
- На экране есть заголовок и пояснительный текст, читаемые в обеих темах.
- Переключение мгновенно меняет цвета без перезапуска приложения.

## Вариант 11. «Заметка»

Большое текстовое поле (многострочное) и кнопка «Сохранить». При нажатии «Сохранить» текст заметки отображается под кнопкой в `Card` с закруглёнными краями. При повторном сохранении старая заметка заменяется новой. Кнопка «Очистить» удаляет текст из поля и карточки.

- `TextInput` с `multiline` и увеличенной высотой.
- Текст поля и сохранённая заметка — два отдельных состояния.
- Кнопка «Сохранить» переносит текст поля в карточку (`Card` из Paper или `View` со стилями).
- Повторное сохранение заменяет содержимое карточки, а не добавляет вторую.
- Кнопка «Очистить» сбрасывает оба состояния; пустая заметка не сохраняется.

## Вариант 12. «Подсчёт символов»

- Текст «Введено символов: X» обновляется на каждый ввод.
- При длине больше 50 цвет счётчика меняется на красный.
- Ввод обрезается до 50 символов (проверка длины в `onChangeText`).

## Вариант 13. «Радиокнопки»

## Вариант 14. «Регистрация»

Результат проверки отображается под кнопкой (успех или конкретная ошибка).

- При успехе показывается зелёное сообщение «Регистрация прошла успешно».
- При ошибке выводится конкретное сообщение (какое именно правило нарушено), красным цветом.
- Сообщения на русском языке, например: «Заполните все поля», «Пароль должен быть не короче 6 символов», «Пароли не совпадают».

## Вариант 20. «Секундомер»

## Вариант 25. «Список задач (To-Do)»

Поле ввода и кнопка «Добавить задачу». Задачи добавляются в `FlatList`. У каждой задачи — `Checkbox` для отметки выполнения. Выполненные задачи отображаются с зачёркнутым текстом (`textDecorationLine: 'line-through'`) и серым цветом. Кнопка «Удалить выполненные» удаляет все отмеченные задачи. Счётчик оставшихся задач внизу: «Осталось: X».

- Установите `react-native-paper` и используйте `Checkbox.Android` или `Checkbox.Item`.
- Задача — объект `{ id, title, done }`, список задач хранится в состоянии.
- Добавление через `[...tasks, newTask]`, поле очищается, пустая строка не добавляется.
- Переключение чекбокса обновляет `done` конкретной задачи через `map`.
- Выполненные задачи зачёркнуты и серые; «Удалить выполненные» фильтрует список.
- Внизу — счётчик «Осталось: X» по числу невыполненных задач.
